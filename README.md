# 포켓몬 택틱스 — 신오 대결전 (비공식 팬 데모)

브라우저에서 바로 플레이하는 포켓몬 SRPG 전투 데모입니다.
DS 해상도 256×192, 24px 타일 + 카메라 스크롤, 18타입 상성, 적 AI, PMD(불가사의 던전)식 맵 위 전투 연출, 갈무리 픽셀 폰트 한글 UI.

> 비영리 팬 프로젝트입니다. Pokémon 및 관련 명칭의 권리는 Nintendo / Creatures / GAME FREAK 에 있습니다.

## 실행

ES 모듈을 쓰므로 `file://` 로 `index.html` 을 직접 열면 동작하지 않습니다. 로컬 서버로 여세요.

```bash
node tools/serve.js 8000
```

브라우저에서 <http://localhost:8000> 접속. (Node 18 이상, 외부 패키지 없음. 서버는 이 컴퓨터에서만 접속 가능)

## 게임 흐름

타이틀 → **마을(로비)** → 출격 게시판 → **던전 선택** → 층마다 [전투 → 결산(레벨업·기술·진화) → 다음 층 / 마을로] → 마을

- **로그라이크 던전**: 층마다 지형·적·보물상자가 자동 생성됩니다. 깊을수록 적이 강해집니다.
  - 신오 들판 5층 (5층 보스) → 돌파하면 신오 동굴 7층 해금
  - 층 클리어: 아군 1마리가 **계단**에 도착하거나 적 전멸. 보스 층은 보스 격파.
  - 층 사이: 매 층 완전 회복, 단 그 층에서 기절한 포켓몬은 다음 층을 HP 50%로 시작.
  - **보물상자**(진화의돌 · 경험 사탕)는 돌파하거나 층 사이에서 마을로 돌아가면 받습니다. **전멸하면 보물만 잃고** 레벨·기술은 유지.
  - 층에 들어갈 때마다 저장 → 도중에 꺼도 타이틀 "이어하기"로 같은 층·같은 맵에서 재개.
- 마을은 대략적인 뼈대입니다. 건물 자리는 바위·나무 더미입니다.
- **코인**: 적 격파 `3 + 레벨÷3`, 층 돌파 `10 × 층`, 보물상자 코인 주머니 `20 × 층`. 돌파·귀환 시 받고 전멸하면 이번 탐험 코인을 잃습니다.
- **모집소**(마을 오른쪽 위 표지판): 100코인으로 1단계 포켓몬 뽑기. 희귀도 평범 70% · 희귀 25% · 매우 희귀 5% (계열 최종형 종족값 기준). 같은 계열이 또 나오면 **결정**이 모입니다(알기술·특성 해금용 예정).
- **편성소**: 메타몽 + 출전 4마리를 고릅니다. 출전하지 않은 동료는 경험치를 받지 않습니다.
- 마을에는 동료들(출전 멤버 먼저)이 서 있고, 말을 걸면 전투 팁을 알려 줍니다.

## 전투 규칙 (요약)

- **HP 배율**: 최대 HP × (1.4 + 레벨/100). 같은 레벨끼리 보통 공격은 HP 약 17%, 효과가 굉장하면 약 33%.
- **변화기**: 습득표의 능력치 변화기(칼춤·울음소리·고속이동 …)를 배우고 씁니다. 메뉴에 "변화" 표시.
  - 대상: 자신 / 적 하나(사거리 1~2) / 주변 적 전체(거리 2 이내) / 아군 하나(인접) / 주변 아군(자신 포함, 거리 2 이내). 자신·범위형은 확인 한 번으로 사용.
  - 적에게 쓰는 변화기는 명중 판정을 받습니다.
- **능력치 랭크**: −6~+6. 공격·방어·특공·특방·스피드는 본가 배율, 명중·회피는 랭크당 ±8%p.
  - 랭크 변화는 하나하나가 따로 시간을 가집니다: 수치는 합쳐지지만(−6~+6) 각 변화는 **3턴 뒤** 따로 풀립니다(그 유닛 편 차례가 끝날 때 1씩). 다시 써도 이전 변화가 연장되지 않습니다. **범위 기술**(울음소리·째려보기·얼다바람 등)로 바뀐 랭크는 **2턴**.
  - 층이 바뀌면 모두 초기화. 유닛 정보창에 "공+2(3)"처럼 표시.
- **부가효과**: 공격기의 능력치 변화(깨물어부수기 방어↓ 20%, 인파이트 자신 방어·특방↓)가 확률대로 발동. 빗나가거나 효과가 없으면 발동하지 않습니다.
- 상대도 변화기를 씁니다 (때릴 상대가 없으면 자신 강화, 범위 안 아군이 있으면 약화).
- **기술 범위 모양**: 기술마다 맞는 모양이 다릅니다. 기술 정보창에 표시.
  - 단일(사거리 1, 1~2, 원거리 2~3) · 직선 3칸 관통(하이드로펌프 등, 벽에서 멈춤) · 앞 부채꼴(열풍·눈보라 등) · 주변 8칸(지진·방전 등, **아군도 맞음**) · 착탄 십자(불대문자 등, 2~3칸 앞).
  - 방향·착탄 칸은 방향키나 클릭으로 고르고, 처음엔 가장 많이 맞는 쪽을 가리킵니다. 여러 마리를 맞히면 각자 데미지 ×0.75.
  - 자폭·대폭발은 쓴 쪽이 기절합니다. 찌리리공·붐볼은 처음부터 자폭을 알고, 상대 찌리리공은 적극적으로 터집니다.
- **날씨** (층마다 확률로 하나, 층 끝까지 고정; 들판 비 15%·쾌청 10%, 동굴 안개 15%):
  - 비: 물 ×1.5·불꽃 ×0.5, 번개 반드시 명중 / 쾌청: 불꽃 ×1.5·물 ×0.5, 얼지 않음, 번개 명중 50
  - 모래바람·싸라기눈: 해당 타입 외 차례 끝 HP 1/16 (지금 던전엔 안 나옴) / 안개: 명중 −10%p, 아군에게서 5칸 이상 먼 적은 실루엣·"???"
- **특성** (4세대 기준, 숨겨진 특성 제외): 동료가 될 때 그 종의 특성 중 하나가 무작위로 정해지고, 진화해도 같은 칸을 유지합니다. 편성소 "특성 바꾸기"에서 그 계열 결정 3개로 다른 특성으로 바꿀 수 있습니다(특성이 하나뿐인 종은 불가).
  - 본가 그대로: 데미지·명중·급소(심록류·적응력·테크니션·천하장사·필터·노가드 등), 무효·흡수(부유·축전·저수·타오르는불꽃·불가사의부적), 상태이상·랭크 방지(유연·불면·클리어바디 등), 날씨·차례 끝(쓱쓱·엽록소·젖은접시·포이즌힐·가속·탈피), 접촉 반격(정전기·불꽃몸 등 — 접촉 = 1칸 거리 물리 기술). 틀깨기는 방어 특성을 무시합니다.
  - SRPG 판: 위협(이동을 마치면 옆의 상대 공격 −1, 같은 상대에게 연달아 안 됨), 잔비·가뭄 등(층 시작 날씨, 빠른 쪽 먼저·나중 것이 덮음, 안개는 그대로), 피뢰침·마중물(2칸 안 단일 전기/물 기술을 끌어옴), 개미지옥·그림자밟기·자력(옆의 상대 이동력 1), 옹골참(HP 가득에서 한 층 한 번 버팀), 게으름, 슬로스타트(5차례), 트레이스, 다운로드, 플러스·마이너스, 플라워기프트, 나이트메어, 싱크로, 픽업·꿀모으기(층 돌파 때 10% 로 코인·사탕), 위험예지·예지몽(적 정보창에 "효과 굉장" 경고).
  - 쓸 데가 아직 없는 특성(먹보·서투름 등)은 정보창에 회색으로 보이고 효과가 없습니다. 정보창·편성소·결산 화면에 특성 이름, 발동하면 대사가 나옵니다.
- **상태이상** (본가 4~5세대 기준, 층이 끝나면 모두 회복):
  - 마비: 이동력·스피드 절반, 기술을 쓸 때 25% 실패. 화상: 페이즈 끝 HP 1/8, 물리 데미지 절반. 독 1/8, 맹독 1/16부터 점점 증가.
  - 잠듦: 1~3턴 이동·행동 불가. 얼음: 매 턴 20%로 녹고 최대 3턴, 불꽃 공격에 맞으면 바로 녹음.
  - 혼란: 1~4턴, 기술을 쓸 때 50%로 자신을 공격. 다른 상태이상과 함께 걸릴 수 있음.
  - 면역: 불꽃→화상, 얼음→얼음, 독·강철→독. 전기자석파는 땅 타입에 무효.
  - 시작 기술 중 변화기는 최대 2개. 상대는 아군이 이미 2마리 이상 잠들거나 얼어 있으면 잠재우는 기술을 쓰지 않습니다.

## 조작

마을: 방향키(누르고 있으면 계속 걷기) 또는 클릭으로 이동, Z 로 앞을 조사·대화. 출격 준비 화면에서 X 는 마을로.

전투:

| 동작 | 키보드 | 마우스 |
|---|---|---|
| 커서 이동 (카메라가 따라감) | 방향키 | 마우스 이동 |
| 결정 | Z / Enter / Space | 왼쪽 클릭 |
| 취소 (이동 후 취소 시 원위치) | X / Esc / Backspace | 오른쪽 클릭 |
| 턴 종료 | E | 빈 칸 클릭 → 턴 종료 |

- 아군 선택 → 파란 칸으로 이동 → 기술 선택 → 대상 선택. 대상 선택 중에는 명중률·데미지 범위·기절 여부가 미리 표시됩니다.
- 지형: 수풀(회피 +15%), 바위산(이동 비용 2, 방어·특방 ×1.2), 물(물·비행 타입만 진입), 나무(진입 불가).

## 스프라이트 (PMD Sprite Collab)

저장소에는 스프라이트가 **포함되어 있지 않습니다**. 없으면 코드로 그린 오리지널 임시 도트가 표시됩니다.
<https://sprites.pmdcollab.org> 에서 포켓몬별 스프라이트·초상화 폴더를 받아 그대로 넣으면 자동으로 적용됩니다.

```
assets/sprites/pmd/sprite/0392/AnimData.xml, Idle-Anim.png, Walk-Anim.png, Attack-Anim.png, Shoot-Anim.png, Hurt-Anim.png …
assets/sprites/pmd/portrait/0392/Normal.png  (선택: Determined.png, Pain.png)
```

- 저장소를 통째로 받았다면 `SpriteCollab-master/` 를 프로젝트 맨 위에 두기만 해도 됩니다 (`assets/sprites/pmd/` 를 먼저 찾고, 없으면 여기서 찾음). 이 폴더도 git 에서 제외됩니다.
- 폴더 이름은 전국도감 번호 4자리: 24종 (각 계열 1~3단계, 예: 0390 불꽃숭이 · 0391 파이숭이 · 0392 초염몽)
- 쓰는 애니메이션: Idle(대기) · Walk(이동, 8방향) · Attack(물리) · Shoot(특수) · Hurt(피격). 없는 동작은 비슷한 동작으로 대체합니다.
- 초상화는 정보창과 대사창에 쓰입니다 (공격 시 Determined, 피격 시 Pain).
- **라이선스**: 커뮤니티 제작분은 CC BY-NC 4.0 (비상업 + 출처 표기, 각 폴더의 `credits.txt`). `CHUNSOFT` 로 표기된 부분은 원작 게임 스프라이트입니다. 이 폴더는 git 에 올라가지 않도록 설정되어 있습니다.

## 맵 타일

- 타일은 그림 파일 없이 코드로 그립니다 (`src/render/tiles.js`). 4~5세대 DS 필드풍: 모래 물가의 물, 뾰족한 긴 풀숲, 이어지는 숲, 입체 바위. 동굴 테마는 같은 구조에 돌바닥·수정 덤불·암벽.
- 물·풀숲·벽은 4분할 오토타일로 경계가 둥글게 이어집니다 (`src/render/autotile.js`).
- 브라우저 없이 타일을 PNG 로 미리 보기: `node tools/tile-preview.js out.png field test` (테마 `field`/`cave`, 맵 `map`/`town`/`test`).

## 기술 이펙트 (pixelfx)

- 공격·피격·랭크·상태이상 연출은 [pixelfx](https://github.com/patch-gg/pixelfx) (MIT, © Patch · Hugo Duprez, 일부 Hollow Crown) 의 픽셀 이펙트를 씁니다. 라이선스 원문: `src/vendor/pixelfx/LICENSE`, `NOTICE.md`.
- 기술마다 **모양·분류로 고른 틀 × 타입 색**: 근접은 타격 불꽃, 원거리 특수는 구체가 날아감, 직선은 빔, 부채꼴은 숨결, 주변은 충격파, 착탄은 십자 폭발. 자폭·대폭발은 전용 큰 폭발 + 화면 흔들림.
- 위력에 따라 세기가 달라집니다: 위력 50 이하는 작은 반짝임(귀엽게), 90 이상은 충격이 한 겹 더 겹치고 더 밝고 넓게.
- 랭크는 오르면 빨강, 내리면 파랑. 상태이상은 걸릴 때 한 번 + 걸려 있는 동안 몸 위에 계속 표시.
- 고르는 규칙: `src/data/moveFx.js`, 기술별 예외: `src/data/moveFx.json`.
- 이펙트를 늘릴 때: pixelfx 를 받아 둔 경로로 `node tools/vendor-pixelfx.js <pixelfx 경로>` (목록은 그 파일의 `FX_FILES`).

## 성장 · 진화

- **주인공은 메타몽**: 마을을 걷는 리더이자 항상 출전하는 5번째 멤버 (지금은 몸통박치기, 변신은 이후 확장).
- 파티: 메타몽 + 불꽃숭이·팽도리·모부기·꼬링크, 시작 Lv.8.
- **포켓몬 1~4세대 493종**: 던전 적은 테마 타입(들판: 노말·풀·벌레·비행·전기·페어리 / 동굴: 바위·땅·강철·고스트·독·드래곤·격투)에서 층 깊이에 따라 진화 단계가 올라가며 등장. 전설·환상 제외.
- **분기 진화**: 조건을 만족하는 갈래가 여럿이면 "어느 모습으로 진화할까?"에서 고르고(진화하지 않기 가능, 다음 레벨업에 다시 물음), 원작이 무작위인 개무소는 무작위.
- 적을 쓰러뜨리면 경험치: 쓰러뜨린 아군 100%, 그 순간 살아 있는 다른 아군 50%. 패배해도 받은 경험치는 남음.
- 전투 후 **결산** 화면에서 레벨업 → 기술 습득(4개면 잊을 기술 선택) → 진화 연출.
- 진화 규칙: 원작 레벨 진화는 그대로, 아이템 진화는 모두 **진화의돌**, 친밀도·교환·기타 진화는 레벨 진화로 대체 (`src/data/balance.js` 의 매트릭스: 2단 20/30/25, 3단 1차 16/20/18, 3단 2차 32/36/34, 2차는 1차+8 이상).
- 진화의돌: 던전 보물상자에서 획득. 마을 **편성소**에서 사용 (지금 아군은 모두 레벨 진화라 대상이 없음).
- 진행은 브라우저에 자동 저장 (`localStorage`). 타이틀에서 이어하기 / 처음부터.

## 데이터 (PokeAPI)

전국도감 1~493 포켓몬(종족값·성장 곡선·기초 경험치·진화 갈래·진화 단계)과 기술(한국어 이름·타입·위력·명중)은 [PokeAPI](https://pokeapi.co) 4세대 기준(습득표: Pt → HGSS → DP 순)으로 받아 `src/data/generated/pokedex.js` 에 저장해 둡니다. 게임 실행 중에는 API 를 호출하지 않습니다. 응답은 `tools/.cache/` 에 캐시되어 다시 받을 때 빠릅니다.

```bash
node tools/fetch-pokeapi.js   # 포켓몬을 추가하거나 데이터를 새로 받을 때 (네트워크 필요)
```

- 습득 기술은 Pt 레벨업 습득표. 변화기·위력 없는 기술은 아직 배우지 않습니다.
- 사거리(물리 1칸, 특수 1~2칸, 예외 `src/data/moveRanges.js`)와 이동력(스피드 종족값 기준)은 SRPG 전용 규칙입니다.
