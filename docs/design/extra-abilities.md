# 추가 특성 시스템 (특성 3칸) — 기획서

- 작성: 2026-11-18 · 상태: **확정** (3칸 SRPG 전용 특성 목록은 별도 기획서)

## 목적
후반으로 갈수록 "내 포켓몬을 내 방식으로" 만드는 성장. 특성을 최대 3개까지 겹친다. 후반 적도 그에 맞춰 강해진다.

## 구조 (사용자 결정)
| 칸 | 내용 | 얻는 방법 |
|---|---|---|
| **1칸** | 원래 특성 (지금 그대로, 숨겨진 특성 포함) | 지금 해금 규칙 (일반 3결정, 숨겨진 4결정) |
| **2칸** | **무작위 특성 1개** — 전체 특성 후보 + 등급(S~C) | 계열 결정, 또는 새 재료 "각성의 구슬" |
| **3칸** | **SRPG 전용 특성** (우리가 새로 만드는 것) | 상점에서 사서 장착 |

## 2칸: 무작위 특성 *(확률·비용은 내 제안 — 사용자 승인)*
- 후보: 게임에 **구현된 특성 전부**, 단 **SS 등급은 후보에서 제외**. 1칸과 같은 특성은 안 나옴.
- **결정으로 굴리기**: 그 계열 결정 2개 → C 50% · B 30% · A 15% · S 5%.
- **각성의 구슬로 굴리기**: 구슬 1개 → C 20% · B 40% · A 30% · S 10%. 구슬은 보스 레이드·시련 보스처럼 귀한 곳에서만 나옴 (나오는 곳·확률은 각 던전 기획 때).
- **다시 굴리기 허용**: 새로 굴리면 이전 2칸 특성은 사라짐.
- 등급 안에서는 고르게 무작위.

## 3칸: SRPG 전용 특성 (상점)
- 예: 선봉(첫 차례 이동력 +2) · 엄호(옆 아군이 받는 피해 일부를 대신) · 지휘(주변 아군 명중 +5). **목록은 별도 기획서.**
- 상점 진열에 전용 특성 칸 1개 추가 (탐험마다 바뀜). 사면 그 포켓몬 전용, 옮기기 불가.

## 적도 강해짐 *(내 제안 — 사용자 승인)*
- 시련 5단계쯤(Lv 50대)부터 일반 적 일부가 2칸 특성 (C·B 만).
- 보스는 A 까지.
- 맨 끝 구간에서는 3칸 전용 특성을 가진 적도.

## 메타몽
1칸은 캡슐로 바꾸는 지금 방식 그대로, 2·3칸은 다른 포켓몬과 같다.

새 세대·숨겨진 특성이 들어오면 그 묶음마다 등급을 같이 매긴다 (`generation-migration.md`).

## 구현 메모 (코딩할 때)
- 동료: `extraAbility: id | null`, `customAbility: id | null`. 전투 유닛은 특성을 배열로(`abilities: [1칸, 2칸, 3칸]`), `has(u, id)` 가 셋 다 봄. 특성 끄기(위액)는 셋 다 끔 *(내 결정)*.
- 등급표 `src/data/abilityTiers.js`. 굴림은 순수 함수(시드 = 저장 카운터).
- 저장 버전 올림. 각성의 구슬은 `items.awakenOrbs`.
