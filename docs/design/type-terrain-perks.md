## 타입별 이득

| 타입 | 이득 |
|---|---|
| **벌레** | 나무 칸을 지나가고 **나무 위에 멈출 수도 있음** (멈추는 건 벌레만 — 유연 특성은 지나가기만). 나무 위에서는 피해 감소 ×1.1(바위 ×1.2 의 열화판) + 회피 +8(수풀 +15 의 열화판)을 동시에 받음 |
| **얼음** | 물 칸을 지나가며 그 칸을 **얼음 타일**로 바꿈. 얼음 타일 = 나중에 얼음 동굴 맵의 미끄러지는 얼음과 같은 칸 |
| **바위** | 바위 칸 이동 비용 2 → 1 |
| **땅** | 바위 칸 이동 비용 2 → 1 |
| **격투** | 바위 칸에 서서 공격하면 명중 +5% |
| **비행** | 지금 규칙(비행 이동력 +1, 물 위 이동 등) 유지 + **모든 장애물 통과**. 나무·벽처럼 원래 못 지나가는 칸은 이동 비용 3, 그 위에 멈출 수 없음. **텔레포트 장치는 못 씀** |
| **물** | 물 칸 이동 규칙 유지 + **물 칸에서 출발한 차례는 이동력 +1** |
| **고스트** | 상대 포켓몬이 있는 칸을 지나갈 수 있음 (멈출 수는 없음) |
| **에스퍼** | 어두운 동굴·안개 맵에서 시야 +1 (비슷한 효과의 특성과 중첩) |
| **풀** | 수풀 회피 +5 (15 → 20) + **수풀 칸에서 출발한 차례는 이동력 +1** |
| **악** | 수풀에 있으면 **3칸 밖**의 상대에게 안 보임 (안개 규칙처럼) |
| **드래곤** | 비행처럼 **장애물 통과**(나무·벽 비용 3, 멈춤 불가) + **물 위 이동**. 비행의 이동력 +1 은 **없음**. 텔레포트 장치는 **쓸 수 있음** |
| **강철** | 바위 칸에서 받는 피해 감소 ×1.2 → **×1.35** |
| **독** | 나중에 나올 늪·폐수 웅덩이 같은 지형의 이동력 감소·이동 방해 면역 |
| **전기** | 물·폐수 같은 **액체 칸**으로 연쇄 공격 (아래 연쇄 규칙) |
| **불꽃** | **수풀·낙엽 칸**으로 연쇄 공격 (아래 연쇄 규칙) |
| **노말** | 주변 칸(상하좌우)에 아군이 있으면 그 수만큼 받는 피해 3% 감소 (최대 12%) |

## 연쇄 공격 규칙 (전기·불꽃)
- 맞은 상대가 그 종류 칸(전기: 액체 / 불꽃: 수풀·낙엽) 위에 있으면 시작.
- 그 칸의 **바로 옆(상하좌우)** 같은 종류 칸에 상대가 있으면 그 상대에게 연쇄, 그 상대의 옆 칸으로 다시 이어짐. 상대가 칸마다 줄지어 있으면 이론상 전체로 퍼질 수 있고, 빈 칸에서는 끊김.
- 연쇄 피해 = 원래 피해의 10%. 한 상대는 한 번만. **광역 기술이 이미 맞힌 상대에게는 연쇄가 겹치지 않음.**
- 아군은 연쇄에 맞지 않음 *(쓴 쪽의 상대 편만 — 내 결정)*.

## 나중 기획에 넘기는 것
얼음 타일(미끄러짐), 텔레포트 장치, 어두운 동굴·안개 시야, 늪·폐수 웅덩이 — 각 맵 기획서에서 정한다. 그 지형이 생기기 전까지 얼음·에스퍼·독의 이득은 쓸 곳이 없다 (얼음의 "물을 얼음 타일로"는 얼음 타일이 생길 때 같이).
