## ✅ 완료 (2026-11-13): 로그라이크 던전

스펙 `docs/superpowers/specs/2026-11-13-roguelike-dungeon-design.md`, 계획 `docs/superpowers/plans/2026-11-13-roguelike-dungeon.md`.

확정된 결정:
- 던전 = 종류별 N층 (예: 신오 들판 5층). 층마다 맵(지형·적)을 자동 생성, 깊을수록 적 레벨↑·종류 변화
- 한 던전을 끝까지 클리어하면 다음 종류 해금 (들판 → 동굴 → 설산 …, 종류마다 타일·적 풀)
- 실패(전멸): **레벨·기술은 유지**, 이번 탐험 보상(진화의돌 등)만 잃음
- 층 사이 HP: **매 층 완전 회복**, 단 **기절한 포켓몬은 HP 50%로** 다음 층 진행
- 층 클리어: **계단 도달(아군 1마리) 또는 적 전멸**
- 출격 게시판 → 던전 선택 화면 (기존 스테이지 선택 대체)

스펙 때 정할 것: 맵 생성 방식(방+통로 / 지형 덩어리), 층 수·해금 조건 수치, 층별 적 레벨 곡선, 층 사이 보상 여부, 탐험 중 저장(중단 후 이어하기) 여부.

## 미뤄 둔 작은 문제 (리뷰 Minor)

- 한 번에 큰 경험치 → 진화 1단계만, 사이 레벨 새 종족 기술 누락 (`core/progress.js`)
- 파티 멤버를 종족으로 식별 → 같은 종족 2마리면 경험치 섞임 (3번 작업 때 index 기반으로)
- 진화 레벨을 이미 넘긴 채 불러온 멤버는 다음 레벨업 때 진화
- 종족값·기초 경험치는 최신 세대 값 (타입·기술은 Pt)
- 결산 행에 "Lv.9 ▶ 10" 표시 없음
