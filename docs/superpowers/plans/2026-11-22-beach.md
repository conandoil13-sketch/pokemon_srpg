# 해변 맵 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 시련 2번 자리를 해변으로 바꾼다 — 얕은 물 칸, 가장자리 바다 띠 + 물때 3상태(−1/0/+1), 깊은 물 섬과 확정 상자, 모래더미, 물·비행 위주 적과 물·얼음 보스, 해변 도트.

**Architecture:** 얕은 물 `,` 은 pathfind·지형 이득에 칸 하나 추가. 바다·섬은 `generateFloor` 안에서 `dungeon.sea` 가 있을 때만 별도 난수(`hashSeed(seed, 4000)`)로 — 다른 던전 결과 불변. 물때는 새 순수 모듈 `src/core/tide.js` 가 칸 등급(A/B)과 라운드로 격자를 바꾸고 `endPhase` 가 부른다. 그림은 단풍 숲처럼 pixelfx 정적 타일(`src/fx-custom/beach/tiles.js`) + `src/render/beachTiles.js`.

**Tech Stack:** 바닐라 JS ES 모듈, `node --test`, pixelfx(vendor).

**Spec:** `docs/superpowers/specs/2026-11-22-beach-design.md`

## Global Constraints
- 자리: 시련 2번 (`fillerStage(2)` 곡선: 시작 Lv 30, 8층, 16×12). id `beach`, 이름 `해변`, 테마 `beach`. 저장 이전 `trial-2` → `beach`.
- 물때 등급표: A = { −1: `.`, 0: `,`, +1: `~` } · B = { −1: `,`, 0: `~`, +1: `~` } · C = 항상 `~`.
- 물때 순서: 라운드(state.turn) 1~3 = 0, 4~6 = +1, 7~9 = 0, 10~12 = −1, 그 뒤 반복. 바뀌기 한 라운드 전 예고.
- 섬: 층마다 60%, 모래 2칸 + 둘레 전부 C, 섬이 생기면 상자 1개 확정(기존 0~2개와 별개, 같은 확률표).
- 소수 타입(전기·얼음·땅만 가진 종): 뽑히면 70% 확률로 한 번 다시 뽑음. 보스는 물 또는 얼음 타입. 모래더미 2~3개, 종 = krabby·kingler·shellder·cloyster·corphish·crawdaunt. 날씨 비 15%.
- 불꽃 불리함 없음. 해변 아닌 던전 골든 해시·난수 소비 그대로.
- 브랜치 `feat/beach`. 테스트 `npm test`.

## Review Focus
1. 밀물에 얕은 물이 깊은 물로 바뀔 때 그 위에 선 땅 포켓몬 → 나갈 수는 있어야 함 (Task 4 테스트).
2. 섬은 어느 물때든 걸어서 못 감 (썰물에도 둘레 C) (Task 3 테스트).
3. 바다 띠가 출발 3열·계단·보스를 덮지 않음, 어느 물때든 도보로 계단·보스 도달 (Task 3 테스트).
4. 텔레포트·밀어내기·바톤터치 착지가 깊은 물에 땅 포켓몬을 올려놓지 않음 → `canEnter` 그대로라 안전, 얕은 물엔 허용 (Task 1 테스트에 `canEnter(',')`).
5. 층 시작 저장 재개 시 물때 0으로 다시 시작 (메모만 — 층 시작 저장이라 자연히 맞음).

### Task 3: 바다 띠 · 물때 등급 · 섬 상자 (층 생성)
**Files:** `src/core/floorgen.js` (+ `placePiles` 가 `dungeon.pileSpecies ?? pool`) · Test `tests/beach.test.js`
**Interfaces:** Produces: 해변 층 결과에 `tide: { a: [{x,y}…], b: [{x,y}…] }` (C 는 그냥 `~`), 섬 상자는 `chests` 에 `{ …, island: true }`. 해변 아닌 던전은 `tide` 키 없음.
- 바다 알고리즘 *(계획에서 정함)*: 띠 쪽 = 위/아래 (`seaRng` 첫 굴림). 깊이 D = `Math.round(H / 4)`, 열마다 d ∈ {D−1, D} (이웃 열과 ±1 이내로 무작위 걸음). x < 3 열은 바다 없음. 해안에서 첫 줄 A(`,`), 둘째 줄 B(`~`), 그 너머 C(`~`). **바다를 덩어리보다 먼저** 칠하고, 덩어리는 띠 줄과 띠 바로 옆 한 줄(완충 줄)에 칠하지 않음 → 연결성 보정이 바다를 뚫지 않음.
- 섬: 연결성·계단·적·상자 뒤, `seaRng` 60% → x ≥ 8, 띠 밖에서 4×3 직사각형(가운데 2칸 모래 + 둘레 10칸 C)이 모두 빈 `.` 이고 사용 안 된 자리 중 하나. 놓은 뒤 땅 도달 칸 수가 직사각형만큼만 줄어야 함(길 안 끊음). 섬 모래 한 칸에 상자 (기존 확률표, 난수 `hashSeed(seed, 4100)`).

  - 바다(`,`+`~`) 면적 18~32%, x < 3 열엔 물 없음.
