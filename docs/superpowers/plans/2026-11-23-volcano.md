# 화산동굴 (8-2) Implementation Plan

**Goal:** 8단계 두 번째 분기 화산동굴 — 용암(건넘 규칙·마그마그 예외), 현무암 열 피해(행동 끝), 분출구 스팀(3라운드 박자·예고·밀기), 쾌청 30%, 화산 그림.
**Architecture:** 지형 문자 `L` `v` `V` + 순수 모듈 `src/core/vent.js` (경로·박자·피해 계산·밀린 자리). 적용(피해·기절)은 battle.js (`steamVents` 를 endPhase 적 페이즈 끝, `basaltHeat` 를 행동 끝 — states `settleSand` 를 지형 정산 훅으로 확장). 배치는 floorgen: `lavaLayout`(별도 난수 7300, 연결성 전) + `volcanoExtras`(7400, 맨 끝). 그림 `src/render/volcanoTiles.js`.
**Spec:** docs/superpowers/specs/2026-11-23-volcano-design.md

## Global Constraints
- 다른 던전의 층 생성 결과·난수 소비 불변 (`dungeon.volcano` 일 때만).
- 수치: 현무암 1/12 · 스팀 1/16 × 물 상성 · 사거리 6 · 3라운드 · 분출구 2~3 · 쾌청 30%.

## Review Focus
- 스팀에 밀린 지상 포켓몬이 용암에 들어감 → canEnter 로 둑에서 멈춤.
- 여러 포켓몬이 한 줄에 → 먼 쪽부터 밀어 서로 겹치지 않음.
- 스팀·열로 보스 기절 → knockOut + checkResult.
- 밀린 연출 중 다음 차례 시작 → 슬라이드가 끝난 뒤 진행.
- 마그마그를 용암에 놓았는데 갇힘 → 육지와 맞닿은 용암 칸만.
