# 날씨 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 층마다 확률로 정해지는 날씨(비·쾌청·모래바람·싸라기눈·안개)를 규칙·AI·화면에 넣는다.

**Architecture:** 순수 모듈 `src/core/weather.js` + 던전 확률표. 데미지·명중 함수는 `weather` 인자(기본 null)를 받고, 전투 상태 `state.weather` 를 넘긴다. 안개 흐림은 화면·AI 쪽 판정 함수.

**Tech Stack:** vanilla ES modules, Canvas 2D, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-14-weather-design.md`

## Global Constraints
- 날씨 id: `rain | sun | sand | hail | fog`, 없음은 `null`. 한 층 하나, 층 고정.
- 확률: 들판 rain 0.15 · sun 0.10, 동굴 fog 0.15. sand·hail 은 규칙만.
- 배율: rain 물 ×1.5 불꽃 ×0.5 / sun 불꽃 ×1.5 물 ×0.5 / sand 바위 타입 특방(특수 기술 방어) ×1.5.
- 명중: rain thunder 최종 100 / sun thunder 기본 명중 50 / hail blizzard 최종 100 / fog 모든 기술 −10 (최종 0~100).
- 페이즈 끝: sand 바위·땅·강철 외, hail 얼음 외 maxHp/16 (최소 1). 기절 보상 = 상태이상 피해와 같음.
- sun: 얼음 상태 걸리지 않음, 얼어 있던 유닛은 그 편 페이즈 시작에 녹음.
- 안개 흐림: 아군 어느 유닛과도 맨해튼 ≥ 5 인 적 (실시간). 적 AI 는 적 차례 시작 때 정한 "적 모두에게서 ≥5 인 아군" 을 공격·위협 대상에서 뺌.
- 날씨 굴림은 층 시드에서 **별도 난수** — 기존 시드의 지형·적·상자 불변.
