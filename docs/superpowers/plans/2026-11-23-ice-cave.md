# 얼음동굴 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (native). Steps use checkbox (`- [ ]`) syntax.

**Goal:** 8-1 얼음동굴 (빙판 미끄럼·부딪힘·고드름) + 얼음 타입 물 얼리기.
**Architecture:** 미끄럼은 `pathfind.search` 안에서 (빙판 걸음 = 미끄러진 끝 칸 하나). 부딪힘·고드름·물 얼리기는 `battle.moveUnit` 이 경로를 보고 처리해 `state.log.iceEvents` 로 남김. 화면은 states 의 walk 끝에서 이벤트를 슬라이드·알림으로.
**Spec:** `docs/superpowers/specs/2026-11-23-ice-cave-design.md`

## Global Constraints
- 빙판 `_` · 고드름 `Y`. 미끄럼 대상 = 지상(떠 있지 않음) && 얼음 타입 아님. 고드름 피해 = floor(maxHp/8) (최소 1), 얼음 타입 면역.
- 밀기 면역 = 보스·뿌리박기·흡반 (pushAway 와 같게). 연쇄 없음, 밀린 쪽은 1칸만.
- 다른 던전 골든·난수 소비 불변 (iceLayout 은 별도 난수 7500, 맨 끝).

## Review Focus
1. 미끄러진 경로의 이동 비용 (치고 빠지기 남은 이동력) — 미끄럼 칸은 공짜.
2. 안개·숨은 적에 부딪힐 때 (보이지 않는 유닛은 길찾기에 없음).
3. 밀물 칸 얼린 뒤 물때 복귀.
4. 모으기 돌진·봇·AI 이동도 같은 미끄럼/부딪힘.
5. 층 검증: 스쳐 지나가는 칸은 도달로 치지 않음.

- [ ] 테스트: 바닥에서 멈춤 / 막히면 빙판에서 / 물 앞 / 지나가는 칸 못 멈춤 / 비용 1 / 얼음 타입·떠 있음 자유 / 유닛 앞 멈춤·뒤가 비면 그 칸 / 밀기 면역 / pathTo 지나간 칸 포함 / pathCost.
- [ ] 구현 → 통과 → 커밋.

### Task 3: 부딪힘·고드름·물 얼리기 (`battle.moveUnit`, `core/ice.js`, ai)
