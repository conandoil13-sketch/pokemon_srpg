# ???시티 Implementation Plan

> Native execution (사용자 기본). Steps use checkbox (`- [ ]`) syntax.

**Goal:** 시련 3번 자리를 대체하는 5번째 맵 ???시티 — 옥상 높이, 워프 타일, 쓰레기통.
**Architecture:** 칸 `B` = 건물(옥상). 이동 규칙은 `pathfind.search` 에 "어느 칸에서 들어오나"를 더해 처리, 높이 명중은 `hitChance` 의 `ctx.atkTile`. 워프는 `src/core/warp.js` (순수) + `state.warps`. 층 생성은 `dungeon.city` 일 때만 별도 난수 단계.
**Tech Stack:** vanilla JS, node:test.
**Spec:** `docs/superpowers/specs/2026-11-22-city-design.md`

## Global Constraints
- 이름 `???시티`, id `city`, theme `city`, 자리 3 (`fillerStage(3)` 곡선), 저장 이전 `trial-3` → `city`.
- 명중: 옥상→지상 +10, 지상→옥상 −10. 비행·드래곤 도로→옥상 비용 2, 옥상 멈춤 가능. 중력 비행 불가.
- 워프 70%, 2색 × 2쌍, 도로↔옥상 쌍 ≥1 (옥상 있으면), 끝에서만, 짝 점유면 안 탐, 비행(드래곤 아님) 불가, 적 안 씀.
- 다른 던전 생성 결과·골든 해시 불변 (city 단계는 별도 난수).

## Review Focus
- 넉백·끌어당기기·순간이동으로 지상 포켓몬이 옥상에 올라가지 않아야 함 → `canEnter('B', 지상)` false.
- 옥상 위 적 AI 가 내려오고 다시 못 오름 (reachable 그대로).
- 치고 빠지기·되돌리기(취소)와 워프: 워프 뒤 이동 취소 불가(moveLocked).
- 워프 도착 칸에 상자가 있으면 연다(기존 상자 열기 경로와 같게) — 상자는 워프 칸에 안 놓음으로 회피.
- 안개·악 숨기 중 워프 — 아군만 쓰므로 영향 없음.
