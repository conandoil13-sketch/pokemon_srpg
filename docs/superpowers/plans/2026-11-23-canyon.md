## Review Focus
1. 중력·특성 잃음 등으로 낭떠러지 위에서 뜨지 못하게 된 포켓몬 → 떨어져야 함 (`chasmFalls`).
2. 고지 위에서 밀린 지상 포켓몬: 고지끼리·고지→저지는 밀림, 저지→고지는 막힘.
3. 덩굴 오르기 후 치고 빠지기(남은 이동력)·AI 이동이 오르기 규칙을 지킴.
4. 낙사로 보스/마지막 적이 쓰러지면 승리 판정, 아군 마지막 포켓몬이면 패배.
5. 다른 던전 지도·난수 그대로 (H·|·X 는 협곡에만).

### Task 1: 데이터·자리·저장 이전
- Create `src/data/canyon.js` (`CANYON`, `canyon: true`, types `['flying','dragon','rock','psychic','grass']`, minor `['rock','psychic','grass']`, bossTypes `['flying','dragon']`, fallback `'swablu'` 등 비행 종).
- `dungeons.js` 슬롯, `save.js` RENAMED `'trial-7': 'canyon'`. 기존 테스트의 `trial-7` 기대값 갱신.
- Test `tests/canyon.test.js`: 자리·해금·곡선·타입 비율(비행+드래곤 우세, 드래곤 ≥ 20%)·저장 이전.

### Task 2: 길찾기·명중
- `pathfind`: `TILE_COST` H 1, `|` 1, X 1. `canEnter('H')` = soars, `canEnter('X')` = floats || 드래곤(중력 아님). `search`: H→H 1 (누구나), 저지→H = soars 2 / 지상은 `|` 에서 시작한 첫걸음만 (비용 = 이동력 전부), H→저지 1. `pathCost` 맞춤.
- `damage.hitChance`: 높은 칸 = `B` 또는 `H`.
- Tests: 고지 걷기·뛰어내리기·비행 2·덩굴 오르기(시작해야만, 이동 끝)·지상 낭떠러지 불가·비행 멈춤 가능·명중 ±10.

### Task 3: 낙사
- `battle.pushAway`: 다음 칸이 X 이고 못 들어가면 그 칸까지 밀려 떨어짐 → `knockOut(state, t, a)`, `out.pushed.fell = true`. H 위에서 밀리면 H 칸도 들어감.
- `battle.chasmFalls(state)`: X 위인데 못 있는 포켓몬 → 떨어짐 (기술 뒤·페이즈 끝). 이벤트 `state.log.falls`.
- `export pushPreview(state, a, t)` → `{ to, fall }`. states: 변화기 예상 창 "낙사!", 알림 "…은/는 낭떠러지로 떨어졌다!".
- Tests: 낙사 = 기절·경험치·격파 기록, 보스 안 밀림, 뜨는 포켓몬은 X 위에 멈춤, 중력 → 떨어짐, 미리보기.

### Task 4: 층 생성 `canyonLayout`
- 능선(위 1/3, 열마다 ±1), 능선 위 바위, 아래 개울 + 물가 나무·풀숲, 틈 2~3 + 구덩이 0~1, 덩굴 2~4. 지상 걷기(덩굴 포함) 검증, 최대 20번.
- 검증용 walker 는 search 로 (덩굴 오르기 = 여러 차례에 걸쳐 가능 → 도달 판정은 "차례를 이어 가며" — 덩굴 칸에서 다시 시작하는 BFS).
- Tests: 결정적, 출발 3열 깨끗, 계단·상자 도달, 적이 X 위에 없음(뜨는 적 제외), 덩굴 위 칸이 H, 다른 던전 불변.
