# X 메뉴 + 가방 화면 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 마을에서 X(키보드 C)로 작은 메뉴를 열고, 가방 화면에서 종류별로 보고 지니는 도구를 출전 포켓몬에게 바로 지니게·빼게 한다.

**Architecture:** 새 게임 이벤트 `{ type: 'menu' }` 를 입력(키보드 C, 터치 X)에 더한다. 마을 장면이 이 이벤트로 자기 안에 작은 선택 메뉴(가방·닫기)를 띄우고, "가방"은 `onBag({ x, y, facing })` 로 main 에 알린다. main 의 `go.bag(spot)` 이 `createBag` 장면을 열고, 닫으면 `go.town(null, spot)` 으로 같은 자리로 돌아온다.

**Tech Stack:** 바닐라 JS ES 모듈, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-17-bag-menu-design.md`

## Global Constraints
- 키보드 `c`/`C` → `menu`, 터치 `data-k="x"` 버튼(A·B 근처, 라벨 "X") → `menu`. 키보드 X 는 계속 취소.
- X 메뉴는 마을에서만. 다른 장면은 `menu` 를 무시(처리 안 해도 깨지지 않음).
- 가방 탭 3개: `도구` / `진화·뽑기` (진화의돌 `items.evoStone`, 10연속 뽑기 바우처 `items.tenVoucher`) / `메타몽` (파우더 6종 `items.powders`, 캡슐 `items.capsules` 개수). 비면 "아무것도 없다".
- 도구 탭: 맨 위에 출전 포켓몬이 지닌 도구 줄들("○○: 도구이름", 고르면 빼기), 그 아래 가방 도구("이름 ×n", 고르면 출전 포켓몬 목록 → 지니기/바꾸기). 기존 `equip`/`unequip` 사용, 바뀌면 `onSave()`.
- 출전 포켓몬 = 지금 출전 편성 (`deployed(game)` 과 같은 목록: 메타몽 + 출전 4).
- 브랜치 `feat/bag-menu`. 테스트 `npm test`. 저장 `pokemon-tactics-save` 백업·복원.

## Review Focus
1. 마을에서 메시지 창이 떠 있을 때 X → 메뉴가 열리지 않음 (메시지 먼저) → Task 1 테스트.
2. 걷는 중(경로 이동) X → 걸음을 멈추고 메뉴, 돌아오면 같은 칸·방향 → Task 1 테스트.
3. 가방 도구가 마지막 하나일 때 지니면 목록에서 그 줄이 사라지고 커서가 범위 밖으로 가지 않음 → Task 2 테스트.
4. 출전 포켓몬이 없는(메타몽만) 경우 도구 → 목록에 메타몽만 → Task 2 테스트.
5. 탭을 바꾸면 커서가 0 으로, 빈 탭에서 확인해도 아무 일 없음 → Task 2 테스트.
