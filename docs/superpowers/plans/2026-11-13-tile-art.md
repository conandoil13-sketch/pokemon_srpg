# 맵 타일 다시 그리기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 맵 타일을 4~5세대 DS 필드풍으로 코드로 다시 그리고, 물·풀숲·나무·암벽에 4분할 오토타일을 넣는다.

**Architecture:** 순수 모듈 `src/render/autotile.js` 가 조각 모양을 고르고, `src/render/tiles.js` 가 테마별 조각 그림을 캐시해 그린다. `drawMap` 시그니처는 그대로.

**Tech Stack:** vanilla ES modules, Canvas 2D, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-13-tile-art-design.md`

## Global Constraints
- 타일 24px, 조각 12px. 그림 파일·외부 타일셋 금지. 원작 타일 모방 금지(느낌만).
- `drawMap(ctx, grid, time, camX, camY, viewW, viewH, theme)` 시그니처·타일 기호·게임 규칙 불변.
- 빛은 위 왼쪽, 그림자 아래 오른쪽. 외곽선은 각 재질의 가장 어두운 색.

## Review Focus
1. 맵 가장자리 칸의 경계 — 맵 밖은 "같은 종류"로 취급해 가장자리에 테두리가 생기지 않음. → Task 1 test.
2. 한 칸짜리 물·숲(고립) — 네 모서리가 둥근 바깥 모서리. → Task 1 test.
3. 대각선으로만 닿은 물 — 안쪽 모서리 조각. → Task 1 test.
4. 동굴 테마에서 나무가 아니라 암벽 조각 — 테마별 그림. → Task 2 브라우저 확인.
5. 그리기 성능 — 화면 칸 약 11×9 × 조각 4 = 400 drawImage, 프레임당 1ms 이하 유지(캐시). → Task 2 브라우저 측정.

### Task 1: 오토타일 조각 고르기 (순수)

**Files:** Create `src/render/autotile.js`, `tests/autotile.test.js`

**Interfaces — Produces:** `QUAD = { INNER: 0, EDGE_H: 1, EDGE_V: 2, OUTER: 3, CORNER_IN: 4 }`; `quadrants(grid, x, y, same: (ch) => boolean) => [tl, tr, bl, br]` 각 값 `QUAD.*`. 조각 규칙(예: 왼쪽 위): 가로 이웃(왼쪽) h, 세로 이웃(위) v, 대각(왼쪽 위) d — `!h && !v → OUTER`, `h && !v → EDGE_H`(위가 테두리), `!h && v → EDGE_V`, `h && v && !d → CORNER_IN`, 그 외 `INNER`. 맵 밖은 same 으로 취급.

- [ ] **Step 1: tests** — 고립 물 한 칸 → `[3,3,3,3]`; `~~~` 가운데 칸 → 위 둘 EDGE_H, 아래 둘 EDGE_H(아래가 테두리); 2×2 물 블록의 왼쪽 위 칸 → tl OUTER, tr EDGE_H, bl EDGE_V, br INNER; ㄱ자 물에서 안쪽 모서리 → CORNER_IN; 맵 가장자리 칸 물 → 맵 밖 방향은 테두리 없음
