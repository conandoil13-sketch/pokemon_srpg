# 돌진 이펙트 Implementation Plan

**Goal:** 돌진기(`DASH`)에 타입 팔레트 돌진 이펙트 — 출발 먼지 · 속도선 꼬리 · 도착 섬광, 붙어 있으면 짧은 런지, 돌아오기는 옅은 꼬리.
**Spec:** docs/superpowers/specs/2026-11-24-dash-fx-design.md

## Task 1: 이펙트 `pokemon/dash-trail` (src/fx-custom/pokemon/dash-trail.js, 등록 src/fx-custom/index.js)
- 원점 = 출발 칸 발밑, 오른쪽. 옵션: `palette`(5+), `reach`(px, 머리가 가는 거리), `travel`(초, 머리가 reach 에 닿는 시간), `faint`(돌아오기: 꼬리만 옅게), `height`(몸 높이 14), `light`.
- 테스트 (tests/fx.test.js): 4방향 · reach 8/16/48 · faint 에서 그려지고 실패 0, 끝나면 비어 있음.

## Task 2: 고르기 (src/data/moveFx.js)
- `DASH` 기술이면 `out.dash = spec('pokemon/dash-trail', { palette: pal(type), light })`. 다른 기술엔 없음. 덮어쓰기 표(moveFx.json)로 끌 수 있음 (`dash: null`).
- 테스트: 플레어드라이브 dash 팔레트 = 불꽃, 악·독 돌진기 없음 → 브레이브버드(비행)·볼트체인지(전기); 몸통박치기엔 dash 없음.

## Task 3: 연출 (src/render/mapAttack.js `enter`)
- 'dash' 단계: `dashed.from` 발밑, 방향 = 대상 쪽, reach = 칸 수 × 16, travel = 그 단계 길이.
- 'act' 단계 + 대시 없음: 런지 (reach 8, travel 0.12).
- 'back' 단계: `returned.from` 발밑, 반대 방향, faint.
- 확인: 브라우저에서 불꽃·물·전기·비행 돌진기 스크린샷.
