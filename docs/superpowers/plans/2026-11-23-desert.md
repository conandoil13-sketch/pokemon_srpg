# 사막 (7-2) Implementation Plan

**Goal:** 7단계 두 번째 분기 사막 — 깊은 모래(비용 2·회피 +15)·흐르는 모래(행동 끝 1칸 밀림)·모래지옥(행동 끝 가운데로 끌림, 탈출은 이동력 전부), 모래바람 60%, 중후한 황토 그림.
**Architecture:** 지형 문자 `:` `=` `o` `@` + 순수 모듈 `src/core/sand.js` (`sandShift(state, unit)` 를 행동이 끝날 때 한 번 — battle 의 행동 종료 지점). 배치는 floorgen `desertLayout`(별도 난수 `hashSeed(seed, 7200)`, `dungeon.desert` 일 때만), 층 결과 `flows`. 그림 `src/render/desertTiles.js`.
**Spec:** docs/superpowers/specs/2026-11-23-desert-design.md

## Global Constraints
- 다른 던전의 층 생성·난수 소비 불변 (골든 테스트).
- 수치: `:` 진입 2 · 회피 +15 / `=` 띠 3~6칸, 층당 2~3줄 / 지옥 3×3, 층당 1 (넓은 맵 2) / 모래바람 60% / 떠 있음(비행·부유)·숨기 중 전부 무시.
- 저장 이전 `trial-5` → `desert`.

## Review Focus
- 밀림·끌림 목적지가 다른 유닛·벽·바위·맵 밖 → 제자리 (연쇄 없음).
- 지옥 가운데에서 탈출한 턴엔 바깥 칸에 서도 다시 안 끌림.
- 밀려서 압정·워프·발전기 같은 다른 규칙 칸에 들어가지 않음 (사막엔 없지만 canEnter 사용).
- 강제 이동 후 기억·장판 갱신 (refreshField).
- 출발 구역·계단 칸에 지형이 덮이지 않음, 연결성 유지.
