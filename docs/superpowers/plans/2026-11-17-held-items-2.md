# 지니는 도구 2차 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 도구 11개 id(10종)를 1차와 같은 방식으로 넣고, 선제공격손톱 보너스 행동을 화면 흐름에 붙인다.

**Architecture:** `heldItems.js` 표에 효과 필드·가격, `items.js` 판정 함수, 기존 계산 자리 훅. 선제공격손톱은 스피드 보너스 옆에 `quickClawUnit(state, side, rng)` + `state.quickGiven`.

**Tech Stack:** 바닐라 JS ES 모듈, `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-17-held-items-2-design.md`

## Global Constraints
- id: `kings-rock`, `razor-fang` (flinch 0.1), `big-root` (healMult 1.3), `metronome` (streak +0.2, 최대 2), `zoom-lens` (still acc 1.2), `choice-scarf` (choice 'any', speedMult 1.5, move +1), `iron-ball` (speedMult 0.5, move −1, grounded), `smoke-ball` (escape), `quick-claw` (0.2), `lucky-egg` (exp 1.5), `amulet-coin` (coins 2). 가격 600/600/300/600/300/600/150/150/600/1200/1200.
- 풀죽음: 기존 풀죽음 판정 자리에서 `flinchChance = max(기술, 도구)` 가 아니라 기술 풀죽음이 없을 때만 도구 10%.
- 메트로놈: `u.metroMove`·`u.metroStreak` (전투 유닛 — 층마다 새로). 위력 ×min(2, 1 + 0.2·streak), streak 은 같은 기술 연속 사용 수 − 1.
- 줌렌즈: 이번 차례에 이동하지 않았을 때(`!u.walked` — 이동 확정 때 true, 차례 시작에 false).
- 구애스카프: `choice: 'any'` (물리·특수 배수 없음, 고정만). 스피드는 `effectiveStat` 의 'spe' 에 곱함 (스피드 보너스 비교·표시에 반영).
- 검은철구: `refreshField` 가 `grounded` 를 `!!state.gravity || 철구` 로. `moveBudget` 에 −1 (최소 1).
- 연기구슬: `moveBudget` 의 도주 판정에 연기구슬 추가.
- 선제공격손톱: 페이즈 끝, 스피드 보너스 처리 다음에 굴림. 지닌 살아 있는 유닛 목록 순서대로 각 20%, 처음 맞은 하나. 페이즈마다 1번 (`quickGiven`, endPhase 에서 false). 잠듦·얼음이면 건너뜀.
- 행복의알: `awardExp` 결과에서 지닌 유닛 몫 ×1.5 (내림).
- 부적금화: 출전 유닛 중 지닌 게 있으면 `log.coins`(전투) ×2, 층 돌파 코인 ×2 — main 의 `addBattleCoins`/`addFloorCoins` 호출 자리에서.
- 브랜치 `feat/held-items-2`. 테스트 `npm test`. 저장 백업·복원.

## Review Focus
1. 구애스카프 고정이 기존 구애 계열 고정과 같은 규칙(층 첫 기술) → Task 1 테스트.
2. 검은철구 + 중력 끝남 → 철구 유닛은 계속 땅에 붙어 있음 → Task 1 테스트.
3. 선제공격손톱과 스피드 보너스가 같은 페이즈에 둘 다 나와도 각각 한 번 → Task 2 테스트.
4. 메트로놈: 막힌 기술(도발 등)로 실패하면 streak 유지? → 실패는 사용으로 치지 않음 → Task 1 테스트.
5. 부적금화 지닌 포켓몬이 그 층에서 기절해도 2배 유지 (출전 기준) → Task 2 테스트.
