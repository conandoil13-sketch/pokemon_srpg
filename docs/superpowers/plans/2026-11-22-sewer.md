# 하수도 Implementation Plan

> Native execution (사용자 기본). Steps use checkbox (`- [ ]`) syntax.

**Goal:** 6단계 분기 `[하수도, 시련의 동굴 Ⅱ]` — 하수도 = 독 웅덩이(`%`) + 직선 통로 층 + 새 그림.
**Architecture:** 웅덩이 피해는 순수 함수 `src/core/pool.js` `poolDamage(unit, tile)` → battle 페이즈 끝(날씨 피해 다음)과 AI 위험도에서 씀. 층은 `dungeon.sewer` 일 때 연결성 단계 전에 별도 난수로 벽·통로를 깔기. 그림 `src/render/sewerTiles.js`.
**Spec:** `docs/superpowers/specs/2026-11-22-sewer-design.md`

## Global Constraints
- id `sewer`, theme `sewer`, 자리 4 = `[SEWER, fillerStage(4)]` (trial-4 id 유지, 저장 이전 없음).
- 피해: 1/8 (최소 1), 강철 1/16, 독 면역(복합 포함), `airborne` 면역, 매직가드 면역. 지나가기만 하면 없음.
- 다른 던전 생성 결과·골든 해시 불변.

## Review Focus
- 독 웅덩이 위 기절 → knockOut 경로(경험치·로그) 다른 페이즈 끝 피해와 같게.
- 넉백·끌어당기기로 독에 올라간 유닛도 페이즈 끝에 피해 (칸만 봄).
- 적 AI 가 독 위에서 공격 이득이 크면 서도 됨 — 위험도에 더할 뿐 금지 아님.
- 땅굴(burrow)·공중(fly 2턴기) 중인 유닛은? `airborne` 만 면역 — 2턴 공중 상태는 지금 날씨 피해 규칙 따라감.
