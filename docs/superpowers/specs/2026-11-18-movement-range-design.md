# 이동력 구간 넓히기 + 후반 맵 넓히기 + 메타몽 이동력 — 짧은 설계

- 작성일: 2026-11-18 · 상태: 사용자 승인 대기

## 목적
종족값 스피드(5~160)가 이동력 3~6 네 칸에 뭉개져 아주 빠르거나 느린 포켓몬의 개성이 안 드러난다. 구간을 넓히고, 빠른 포켓몬(130+, 대개 최종 진화·전설급)이 많아지는 후반 맵은 넓혀서 균형을 맞춘다. 메타몽 이동력이 빌드를 무시하는 문제도 고친다.

## 사용자 결정
- 이동력 = 종족값 스피드 **20 단위 구간, 2~8**.
- 130 이상(8)은 보통 최종 진화·전설급 → **그 레벨 구간의 맵부터 넓힌다**.

## 접근
- **A. 구간표 + 던전별 맵 크기 (선택):** `movementFor` 구간표 교체, 던전 데이터에 `size: [W, H]` (없으면 16×12), 층 생성기가 그 크기를 쓴다.
- B. 이동력은 그대로 두고 스피드 랭크만 반영: 사용자 결정(구간 넓히기)과 달라 버림.

## 설계 *(내 결정 표시)*
- **구간:** 30 미만 2 · 30~49 3 · 50~69 4 · 70~89 5 · 90~109 6 · 110~129 7 · 130 이상 8. 비행 +1 유지, 최대 **8**. (종 수: 2=31, 3=111, 4=130, 5=107, 6=82, 7=25, 8=7)
- **메타몽:** 이동력을 빌드 기준으로 — 스피드 = 빌드의 종족값 스피드(파우더 반영), 비행 +1 = 빌드 타입에 비행이 있으면. 지금 48 → 3, 파우더로 70 넘기면 5.
- **맵 크기** *(구간 경계는 내 결정)*: 던전 시작 레벨 기준 — 40 미만 **16×12**(지금) · 40~59 **18×13** · 60 이상 **20×14**. 지금 표로는 신오 2개·단풍 숲(23)·시련 2~3(30·37) = 16×12, 시련 4~6(44·51·58) = 18×13, 시련 7~8(65·72) = 20×14.
- 넓은 맵: 지형 덩어리 수·상자 수는 면적 비례로 조금 늘림 *(내 결정: 덩어리 ×면적비 반올림, 상자는 그대로 0~2)*. 적 수·위협도 예산은 그대로(곡선 유지).
- 나머지 이동 보정(특성·순풍·도구·마비·묶기)은 그대로 새 기본값 위에.

## 비목표
스피드 랭크의 이동력 반영, 스피드 보너스 규칙 변경, 마을 크기.

## 확인
- 테스트: 구간표 경계(29/30, 129/130, 비행 +1·최대 8) / 메타몽 빌드 스피드·비행 타입 반영 / 던전별 맵 크기, 신오 골든 해시 그대로 / 넓은 맵도 연결성·적·보스·계단 생성 / 이동 범위가 맵 밖으로 안 나감.
- 브라우저: 시련 6 층 하나 들어가 넓은 맵·카메라 스크롤 확인 (저장 백업·복원).
