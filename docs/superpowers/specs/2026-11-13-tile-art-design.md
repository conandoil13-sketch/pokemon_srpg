# 맵 타일 다시 그리기 — 설계 (짧은 문서)

- 작성일: 2026-11-13 · 상태: 확정 (사용자 "좋아, 진행")

## 왜
물·땅·나무·바위 타일이 PMD 스프라이트·pixelfx 이펙트보다 디테일이 떨어져 화면이 거칠다.

## 결정 (사용자)
- **코드로 직접 다시 그린다** (그림 파일·외부 타일셋 없음, 원작 타일 사용 안 함).
- 목표 느낌: **4~5세대 DS 필드풍** — 밝고 또렷한 색, 확실한 외곽선, 모래 물가·풀숲 테두리. 느낌만 참고, 원작 타일을 베끼지 않는다.

## 범위
- 들판·동굴 두 테마, 마을·타이틀(같은 `drawMap`).
- 타일 기호는 그대로: `.` 땅/풀, `"` 긴 풀숲, `^` 바위·언덕, `~` 물, `#` 벽(들판=나무, 동굴=암벽), `>` 계단, 보물상자.
- 게임 규칙·맵 데이터는 바꾸지 않는다.

## 설계
- **자동 타일(오토타일)**: 물·긴 풀숲·나무(들판 벽)·암벽은 칸을 12×12 네 조각으로 나눠, 조각마다 이웃 3칸(가로·세로·대각)으로 모양을 고른다 — 안쪽 / 가로 테두리 / 세로 테두리 / 바깥 모서리 / 안쪽 모서리 (클래식 4분할 오토타일). 그래서 물가·숲 경계가 칸 경계에서 끊기지 않고 둥글게 이어진다.
- **풀밭**: 무늬 4종 + 가끔(약 1/8) 작은 꽃·돌멩이, 칸 좌표 해시로 고정.
- **물**: 깊이 2단(가장자리 밝게), 물가 쪽 모래 테두리 + 하얀 물거품 선, 반짝임 3프레임 애니메이션.
- **긴 풀숲**: 삐죽한 잎 덤불, 위 테두리에 잎 끝이 튀어나옴, 이어진 칸은 하나로.
- **나무**: 둥근 수관(위 왼쪽 빛, 아래 오른쪽 그림자, 진한 외곽선), 붙은 나무는 수관이 이어지는 숲, 가장자리 아래에 짧은 줄기·그림자.
- **바위·언덕**: 위 밝고 아래 어두운 입체 바위, 외곽선, 발밑 그림자.
- **계단·상자**: 같은 톤의 외곽선·빛 방향.
- **동굴**: 같은 구조에 돌바닥·암벽·어두운 물 색.
- 그린 조각은 테마별로 한 번 만들어 캐시 (지금처럼). 칸마다 조각 4개 `drawImage`.

## 테스트
- `autotile.test.js`: 조각 모양 고르기 — 고립된 물 한 칸(바깥 모서리 4), 가로로 긴 물(위아래 테두리), 안쪽 모서리(대각만 다름), 맵 가장자리는 같은 종류로 취급.
- 기존 테스트 전부 통과 (규칙 불변).
- 브라우저: 들판·동굴·마을 스크린샷을 보고 3번 이상 다듬기.

## 빌더 재량
색값, 무늬, 애니메이션 속도, 조각 그림 세부.
