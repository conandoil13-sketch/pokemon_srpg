# 기술 이펙트 다양화 — 짧은 설계 + 계획

- 작성일: 2026-11-15 · 상태: 사용자 승인 대기

## 목적
지금은 이펙트 종류가 적어(26개) 기술끼리 비슷해 보인다. 특히 붙어서 쓰는 기술(거리 1)은 물리든 특수든 "타격 반짝임" 하나라, 불꽃세례와 할퀴기가 같아 보인다.

## 사용자 결정
- **물리 근접기와 특수 근접기를 구분.** 특수 근접기는 파이어볼처럼 **날아가는 탄**이 있어야 한다.
- 이펙트 종류·특징을 늘린다. 특히 **새로 만든 뒤 팔레트 스왑**(타입 색)으로 여러 기술에 쓴다.
- 새로 만들 것: **물기(위아래 이빨) · 킥(발차기) · 소리 파동**.

## 설계
### 기술 분류 (기술 모양 계열)
`src/data/moveFamilies.js` 에 기술 id 목록으로 계열을 둔다(이미 철주먹·방음 특성용 `PUNCH`·`SOUND` 목록이 있으니 재사용·확장).
| 계열 | 예 | 근접(거리 1) 연출 |
|---|---|---|
| 물기 | 물기·깨물어부수기·불꽃/번개/얼음엄니·필살앞니 | **새 이펙트 bite** (타입 색) |
| 킥 | 두번치기·로킥·발분해·무릎차기·메가톤킥·트리플킥 | **새 이펙트 kick** |
| 펀치 | PUNCH 목록 | melee/uppercut (타입 색) |
| 베기·할퀴기 | 할퀴기·베어가르기·풀베기·시저크로스·칼날·리프블레이드 | melee/claw-swipe 또는 double-slash |
| 찌르기·뿔 | 쪼기·뿔찌르기·독침·회전부리·드릴부리 | melee/thrust |
| 소리 | SOUND 목록 | **새 이펙트 sound-wave** (거리 무관, 퍼짐) |
| 그 밖의 물리 | 몸통박치기 등 | 지금 그대로 (blunt-hit / hit-spark) |

### 특수 근접기 = 날아가는 탄 (타입별)
불꽃 fire/fireball · 물 water/water-orb · 전기 lightning/ball-lightning · 얼음 ice/ice-lance · 에스퍼·페어리 arcane/arcane-orb · 고스트·악 shadow/void-orb · 그 밖 projectiles/magic-missile(타입 색). 손에서 짧게 모았다가(cast) 옆 칸 대상까지 날아가(travel) 맞는다(hit). **원거리 특수 단일기도 같은 탄**으로 바꿔 거리와 상관없이 "특수 = 쏘는 기술".

### 덤
- 흡수기: shadow/life-steal (대상 → 사용자, 초록 계열) · 회복기: holy/heal · 헤롱헤롱: status/charmed (혼란 연출 대신).

### 새 이펙트 만들기 (pixelfx 방식)
- 작업은 pixelfx **작업용 복사본**(scratchpad)에서: 한 줄 설명 → 초안 2~3개 → 렌더해서 보기 → 3번 이상 다듬기 → `check.mjs` 통과. 사용자 pixelfx 폴더는 건드리지 않는다.
- 완성 파일은 게임 저장소 `src/fx-custom/pokemon/{bite,kick,sound-wave}.js` (core 경로만 바꿈). `render/fx.js` 가 vendor 이펙트와 합쳐 등록.
- 팔레트 옵션(`palette`) 필수 지원, 방향(flip/angle) 지원, 256×192 화면에서 칸(16px) 크기에 맞게.
- 특정 게임 그림·캐릭터를 따라 그리지 않는다(일반적인 이빨·발·음파 모양).

## 계획
1. **가져오기**: `tools/vendor-pixelfx.js` FX_FILES 에 탄 7개 + 타격 5개 + life-steal·heal·charmed 추가 → 실행 → 테스트(모든 사용 id 등록됨).
2. **새 이펙트 3개**: 작업용 복사본에서 만들기·다듬기(렌더 이미지 확인) → `src/fx-custom/` 로 옮겨 등록 → 테스트(팔레트 옵션·끝나면 비워짐).
3. **연결**: `moveFamilies.js` + `moveFx.js` rule 에 계열별 근접 연출·특수 탄·덤 → 테스트(할퀴기·물기·불꽃펀치·불꽃세례(근접)·하이퍼보이스가 서로 다른 이펙트 id).
4. **미리보기**: `tools/fx-preview.html` 에 "기술 고르기"(실제 기술 id) 추가 → 브라우저로 계열별 확인, 사용자에게 보여 주기.
5. 문서·리뷰.

## 테스트·확인
- 계열 분류(대표 기술), 근접 물리·특수가 다른 이펙트, 원거리 특수가 타입 탄, 새 이펙트 3개가 palette 를 받고 정해진 시간 안에 끝남(check.mjs 기준), 기존 테스트 통과, 브라우저 미리보기 육안 확인.

## 구현 중 바뀐 점 (렌더해 보고 결정)
- 펀치: melee/uppercut 은 사용자 몸 위로 크게 그려져 칸에 안 맞음 → `impacts/crit-hit`(별 모양 강타, 타입 색).
- 특수 탄: 물 구슬·마법 구슬·어둠 구슬·공 번개는 크기 옵션이 없거나 서서히 생겨 짧은 탄으로 안 보임 → 불꽃 파이어볼·얼음 얼음 창만 전용, 그 밖은 타입 색 플라스마탄.
- 효과 굉장일 때의 겹타: 이빨·발·별 같은 모양 이펙트(`noEcho`)는 반짝임으로 대신(두 번 물리지 않게). 펀치 급소 때 별 강타 중복 없음.
- 흡수: "체력을 흡수했다" 대사 때 사용자에게 생명 흡수(초록) 연출.
- 쓰지 않게 된 이펙트(어퍼컷·두 번 베기·망치·물 구슬 등)는 가져오기 목록에서 뺐다.
