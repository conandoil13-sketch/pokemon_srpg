# 특성 시스템 — 설계 스펙

- 작성일: 2026-11-14 · 상태: 확정 (사용자 "좋은데? 가보자")
- 선행: 랭크·상태이상·범위 모양·날씨·뽑기(결정)

## 1. 목표 · 이유
랭크·상태이상·날씨·범위·접촉 같은 시스템이 쌓여, 특성을 얹을 자리가 충분하다. 포켓몬마다 개성을 주고 결정(중복 뽑기)의 쓸모를 만든다.

### 사용자 결정
- **4세대까지 기준**. 단순 변환이 되는 특성은 그대로, 어려운 특성은 사용자 밸런싱(§4-③, 확정).
- 특성이 둘인 종: **합류할 때 무작위로 고정**, **같은 계열 결정으로 다른 특성으로 바꿈**. 적은 등장할 때마다 무작위.
- **숨겨진 특성(5세대~) 제외**. 나중 세대에 바뀐 특성은 4세대 특성으로(PokeAPI `past_abilities`; gen ≥ 5 특성은 버림).

### 성공 기준
1. 모든 종이 4세대 특성 목록(1~2개)을 갖고, 동료·적 유닛이 그중 하나를 가진다. 저장·이어하기에서 유지.
2. §4-① 특성이 본가대로, §4-③ 특성이 확정된 SRPG 규칙대로 동작한다. §4-② 는 "효과 없음"(정보창에 이름·설명은 보임).
3. 정보창·편성소에 특성 이름과 설명, 발동 시 짧은 대사·팝업.
4. 편성소에서 결정 3개로 다른 특성으로 바꿀 수 있다 (특성이 하나뿐인 종은 불가).
5. 적 AI 의 기대 데미지에 데미지 관련 특성(타입 강화·면역·흡수 등)이 반영된다.
6. `npm test` 통과, 대표 특성 화면 확인.

### 범위 밖 · 안티 목표
- 숨겨진 특성, 특성 바꾸는 기술(스킬스왑 등), 도구·교체·PP·성별·풀죽음·반동·연속기·야생 조우와 엮인 효과(§4-②).
- **안티 목표**: 특성이 숨어서 판단할 수 없으면 실패 (정보창에 항상 표시, 발동 시 알림). 한 특성이 판을 깨면 실패 (불가사의부적·천하장사 등은 적으로 나올 수 있는 층·레벨을 확인).

## 2. 데이터
- `tools/fetch-pokeapi.js` 가 종마다 `abilities: [id…]`(슬롯 순서, 숨겨진 것 제외, 4세대 기준), 특성마다 `{ id, name(ko), desc(ko short) }` 를 `pokedex.js` 에 추가. 한국어 설명이 없으면 영어 짧은 설명을 사람이 번역한 표(`src/data/abilityText.js`)로 덮음 — 최소한 §4-③ 은 게임 규칙에 맞게 직접 쓴 설명.
- 멤버 `{ …, ability }`. 저장 **v5**: v4 → v5 마이그레이션에서 기존 멤버에 무작위(시드 고정: 종+레벨 해시) 특성 배정. `cleanMember` 는 그 종의 특성 목록에 없으면 첫 번째로.
- 유닛 `unit.ability` (멤버에서 / 적은 `makeUnit` 이 rng 로).
- 결정으로 바꾸기: 편성소 메뉴 "특성 바꾸기 (결정 3)" — 계열 뿌리(lineRoot) 결정을 3 소모, 다른 특성으로 (둘 중 다른 하나). 진화하면 특성 슬롯 유지(본가처럼 같은 슬롯).

## 3. 구조
- `src/core/abilities.js` (순수): 특성별 **훅** 표. 전투 코드가 정해진 시점에 훅을 부른다.
  - `modifyDamage(ctx)` — 공격 측·방어 측 배율 (타입 강화, 천하장사, 두꺼운지방, 필터 …)
  - `immune(ctx)` — 공격 무효/흡수 결과 `{ blocked, heal?, boost? }` (축전, 부유, 불가사의부적 …)
  - `modifyAccuracy`, `modifyCrit`, `modifyStageChange`(클리어바디·단순·천진), `blocksAilment`(면역류)
  - `onContact(attacker, defender, rng)` — 접촉(= 인접 칸에서 쓴 물리기) 반격(정전기·까칠한피부 …)
  - `onPhaseEnd`, `onPhaseStart` — 가속·탈피·젖은접시·건조피부·게으름·슬로스타트 …
  - `onArrive(unit)` — 이동을 마쳤을 때(위협)
  - `onFloorStart(state)` — 날씨 특성·트레이스·다운로드
  - `speedMult(unit, weather)` — 쓱쓱·엽록소·속보
- 데미지·명중·상태이상·랭크·페이즈 처리에 훅 호출 지점을 하나씩 넣는다 (`damage.js`, `status.js`, `stages.js`, `battle.js`). AI 는 같은 데미지 함수를 쓰므로 자동 반영.
- 발동 알림: `state.log.abilityEvents = [{ unitId, ability, text }]` → 연출·대사 "○○의 위협!" 등.

## 4. 특성 분류 (확정)

### ① 그대로 반영
타입 강화(심록·맹화·급류·벌레의알림: HP 1/3 이하 해당 타입 ×1.5) · 적응력(STAB 2) · 테크니션(위력 60 이하 ×1.5) · 색안경(효과 별로 ×2) · 노말스킨 · 배짱 · 틀깨기 · 축전/저수(무효+HP 1/4 회복) · 전기엔진(무효+스피드+1) · 타오르는불꽃(불꽃 무효, 이후 불꽃 ×1.5) · 부유(땅 무효) · 불가사의부적(효과 굉장만 맞음) · 면역/불면/의기양양/유연/마그마의무장/수의베일/마이페이스(해당 상태 면역) · 클리어바디/하얀연기(랭크 하락 무효) · 괴력집게(공격 하락 무효) · 날카로운눈(명중 하락 무효) · 단순(랭크 변화 2배) · 천진(상대 랭크 무시) · 가속(차례 끝 스피드+1) · 두꺼운지방(불꽃·얼음 절반) · 내열(불꽃 절반, 화상 피해 절반) · 필터/하드록(효과 굉장 ×0.75) · 천하장사/순수한힘(공격 2배) · 근성(상태이상 시 공격 1.5배, 화상 감소 무시) · 이상한비늘(상태이상 시 방어 1.5배) · 의욕(물리 1.5배, 물리 명중 0.8배) · 속보(상태이상 시 스피드 1.5배, 마비 감소 무시) · 전투무장/조가비갑옷(급소 안 맞음) · 대운(급소율 1/8) · 스나이퍼(급소 배율 2.25) · 분노의경혈(급소 맞으면 공격 +6) · 쓱쓱/엽록소(비/쾌청 스피드 2배) · 모래숨기/눈숨기(모래바람/싸라기눈 피해 면역 + 명중 −20%p) · 젖은접시/아이스바디(비/싸라기눈 차례 끝 1/16 회복, 아이스바디는 싸라기눈 면역) · 건조피부(물 무효 1/4 회복, 비 1/8 회복, 쾌청 1/8 피해, 불꽃 1.25배) · 촉촉바디(비에 차례 끝 상태이상 회복) · 선파워(쾌청에 특공 1.5배, 차례 끝 1/8 피해) · 리프가드(쾌청에 상태이상 면역) · 에어록/날씨부정(출전 중 날씨 효과 없음) · 기분파(날씨에 따라 타입 변화) · 복안(명중 1.3배) · 노가드(이 유닛이 쓰거나 맞는 기술 반드시 명중) · 하늘의은총(부가효과 확률 2배) · 인분(받는 부가효과 무효) · 탈피(차례 끝 1/3 상태이상 회복) · 포이즌힐(독이면 차례 끝 1/8 회복) · 매직가드(기술 외 피해 무효: 상태·날씨·자해·반격) · 습기(주변 2칸 안 자폭·대폭발 불발, 유폭 무효) · 변색(맞은 기술 타입으로 바뀜) · 갈지자걸음(혼란 시 회피 +20%p) · 일찍기상(잠듦 턴 절반) · 접촉 반격 — 정전기(30% 마비)·독가시(30% 독)·불꽃몸(30% 화상)·포자(30% 마비/독/잠듦)·까칠한피부(공격자 1/8)·유폭(접촉으로 기절 시 공격자 1/4).
- **접촉** = 인접 칸(거리 1)에서 쓴 물리 기술 (내 결정: 데이터에 접촉 표시가 없음).
- 철주먹(펀치 기술 1.2배)·방음(소리 기술 무효)은 기술 이름 목록으로.

### ② 지금은 효과 없음 (이름·설명만)
먹보·서투름·점착·곡예·통찰·멀티타입(도구) · 도주·흡반·자연회복(교체·도주) · 프레셔(PP) · 투쟁심·헤롱헤롱바디·둔감(성별·헤롱헤롱) · 정신력·불굴의마음·악취(풀죽음) · 돌머리·이판사판·스킬링크(반동·연속기) · 발광(조우) · 해감액(흡수 기술 생기면). 시스템이 생기면 다시 연결.

### ③ SRPG 재해석 (사용자 확정)
| 특성 | 규칙 |
|---|---|
| 위협 | **이 유닛이 이동을 마쳤을 때 인접한 적의 공격 −1** (범위 규칙 2턴). **같은 대상에게 연속 발동 불가** — 이 유닛이 바로 직전 자기 차례에 위협한 대상은 이번엔 안 걸림 |
| 잔비·가뭄·모래날림·눈퍼뜨리기 | 출전 중이면 층 날씨를 그 날씨로 덮어씀. 아군·적 모두 해당, 층 시작 때 정해지며 여러 명이면 아군 쪽 → 스피드 높은 순 먼저 |
| 피뢰침·마중물 | 주변 2칸 안에서 쓰인 단일 대상 전기/물 기술을 자기에게 끌어옴 + 무효 + 특공 +1 |
| 개미지옥·그림자밟기·자력 | 인접한 적은 다음 자기 차례 이동력 1 (비행·부유 제외 / 자력은 강철만) |
| 옹골참 | 5세대식: HP 가득일 때 한 방에 기절하지 않고 1 남김 (한 층에 한 번) |
| 게으름 | 행동한 다음 자기 차례는 쉼 (이동·행동 불가) |
| 슬로스타트 | 층 시작부터 자기 차례 5번 동안 공격·스피드 절반 |
| 트레이스 | 층 시작 때 가장 가까운 적의 특성 복사 (트레이스·멀티타입 제외) |
| 다운로드 | 층 시작 때 가장 가까운 적의 방어/특방 중 낮은 쪽에 맞춰 공격 또는 특공 +1 |
| 위험예지·예지몽 | **적 정보창을 볼 때, 그 적이 이 특성을 가진 아군에게 효과가 굉장한 기술을 갖고 있으면 경고 표시** ("⚠ ○○에게 효과 굉장") |
| 플러스·마이너스 | 인접한 아군이 플러스/마이너스면 특공 1.5배 |
| 플라워기프트 | 쾌청일 때 자신과 인접 아군 공격·특방 1.5배 |
| 나이트메어 | 주변 2칸 안 잠든 적에게 차례 끝 1/8 피해 |
| 싱크로 | 독·마비·화상을 건 상대에게도 같은 상태이상 |
| 픽업·꿀모으기 | 층을 돌파하면 10% 확률로 코인 주머니(층×10) 또는 경험 사탕 |

## 5. 화면
- 정보창: 이름 아래 특성 이름(작은 글씨). 편성소·결산 화면: 특성 이름 + 설명 한 줄.
- 발동: 대상 위 특성 이름 팝업 + 대사 ("○○의 위협!", "○○는 축전으로 HP를 회복했다!"). 연속 발동이 잦은 것(가속 등)은 팝업만.
- 위험예지 경고: 적 정보창 아래 붉은 줄.
- 편성소: "특성 바꾸기" 메뉴 (결정 3, 계열 결정 수 표시).

## 6. 테스트
- 데이터: 4세대 기준 특성 목록(예: 팬텀 부유, 또가스 부유 — 화학변화가스 아님), 숨겨진 특성 없음, 모든 특성에 이름·설명.
- 저장 v4→v5, 결정 3으로 바꾸기(부족·특성 하나인 종 거절).
- 특성마다 대표 테스트(①·③ 전부 최소 1개), AI 가 축전 상대에게 전기 기술 안 씀.
