# 9-1 협곡 — 짧은 설계

- 작성일: 2026-11-23 · 상태: 승인
- 바탕: `codex-reviews/2026-11-20-canyon-stage.md` (미정 수치는 여기서 정함) · 분기 구조 `2026-11-22-branch-stages-design.md` · 고저차는 시티 옥상 규칙(`damage.js` ±10)

## 목적
9단계 첫 번째 분기, 묘지의 짝. **"높이와 낭떠러지"**: 위쪽 바위 능선(고지)과 아래쪽 개울가(저지)로 나뉜 협곡. 고지는 명중 이점, 저지는 수풀과 물. 사이사이 낭떠러지가 있어 **밀어내기로 떨어뜨리면 즉시 전투불능** — 처음 나오는 낙사 맵.

## 접근
- **A. 새 칸 3개 (선택)**: 고지 `H`, 덩굴 `|`, 낭떠러지 `X`. 고저 명중은 시티 옥상(`B`) 규칙을 `H` 에도, 덩굴 오르기는 사막 모래지옥 탈출처럼 "그 차례 이동 전부" 틀을 다시 씀, 낙사는 `pushAway` 가 막힌 칸 대신 `X` 를 만났을 때 처리.
- B. 높이를 칸마다 숫자로 (0·1·2 층): 그림·길찾기·AI 가 전부 바뀜. 이번 맵 하나에 과함. 버림.
- C. 낭떠러지 없이 고저만: 기획의 핵심(첫 낙사)이 빠짐. 버림.

## 설계 *(내 결정 표시)*

### 자리·저장
- 9-1 = **협곡** (id `canyon`, 테마 `canyon`, `fillerStage(7)` 곡선 — 9층, Lv 65~70, 상한 73, 맵 20×14). 슬롯 `7: [CANYON, GRAVEYARD]`.
- 해금은 분기 짝 규칙 그대로: **얼음동굴 → 9-1**. 저장 이전 `trial-7` → `canyon` (얼음동굴 때 `trial-6` 과 같은 방식).

### 출현·날씨
- 비행·드래곤 위주, 바위·에스퍼·풀 소수 (`minorTypes`). 그대로 두면 비행(64종)만 보이니 `favored: { type: 'dragon', chance: 0.3 }` *(내 결정 — 드래곤 19종이 묻히지 않게)*. 보스: 비행 또는 드래곤.
- 고유종 없음 *(내 결정 — 기획에 없음)*. 날씨 없음 *(기획에 없음)*.

### 고지 `H` · 덩굴 `|`
- `H` = 능선 위 발판. 고지끼리는 누구나 걸음(1). **고지 → 저지로 뛰어내리기는 누구나 1** (절벽 가장자리 어디서든).
- **저지 → 고지**: 비행·드래곤은 아무 데서나 2 (옥상과 같음). 지상은 **덩굴 `|` 칸에서만**, 그 차례를 **덩굴 칸에서 시작했을 때** 위 칸으로 오르며 **이동이 끝남** (공격·기술은 그대로 가능) *(내 결정 — "한 턴을 쓴다"를 이동만 쓰는 것으로; 오르고 아무것도 못 하면 너무 답답)*.
- 명중: 고지 → 저지 +10, 저지 → 고지 −10 (시티 옥상과 같음). 높이가 달라도 붙어 있으면 근접 공격 가능.
- 덩굴 `|` 은 저지 칸 (풀 같은 바닥, 이동 1), 고지 바로 아래에만.

### 낭떠러지 `X`
- 비행·드래곤·부유(전자부유 포함)만 들어가고 멈출 수 있음. 지상은 못 들어감.
- **떨어지기**: 밀어내기(울부짖기·날려버리기)로 밀리는 길에 `X` 가 있고 그 포켓몬이 뜨지 못하면 그 칸으로 떨어져 **HP 와 상관없이 기절** (밀어낸 쪽이 쓰러뜨린 것으로 — 경험치·격파 기록 같음). 알림 "…은/는 낭떠러지로 떨어졌다!". 보스는 원래 밀리지 않음.
- 조준할 때 예상 창에 **"낙사!"** 표시 *(내 결정 — 기획의 "떨어질 칸 표시")*.
- 직선 기술·사거리는 낭떠러지를 막지 않음 (빈 공간).

### 층 생성 (`floorgen.canyonLayout`, 별도 난수 7700, 맨 끝)
- **위쪽 능선**: 맵 위 1/3 쯤(행 0~3~5, 열마다 높이 ±1 흔들림)을 `H` 로, 출발 3열 밖. 능선 위 바위 `^` 몇 칸.
- **아래쪽 개울**: 맨 아래 쪽 1~2줄 폭 물 `~` 이 가로로 흐르고 물가에 나무 `#`·풀숲 `"`.
- **낭떠러지**: 2~3개, 능선 가장자리에서 아래로 2~5칸 내려오는 폭 1~2 틈 + 가운데 들판의 작은 구덩이 0~1개. 틈 사이로 폭 1 좁은 길이 남게 (떨어뜨리기 좋은 자리).
- **덩굴**: 절벽 아래 2~4곳 (오른 칸이 고지·발판 있음).
- 검증: 지상 포켓몬이 출발 칸에서 계단·모든 상자에 (덩굴 포함) 닿음, 적이 `X` 위에 없음 (뜨는 적 제외). 아니면 다른 난수로 다시(최대 20번), 그래도 안 되면 지형 없이.

### AI
- 같은 길찾기라 따로 손대지 않음. 적의 울부짖기·날려버리기가 아군을 떨어뜨릴 수 있음 (서로 같은 규칙).

### 그림 (품질 기준 = ???시티 이상)
- 고지: 붉은 갈색 바위 능선 윗면 + 아래쪽 절벽면(층 무늬), 바위. 덩굴: 절벽면을 타고 내려오는 초록 덩굴. 저지: 풀밭·흙, 개울(물가 윤곽), 나무·풀숲. 낭떠러지: 끊긴 가장자리(어두운 단면) + 아래가 안개로 덮인 깊은 틈. 계단: 바위 틈 내리막.

## 비목표
돌진류 자기 추락(돌진은 낭떠러지 앞에서 멈춤), 점프킥으로 틈 건너기, 착지 피해, 낙사 외 높이 3단 이상, 협곡 전용 날씨.
