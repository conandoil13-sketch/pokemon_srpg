# 해변 (4번째 맵) — 짧은 설계

- 작성일: 2026-11-22 · 상태: 사용자 승인 대기
- 바탕: `codex-reviews/2026-11-20-beach-stage.md` (참고, 그대로 따르지는 않음)

## 목적
들판 → 동굴 → 단풍 숲 다음 **해변**. 바다가 맵의 약 1/4. 깊은 물을 건널 수 있는 동료(물·비행·드래곤·부유)를 데려가면 더 많이 탐험하고 보상을 더 얻는다 — 방금 넣은 타입별 지형 이득이 처음 크게 쓰이는 맵.

## 사용자 결정
- 밀물·썰물: **기본 0, 썰물 −1, 밀물 +1** 세 상태.
- 불꽃 타입 얕은 물 불리함은 **넣지 않음**.
- 깊은 물 너머 섬이 생긴 층은 **기존 상자 수와 별개로 상자 1개 확정**.

## 접근
- **A. 단풍 숲처럼 시련 자리 하나를 대체 + 바다 생성 단계 추가 (선택)**: `stageSlots({ 1: 단풍 숲, 2: 해변 })`, 층 생성기에 바다·섬 단계를 `dungeon.sea` 가 있을 때만 별도 난수로. 다른 던전 결과·골든 해시 불변.
- B. 해변 전용 생성기를 따로: 계단·적·상자 배치를 중복 구현하게 돼서 버림.

## 설계 *(내 결정 표시)*

### 자리·곡선
- 시련 **2번 자리**(시작 Lv 30, 8층) 대체 *(내 결정 — 4번째 맵 = 단풍 숲 다음 자리)*. 저장 이전: `trial-2` → `beach`. 이름 "해변", 테마 `beach`.

### 타일
- **얕은 물 `,`** (새 칸): 누구나 걷고 이동 비용 1, 물 타입은 여기서 출발해도 이동력 +1 (물 칸으로 침). 지형 판정 없음.
- **깊은 물 `~`**: 지금 물 규칙 그대로 (물·비행·드래곤·부유·전자부유만).
- 모래 바닥 `.`, 야자수 `#`(나무 — 벌레 나무 규칙 적용), 바위 `^` 그대로.

### 바다 생성 *(내 결정)*
- 맵 **위 또는 아래 가장자리**(층마다 무작위)에서 들어오는 띠. 해안선은 열마다 ±1 흔들림. 띠 두께 3 정도로 면적 약 1/4 이 되게.
- 칸마다 **물때 등급**: 해안 첫 줄 = A, 둘째 줄 = B, 그 너머 = C.

| 등급 | 썰물 −1 | 기본 0 | 밀물 +1 |
|---|---|---|---|
| A | 모래 `.` | 얕은 물 `,` | 깊은 물 `~` |
| B | 얕은 물 `,` | 깊은 물 `~` | 깊은 물 `~` |
| C | 깊은 물 | 깊은 물 | 깊은 물 |

- **걸어서 클리어 보장**: 연결성·계단·적·상자 자리는 A 칸을 빼고(밀물 상태 기준) 계산 → 어느 물때든 도보 파티가 계단·보스까지 감. 적·상자·계단은 모래 칸에만.

### 섬 + 확정 상자
- 바다 띠 밖 오른쪽 절반에 **작은 섬 하나**(모래 2~4칸, 둘레가 전부 C 깊은 물)를 층마다 **60% 확률**로 *(내 결정)*. 섬이 생기면 섬 위에 **상자 1개 확정** (기존 상자 0~2개와 별개, 같은 확률표).
- 섬 둘레는 C 라 물때와 상관없이 헤엄·비행으로만 닿음.

### 밀물·썰물 *(내 결정)*
- 순서 0 → +1 → 0 → −1 → 0 … **3라운드마다** 한 칸. 층 시작은 0.
- **한 라운드 전 예고**: 바뀔 칸에 물결 표시 + 배너 "밀물이 들어온다" / "물이 빠진다".
- 바뀐 칸 위에 못 서는 포켓몬이 서 있으면 그대로 둠 (거기서 나가는 건 자유, 다시 들어오진 못함). 밀려나거나 피해 없음.

### 적·보스·모래더미
- 적 타입: **물·비행 위주**, 전기·얼음·땅은 소수 *(내 결정: 소수 타입만 가진 종은 뽑히면 70% 확률로 한 번 다시 뽑음 — 해변 전용 규칙)*.
- 보스: 물 또는 얼음 타입을 가진 종만.
- **모래더미** = 낙엽더미 규칙 그대로 (`*`, 2~3개, 다가가면 기습 or 상자 자동). 나오는 종은 크랩·킹크랩·셀러·파르셀·가재군·가재장군.
- 날씨: 비 15% *(내 결정)*.

### 그림 (도트)
- 모래 바닥(여러 변형), 얕은 물(밝은 청록, 물결), 깊은 물(진한 파랑), 야자수, 암초 바위, 모래더미, 물때 예고 물결. 단풍 숲 `autumnTiles` 방식으로 `beachTiles`.

## 비목표
불꽃 불리함, 물 칸 적 생성, 밀물로 피해·밀어내기, 전기 연쇄(나중 타입 이득), 바다 모양 다양화(만·곶).

## 확인
- 테스트: 바다 면적 약 20~30% / 물때 3상태 표 대로 바뀜 / 어느 물때든 도보로 계단·보스 도달 / 섬이 생기면 섬 상자 1개 + 섬은 걸어서 못 감 / 해변 아닌 던전 골든 해시 그대로 / 모래더미 종 / 보스 물·얼음 / 저장 이전.
- 브라우저: 해변 한 층 — 물때 예고·변화, 섬 상자, 도트 (저장 백업·복원).
