# 하수도 (6-1 분기 맵) — 짧은 설계

- 작성일: 2026-11-22 · 상태: 승인
- 바탕: `codex-reviews/2026-11-20-sewer-stage.md` (미정 수치는 여기서 정함) · 분기 구조 `2026-11-22-branch-stages-design.md`

## 목적
시티 다음 6단계의 첫 분기. 새 기믹은 **독 웅덩이**: 지름길이지만 그 위에서 차례를 끝내면 피해. "물길로 돌아갈까, 독을 밟고 질러갈까"를 매 턴 고르게 한다. 나머지(벽·타이어·이끼·봉투)는 기존 규칙에 그림만 새로.

## 접근
- **A. 시련 4번 자리를 `[하수도, 시련 임시]` 분기로 (선택)**: 6-1 하수도 · 6-2 시련의 동굴 Ⅱ(지금 그 자리 임시 스테이지 그대로, id `trial-4` 유지 → 저장 이전 없음). 깊은 동굴이 생기면 6-2 를 바꿔 끼움. 시티 돌파 → 둘 다 열림, 7단계는 짝 해금.
- B. 하수도 하나만 자리에 넣기: 분기 표시가 안 나서 구조를 실제로 못 씀. 버림.

## 설계 *(내 결정 표시)*

### 자리·곡선
- 자리 4 (`fillerStage(4)` 곡선), id `sewer`, 이름 **하수도**, 테마 `sewer`.

### 타일
| 칸 | 문자 | 규칙 |
|---|---|---|
| 하수도 벽 | `#` | 지금 벽 그대로 (막힘) |
| 통로 바닥 | `.` | 그대로 |
| 물 웅덩이 | `,` | 기존 얕은 물 그대로 (누구나 통과·멈춤, 물 타입 이득, 전기 연쇄) |
| **독 웅덩이** | `%` (새) | 이동 비용 1, 누구나 통과·멈춤. **자기 페이즈 끝에 그 위면 최대 HP 1/8 피해** *(내 수치)* |
| 타이어 더미 | `^` | 바위 칸 그대로 (비용 2, 방어 이득) — 그림만 |
| 이끼 수풀 | `"` | 수풀 그대로 (회피·불꽃 연쇄·악 숨기) — 그림만 |
| 쓰레기봉투 | `*` | 낙엽더미 규칙 그대로 (2~3개) |

- 독 웅덩이 피해: **독 타입 면역**(독·강철 복합도 면역), **강철 절반(1/16)**, 그 밖 1/8, 최소 1. *(내 결정)* **떠 있는 포켓몬(중력 아닌 비행·부유 특성)도 면역** — 지금 물·나무 규칙과 맞춤.
- 기절은 가능(HP 1 남기지 않음) *(내 결정 — 날씨 피해와 같게)*.
- 정보창 지형 이름 "독 웅덩이", 예상 창은 그대로.

### 층 생성 *(내 결정, `dungeon.sewer` 일 때만 별도 난수 — 다른 던전·골든 해시 불변)*
- 바탕을 벽으로 채우고 **직선 통로**를 판다: 가로 본관 2~3줄(폭 2) + 세로 연결관 3~5줄(폭 1~2), 가끔 막다른 짧은 가지.
- 본관 가운데 줄 일부를 **물길**(`,` 줄)로. 연결관 몇 개는 **독 웅덩이 지름길**(`%` 2~4칸 덩어리) — 돌아가면 물길, 질러가면 독.
- 넓은 공간(교차점) 몇 곳에 타이어 더미·이끼 수풀. 출발·계단·보스 연결은 기존 연결성 단계가 보장, 독 칸 위엔 적·상자·계단 안 놓음.

### 적·보스·AI
- 적 타입: **독·악 위주**, 물·풀 소수(`minorTypes`, 70% 재굴림). 보스: 독 또는 악.
- 봉투에서 나오는 종: 질퍽이·질뻐기(자주, 가중 2배)·스컹뿡·스컹탱크·삐딱구리 *(4세대 범위 — 깨봉이는 세대 확장 후)*.
- 날씨: 안개 15% (비·쾌청 없음, 지하) *(내 결정)*.
- **적 AI**: 독 웅덩이에 멈출 자리의 위험도에 웅덩이 피해를 더함(면역이면 0) — 적이 괜히 독에 서지 않게.

### 그림 (품질 기준 = ???시티 이상, `src/render/sewerTiles.js`)
- 벽: 어두운 벽돌(줄눈·음영·이끼 얼룩), 통로 바닥: 젖은 콘크리트 판(물자국·배수구 그레이트).
- 물길: 탁한 청록 물 흐름 애니메이션 + 가장자리 턱. 독 웅덩이: 보라 물 + 거품 터지는 애니메이션.
- 타이어 더미: 가운데 구멍 보이게 포갠 바퀴. 쓰레기봉투: 윗매듭 보이는 검정·초록 봉투. 이끼 수풀: 축축한 초록 덤불.
- 브라우저에서 실제 층 스크린샷으로 두세 번 다듬기.

## 비목표
깊은 동굴(6-2 진짜 맵), 깨봉이 계열(세대 확장), 독 웅덩이가 독 상태이상을 거는 것, 물길 흐름에 떠밀림.

## 확인
- 테스트: 6단계 `[sewer, trial-4]` 분기·시티 돌파로 둘 다 열림·7단계 짝 해금 / 독 웅덩이 피해(1/8·강철 1/16·독 면역·독강철 면역·비행/부유 면역·지나가기만 하면 없음) / 생성(벽+직선 통로, 물길·독 지름길 존재, 계단·보스 연결, 독 칸 위 배치 없음, 다른 던전 골든 해시 불변) / AI 가 독에 멈추는 걸 피함.
- 브라우저: 하수도 층 그림·웅덩이 피해 표시 (소리 끄기 + 저장 백업·복원).
