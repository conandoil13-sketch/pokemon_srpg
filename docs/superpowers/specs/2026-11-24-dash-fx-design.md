# 돌진 이펙트 (타입 팔레트) — 짧은 설계

- 작성일: 2026-11-24 · 상태: 승인 (2026-11-24)
- 요청: "돌진할 때 이펙트를 만들고 그걸 타입별로 팔레트스왑해서 넣어주면 돌진기들이 잘 보일 것"

## 지금 상태 (조사)
- 돌진기 = `src/core/dash.js` 의 `DASH` 14개: 돌진·플레어드라이브·스파크·브레이브버드·이판사판태클·화염바퀴·양날박치기·신속·전광석화·아쿠아제트·폭포오르기·점프킥·회전부리·유턴·볼트체인지.
- 전투 결과에 `dashed {from, to}` · `returned` 가 이미 있고, `mapAttack.js` 는 'dash'·'back' 단계에서 스프라이트를 미끄러뜨리기만 한다 — 이펙트는 없음. 붙어 있으면(거리 1) 대시 단계 자체가 없음.
- 이펙트는 pixelfx 방식 (`src/fx-custom/pokemon/*.js`, `palette` 옵션), 타입 색은 `moveFx.js` 의 `pal(type)` (악·독 전용 팔레트 포함).

## 설계 (추천안)
- **새 이펙트 `pokemon/dash-trail`** (픽셀 직접 그림, 타입 팔레트 5단):
  1. 출발: 발밑에서 흙먼지·불꽃 같은 킥오프 퍼프 (타입 색).
  2. 달리는 동안: 몸 높이에 가로 속도선 다발 + 뒤로 길게 끌리는 꼬리 — 앞쪽은 흰색·밝은 색, 꼬리는 어두운 색으로 디더 페이드.
  3. 도착: 대상 앞에서 짧은 충돌 플래시(쐐기 모양 섬광 + 파편 몇 점).
  - 대시 거리(칸 수)를 `reach` 옵션으로 받아 꼬리 길이를 맞춘다. 위·아래는 지금 이펙트처럼 회전.
- **타입 팔레트 스왑**: `pal(move.type)` 그대로 → 불꽃은 주황 불꽃 꼬리, 물은 물보라, 전기는 노란 번개 꼬리, 비행은 연회색 바람… 따로 그림을 그리지 않고 한 이펙트가 18타입 전부를 커버.
- **붙어 있을 때(거리 1)**: 대시 단계가 없어도 짧은 "런지" 버전(꼬리 1칸)을 'act' 단계에 한 번 → 돌진기는 항상 돌진처럼 보이게.
- **돌아오기(유턴·회전부리·볼트체인지)**: 'back' 단계에 반대 방향으로 옅은 꼬리 하나.
- 기존 타격 이펙트(hit)는 그대로 — 돌진 이펙트는 그 앞에 덧붙임.

## 비목표
돌진기가 아닌 접촉기(몸통박치기 등)의 연출, 스프라이트 자체의 색 바꾸기(잔상), 새 기술 판정.

## 확인
- 테스트: `fxForMove` 가 돌진기에 `dash` 스펙(타입 팔레트)을 주고 다른 기술엔 안 줌, 악·독 팔레트, fx 매니저에 'pokemon/dash-trail' 이 등록되고 그려도 예외 없음(4방향·거리 1~3).
- 브라우저: 불꽃·물·전기·비행 돌진기 하나씩 실제 전투에서 써 보고 스크린샷.
