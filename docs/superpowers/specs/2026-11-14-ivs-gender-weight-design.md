# 개체값 · 성별 · 몸무게 — 설계 스펙

- 작성일: 2026-11-14 · 상태: 빌더 체크 완료, 사용자 승인 대기

## 1. 목적 · 이유
같은 종이라도 개체마다 다른 맛(개체값·성별·몸무게)을 준다. 특히 **PokeRogue 처럼 뽑기에서 같은 계열이 또 나오면 능력치마다 더 높은 개체값으로 합쳐지는** 수집 보상을 만든다. 성별은 본가 규칙(성별 진화·투쟁심·헤롱헤롱)을 살리고, 몸무게는 안다리걸기·풀묶기 같은 기술과 나중 메타몽 무게 캡슐의 바탕이 된다.

### 사용자 결정
- 성별: **표시 + 성별 규칙(A)** — 성별 진화, 투쟁심, 헤롱헤롱바디, 메로메로·유혹.
- 성별 표시: ♂ 파랑 · ♀ 빨강, 이름 옆. **니드런♀·니드런♂처럼 이름에 기호가 있는 종은 붙이지 않음.**
- 성별은 뽑기에서 나온 것으로 정해지고, **같은 계열을 다른 성별로 뽑으면 그 성별이 해금 → 비용 없이 ♂/♀ 전환** (PokeRogue 식, 내 해석을 사용자 확인).
- 성별로 진화가 갈리는 계열: **이번엔 한 계열 한 마리**(진화 전에 성별을 바꿔 갈래 선택). 같은 계열 여러 마리 보유는 나중(이브이 포함).
- 개체값: **아군·적 모두 0~31 무작위(A)**. 메타몽은 31 고정(내 제안, 사용자 수락).
- 데이터는 PokeAPI 에서 다시 받는다(성별 비율·몸무게·성별 진화 조건).

### 성공 기준
1. 동료마다 개체값 6개·성별이 있고, 자세히 보기·박스에서 보인다.
2. 뽑기 중복 → 결정 + 개체값 능력치별 최대 합치기 + 새 성별 해금.
3. 성별 진화(엘레이드·눈여아·도롱마담/나메일·비퀸)가 성별대로.
4. 투쟁심·헤롱헤롱바디·메로메로·유혹·안다리걸기·풀묶기가 동작.
5. 기존 저장이 그대로 불러와진다(개체값·성별 채움). `npm test` 통과, 브라우저 확인.

### 범위 밖 · 안티 목표
- 범위 밖: 같은 계열 여러 마리, 성격·노력치, 메타몽 무게 캡슐(구조만), 이로치, 암수 다른 스프라이트, 몸무게로 바뀌는 다른 효과(5세대 헤비봄버 등).
- **안티 목표**: 개체값 도입으로 난이도가 갑자기 바뀌면 실패(적도 같이 무작위). 성별 전환으로 성별 진화 조건을 "진화한 뒤" 우회하면 실패(진화 판정 시점 성별만 봄). 니드런 이름 옆에 기호가 두 번 붙으면 실패.

## 2. 규칙

### 2-1. 개체값
- `member.ivs = { hp, atk, def, spa, spd, spe }` 각 0~31 정수. 합류 때 rng 로 각각 무작위(rng 없으면 종 이름 해시로 결정적).
- 능력치 계산 `statsAt(base, level, ivs)` — ivs 없으면 31(지금과 같음, 테스트·호환).
- 적: `makeUnit` 이 `hash(species, x, y, level, stat)` 로 결정적 무작위(같은 층이면 같음, 지금 특성과 같은 방식).
- 메타몽: 31 고정(빌드 주인공).
- **뽑기 중복**: 결정 +1(지금) + 능력치마다 `max(가진 값, 새로 굴린 값)` 합치기. 결과에 어떤 능력치가 올랐는지 담아 연출 대사("공격·스피드 개체값이 올랐다!").
- 표시: 자세히 보기 능력치 페이지에 능력치마다 숫자와 판정 — 31 "최고", 30~26 "훌륭함", 25~16 "꽤 좋음", 15~1 "그럭저럭", 0 "별로".

### 2-2. 성별
- 종 데이터 `genderRate`: PokeAPI `gender_rate` (−1 = 성별 없음, 0 = ♂만, 8 = ♀만, 그 외 ♀ 확률 = rate/8).
- `member.gender = 'male' | 'female' | null`, `member.genders = ['male', …]` 해금된 성별(얻은 적 있는 성별).
- 합류: rate 대로 무작위. 뽑기 중복에서 새 성별이 나오면 `genders` 에 추가.
- 전환: `setGender(game, species, g)` — `genders` 에 있으면 공짜. 성별 없는 종·한쪽 성별만 있는 종은 바꿀 수 없음. 박스 자세히 보기 정보 페이지에서.
- 표시: 이름 옆 ♂(#4878f0)/♀(#f05878). 종 이름에 ♂/♀ 가 들어 있으면 생략(니드런). 박스 패널·자세히 보기·전투 정보창·결산.
- **성별 진화**: 진화 규칙에 `gender: 'male' | 'female'` (PokeAPI evolution_details.gender: 1 = ♀, 2 = ♂). 레벨 진화·돌 진화 판정에서 그 성별일 때만 후보. 킬리아 → 엘레이드(♂, 돌) / 눈꼬마 → 눈여아(♀, 돌) / 도롱벌레 → 도롱마담(♀, Lv.25) · 나메일(♂, Lv.25) / 세꿀버리 → 비퀸(♀, Lv.25, ♂ 는 진화 없음). 판정 시점의 성별만 본다(진화 뒤 바꿔도 되돌아가지 않음).
- 적 성별: 결정적 해시 + rate.

### 2-3. 헤롱헤롱 · 성별 특성 · 기술
- **헤롱헤롱(infatuation)**: 반대 성별(둘 다 성별 있음)에게만. 걸리면 행동(기술 사용)할 때 50% 로 아무것도 못 하고 행동 끝(마비 실패처럼). **자기 차례 3번 지나거나 건 상대가 쓰러지면 풀림**. 혼란처럼 다른 상태이상과 공존. 둔감(oblivious) 특성은 면역(지금 효과 없음 목록에서 뺌).
- **헤롱헤롱바디(cute-charm)**: 접촉 공격을 받으면 30% 로 공격자를 헤롱헤롱(반대 성별일 때).
- **투쟁심(rivalry)**: 같은 성별 ×1.25, 반대 ×0.75, 성별 없음 끼면 ×1.
- **메로메로(attract)**: 대상 헤롱헤롱(명중 100). **유혹(captivate)**: 반대 성별이면 특공 −2, 아니면 실패. 둘 다 배울 수 있게(습득표에 있으면).
- 대사·연출: "○○는 헤롱헤롱해졌다!", "○○는 헤롱헤롱해서 기술을 쓸 수 없었다!", 풀리면 "○○의 헤롱헤롱이 풀렸다!". 상태 지속 연출은 기존 혼란처럼(빌더 재량 이펙트).

### 2-4. 몸무게
- 종 데이터 `weight` (kg, PokeAPI hectogram ÷ 10). 자세히 보기 정보 페이지에 "몸무게 ○○kg".
- **안다리걸기(low-kick)·풀묶기(grass-knot)**: 상대 몸무게로 위력 — <10kg 20, <25 40, <50 60, <100 80, <200 100, 그 이상 120 (4세대). 기대 데미지·AI·예상 창에도. 기술 데이터에 `weightPower: true`, 배울 수 있게. 풀묶기는 기술 데이터에 추가(4세대 기술).
- 유닛 `weight` 필드(메타몽은 빌드 `weight` 가 있으면 그것 — 나중 무게 캡슐용, 지금은 종 값).

## 3. 데이터 · 저장
- `tools/fetch-pokeapi.js`: species `gender_rate` → `genderRate`, pokemon `weight` → `weight`, 진화 상세 `gender` 를 규칙에 보존, 풀묶기 기술. 다시 받아 `src/data/generated/pokedex.js` 갱신(기존 필드 값은 그대로여야 함 — diff 로 확인).
- 저장 v8: 멤버 `ivs`(없으면 결정적 무작위 — 종 이름 해시), `gender`(없으면 결정적 무작위 + rate), `genders`(없으면 [gender]). 메타몽 ivs 31. 정리: 범위 밖 값 → 고침, 성별 rate 와 안 맞으면 다시 정함, genders 에 gender 포함.

## 6. 빌더 체크 뒤 정리 (내 결정, 바꿔도 됨)
- **기존 저장·시작 동료 개체값**: 종 이름 해시로 정하는 결정적 무작위 0~31 (평균 약 15). 사용자가 A(아군·적 모두 무작위)를 골랐으므로 적도 같이 31에서 내려가 체감 난이도는 비슷하다. 별도 보정 없음.
- **성별 전환은 진화한 뒤에도 가능**(표시·성별 규칙에 쓰는 값만 바뀜, 종은 그대로). 진화 판정은 그 순간의 성별.
- 뽑기 결과의 성별 = 그 동료(또는 중복이면 해금 후보)의 성별. 중복이 다른 성별이면 해금.
- **성별 진화 레벨은 지금 데이터 그대로** (도롱벌레 Lv.25 두 갈래, 세꿀버리 Lv.25, 엘레이드·눈여아는 진화의돌). 데이터를 다시 받을 때 진화 상세의 성별만 규칙에 보존하고, 레벨·종류 분류는 지금 결과와 같아야 한다(다시 받은 뒤 diff 로 확인: 새 필드 추가 외에 바뀐 값 없음).
- **헤롱헤롱 시간**: 혼란처럼 그 유닛 편의 페이즈 끝마다 1 씩 줄어 3 → 0 이면 풀림(유닛은 한 페이즈에 행동 한 번). 기술을 쓸 때마다 50% 판정. 건 상대는 `infatuatedBy`(유닛 id)로 기억, 그 유닛이 쓰러지면 바로 풀림.
- **성별 없는 유닛**(메타몽·코일 등): 헤롱헤롱·유혹 안 걸림, 투쟁심 ×1.
- 적 성별·개체값: 위치·레벨 해시 + 종 성별 비율(특성과 같은 방식).
- 뽑기 중복은 매번 개체값 6개를 새로 굴려 능력치마다 큰 값. 10연속 결과에도 오른 능력치(`ivUp`)를 담아 결과 목록에 "개체값↑" 표시. 메타몽은 뽑기에 안 나옴.
- **기술 습득 현황**(지금 레벨업 습득표 기준): 안다리걸기 10종, 메로메로 10종, 유혹 22종이 배움 — 게임에서 바로 쓰인다. 풀묶기는 기술머신 전용이라 습득표에 없음 → 규칙(몸무게 위력)만 넣고 나중에 기술머신·상점·메타몽 캡슐(적이 쓰면)로 얻게.
- 기호 표시: 성별 없는 종은 기호 없음. 한쪽 성별만 있는 종은 기호 표시, 전환 버튼 없음.

## 7. 빌더 재량
판정 글자 색, 기호 위치, 헤롱헤롱 이펙트, 대사 문구 세부, 성별 전환 버튼 위치.
