# 마을 확장 + 상점 — 설계

- 작성일: 2026-11-17 · 상태: 사용자 승인 대기

## 목적
지니는 도구를 노려서 얻는 경로를 만든다. 코인의 두 번째 쓸 곳. 마을을 넓혀 상점 구역을 둔다.

## 사용자 결정
- 상점 **자리 + 사기**까지.
- **탐험에서 돌아올 때마다 진열이 바뀐다.**
- 52종을 **가격대로 나눈다**. 가격은 **지금 SRPG 규칙에서의 가치** 기준 (내가 책정).

## 접근
- **A. 진열 = 가격대별 칸 수 고정 + 무작위 (선택):** 진열 8칸 = 싼 3 · 보통 3 · 비쌈 1 · 최상 1 (최상 칸은 50% 확률로 비쌈으로 대체). 탐험 끝날 때 새로 굴림. 가격대마다 고르게 섞여서 늘 살 만한 게 있다.
- B. 52종 중 8개 완전 무작위: 최상만 몰리거나 싼 것만 나오는 진열이 생겨서 고르지 않았다.

## 가격대 (SRPG 가치 기준 · 내 결정)
판단 기준: 층마다 4~6명이 여러 페이즈 싸우고, 회복은 층마다 2번, 1회 도구는 층마다 돌아옴, 메타몽은 항상 출전.

| 가격 | 도구 | 이유 |
|---|---|---|
| **150** (싼) | 화염구슬 · 독독구슬 · 끈적끈적바늘 · 붉은실 · 끈기갈고리 · 축축한바위 · 뜨거운바위 · 보송보송바위 · 차가운바위 | 근성·포이즌힐 같은 특성이 있어야 쓸모 있거나, 날씨·속박 덱 전용인 좁은 도구 |
| **300** (보통) | 타입 강화 17종 · 힘의머리띠 · 박식안경 · 빛의점토 · 멘탈허브 | 1.1~1.2배, 늘 조금씩 이득 |
| **600** (비쌈) | 초점렌즈 · 예리한손톱 · 광각렌즈 · 빛의가루 · 느긋한향로 · 달인의띠 · 하얀허브 · 검은진흙 · 조개껍질방울 · 기합의머리띠 · 구애머리띠 · 구애안경 | 효과가 크지만 조건이 있음. 구애는 1.5배지만 층 내내 기술 하나로 묶여 SRPG 에선 부담이 커서 이 줄 |
| **1200** (최상) | 먹다남은음식 · 생명의구슬 · 기합의띠 · 메탈파우더 | 매 차례 회복 / 1.3배 무조건 / 층마다 확정 생존 / 항상 출전하는 메타몽 방어 2배 |
| **500** (전용) | 전기구슬 · 굵은뼈 · 심해의이빨 · 심해의비늘 · 럭키펀치 · 대파 | 그 포켓몬이 있을 때만 큰 이득 — "보통" 칸에 같이 섞임 |

## 설계 *(내 결정 표시)*
- **진열:** `game.shop = { stock: [{ id, sold }], seed }`. 8칸, 각 1개 (사면 "품절"). 같은 도구 중복 없음. 첫 저장(상점이 없을 때)과 **탐험이 끝날 때마다(돌파·철수·전멸 모두)** 새로 굴림. 시드는 저장된 카운터라 불러오기를 반복해도 진열이 바뀌지 않음.
- **사기:** 상인에게 말 걸기 → 진열 목록(이름 · 가격 · 품절) + 아래에 설명 + 위에 가진 코인. 고르면 "○○을(를) N코인에 살까?" → 예: 코인 차감, 가방(`items.held`)에 +1, 저장. 코인이 모자라면 회색 + 이유.
- **맵:** 마을을 오른쪽으로 8칸 넓혀 28×14. 새 구역에 상점 건물(지금 건물처럼 바위 덩어리 자리) + 상점 표지판 + 상인 포켓몬 NPC. 기존 시설·동료 자리·물속 선물 자리·돌아오는 자리는 그대로 *(내 결정)*. 상인은 켈리몬 *(내 결정)*. 상점에서 나오면 상점 앞 자리로.

## 비목표
팔기, 할인·세일, 나무열매, 진화의돌·사탕 등 다른 아이템 판매, 진짜 건물 그림.

## 확인
- 테스트: 가격표가 52종 전부를 덮음 / 진열 8칸 가격대 구성·중복 없음·같은 시드 같은 진열 / 탐험 끝나면 바뀜, 불러오기만으로는 안 바뀜 / 사기: 코인 차감·가방 +1·품절·코인 부족 실패 / 저장 왕복·모르는 id 버림 / 넓힌 마을에서 기존 시설 자리·물속 선물 자리 그대로, 모든 시설에 걸어서 갈 수 있음.
- 브라우저: 저장 백업 → 상점 가서 사기 → 가방에 들어감 → 탐험 한 번 철수 → 진열 바뀜 → 저장 복원.
