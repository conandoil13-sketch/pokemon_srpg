# 지니는 도구 2차 (10종) — 짧은 설계

- 작성일: 2026-11-17 · 상태: 사용자 승인 대기

## 목적
1차에서 미룬 도구 중 지금 구조(페이즈 + 이동력 + 스피드 보너스)에 맞게 바꿀 수 있는 10종을 넣는다. 상점 진열도 다양해진다.

## 사용자 결정
- 스피드 관련은 **도구마다 섞는다**: 구애스카프 = 스피드 1.5배 + 이동력 +1 + 기술 고정, 검은철구 = 스피드 절반 + 이동력 −1 + 땅에 붙음, 선제공격손톱 = 페이즈 끝 20% 로 한 번 더 행동 (2배 조건과 별개).
- 묶음 10종: 왕의징표석·예리한이빨·큰뿌리·메트로놈·줌렌즈·구애스카프·검은철구·연기구슬·선제공격손톱·행복의알·부적금화 (예리한이빨은 왕의징표석과 같은 효과라 11개 id).

## 접근
1차와 같은 방식: `heldItems.js` 표에 효과 필드 + `items.js` 판정 + 기존 계산 자리에 훅. 스피드는 `speedOf`/`effectiveStat` 에 도구 배율, 이동력은 `moveBudget`, 땅에 붙음은 기존 `grounded` 규칙 재사용.

## 도구 *(값·가격은 내 결정)*
| 도구 | 효과 | 가격 |
|---|---|---|
| 왕의징표석 · 예리한이빨 | 공격기가 맞으면 10% 로 풀죽음 (다음 차례 기술 봉인). 원래 풀죽음 기술엔 안 겹침 | 600 |
| 큰뿌리 | 흡수 기술·씨뿌리기·아쿠아링·뿌리박기 회복 ×1.3 | 300 |
| 메트로놈 | 같은 기술을 연달아 쓸 때마다 위력 +20% (최대 2배). 다른 기술이면 처음부터, 층이 바뀌면 처음부터 | 600 |
| 줌렌즈 | 이번 차례에 이동하지 않고 공격하면 명중 ×1.2 | 300 |
| 구애스카프 | 스피드 1.5배 (스피드 보너스 비교에 반영) + 이동력 +1, 그 층 첫 기술로 고정 (구애 계열과 같은 규칙) | 600 |
| 검은철구 | 스피드 절반 + 이동력 −1 (최소 1), 땅에 붙음 (비행·부유도 땅 기술 맞고 물 위로 못 감) | 150 |
| 연기구슬 | 이동 불가(검은눈빛 등)·속박의 이동 막힘·개미지옥 같은 묶기 특성을 무시 (도주 특성과 같은 규칙) | 150 |
| 선제공격손톱 | 지닌 편 페이즈가 끝날 때(스피드 보너스 다음) 20% 로 그 포켓몬이 한 번 더 행동. 페이즈마다 1번, 지닌 포켓몬이 여럿이면 앞에서부터 굴려 처음 맞은 하나 | 600 |
| 행복의알 | 지닌 포켓몬이 받는 경험치 1.5배 | 1200 |
| 부적금화 | 출전 포켓몬 중 하나라도 지니면 그 층에서 얻는 전투 코인·층 돌파 코인 2배 (여럿이 지녀도 2배) | 1200 |

- 배너: 선제공격손톱 "○○의 선제공격손톱! 한 번 더 움직인다".
- 상점 가격대에 그대로 들어감 (150·300·600·1200 칸).

## 비목표
비단꼬리·느림보향로(순서 개념), 교정깁스·파워 계열(노력치 없음), 변함없는돌, 학습장치, 나무열매, 도구 기술·특성.
