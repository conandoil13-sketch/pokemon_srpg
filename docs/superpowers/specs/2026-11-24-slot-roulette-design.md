# 특성 각성 슬롯머신 연출 — 짧은 설계 (2026-11-24)

## 왜
2칸 특성 뽑기(편성소 "특성 각성")의 가로 칸 룰렛이 밋밋하다. 슬롯머신처럼, pixelfx 를 조금 써서 "도파민이 터지게".

## 목표 / 아닌 것
- 목표: 연출만 바꾼다. 결과(등급·특성·낚시)는 지금처럼 `rollExtra` 가 먼저 정하고 저장한 뒤 보여 준다.
- 아닌 것: 확률·비용·후보 변경, 새 효과음 파일, 릴 여러 개.
- 망하는 경우: 결과가 연출과 다르게 보임 / 너무 길어서 매번 지루함 / 건너뛰기가 안 됨.

## 접근 (사용자 선택: 릴 1개)
- 릴 3개 (셋 맞추기, 앞 두 개 S 로 낚시) — 더 슬롯답지만 길어짐. 사용자 미선택.
- **릴 1개 (선택)** — 큰 세로 릴 하나가 굴러가다 느려져 멈춤. 지금 길이와 비슷하고 단순.

## 연출 (승인됨)
- 기계: 결과 창 + 가운데 줄(▶ ◀), 테두리 전구가 번갈아 깜빡임(릴 빠를수록 빨리). 제목 "등급 슬롯".
- 돌기: 확인 → 릴이 살짝 위로 튕긴 뒤 아래로 굴러감. 빠를 때 잔상(늘어진 칸). 점점 느려지다 멈출 때 살짝 튕김.
- 업그레이드(S·낚시): 도중에 화면 흔들림 + pixelfx `lightning/thunderclap` + 번쩍 + "고급 슬롯!". 이후 릴에 S 칸이 섞이고 전구가 금색.
- 낚시: S 가 가운데 줄로 천천히 올라와 걸릴 듯 멈칫 → 한 칸 더 넘어가 A/B. 작은 글자 "아깝다…".
- 멈춤 보상: C 작은 불꽃(`impacts/hit-spark`), B 파란 불꽃, A `impacts/crit-hit` + 약한 흔들림, S `lightning/thunderclap` + `ui/level-up` + `pickups/collect-burst` + 금빛 번쩍 + 전구 난리.
- 공개: 등급 색이 걷히는 지금 방식 유지, A·S 는 반짝임 추가.
- 확인 = 건너뛰기(바로 결과). 전체 약 3~4.5초.

## 그 뒤: 특성 UI 다듬기 (내 판단으로 범위 작게)
- 특성 각성 화면: 1칸·2칸 카드에 등급색 테두리, 확률은 색 막대로.
- 자세히 보기 특성 탭 2칸 줄 정리.

## 빌더에게 남긴 것
- 릴 위치는 순수 함수 `reelAt(tl, t)` 로 (테스트: 결과 등급에 멈춤, 낚시면 도중에 S 가 가운데 줄, 평범한 굴림엔 S 없음).
- 픽셀 크기·색·타이밍 세부는 화면을 보며 조정.
