# 뽑기 — 볼 3개 고르기 연출 (짧은 설계)

- 작성일: 2026-11-14 · 상태: 사용자 승인 (구현 전)
- 다음: 편성소 박스 화면(별도 설계)

## 목적
뽑기를 "결과 보기"에서 "고르고 여는 재미"로. 내가 고른 볼이 슈퍼볼·하이퍼볼로 바뀌는 두근거림, 그리고 **안 고른 옆 볼이 하이퍼볼이 되며 매우 희귀가 나오는 아까움**까지 연출한다.

## 사용자 결정
- 희귀도는 지금 그대로 3단계: 평범 70 · 희귀 25 · 매우 희귀 5 (계열 최종형 종족값 450/535 기준).
- **볼 3개에 각각 결과가 들어 있고 하나만 가진다 (B안).**
- 고른 볼을 클릭해서 연다: 희귀면 번쩍 → **슈퍼볼**, 매우 희귀면 한 번 더 → **하이퍼볼**, 그다음 열림 → 포켓몬.
- 안 고른 두 볼도 열어 **볼 변화 + 안에 있던 포켓몬까지** 보여 준다.
- **10연속 뽑기 (추가 결정)**: 900코인(10% 할인). 볼 10개가 한 번에 나오고 **전부 내 것**(고르기 없음). 하나씩 클릭으로 단계 변화·열기, 또는 모두 열기. 끝나면 결과 목록. 같은 10개 안에서 같은 계열이 겹치면 두 번째부터 결정.

## 흐름
```
코인 100 → 몬스터볼 3개 (겉보기 같음) → 방향키/클릭으로 하나 고름
→ 고른 볼 가운데로, 클릭마다 흔들림·단계 변화(몬스터 → 슈퍼 → 하이퍼) → 열림 → 포켓몬·합류/결정 대사
→ 나머지 두 볼 빠르게 같은 변화로 열림 → 작게 포켓몬 + 이름 ("아깝다" 순간) → 메뉴로
```

## 접근
- **채택**: 규칙을 둘로 나눈다. `rollBalls(rng)` = 볼 3개 결과만 정함(코인 안 뺌, 볼마다 따로 70/25/5). `claimBall(game, balls, index, rng)` = 고르는 순간 코인 100 차감 + 동료/결정 적용 → 바로 저장. 볼 변화·열림은 그 뒤의 연출일 뿐.
  - 고르기 전에 닫으면 코인 그대로, 연출 중에 닫아도 받은 건 저장됨. 고르기 전엔 내용이 안 보여 새로고침으로 골라낼 수 없음.
- 버림: 열 때 코인을 빼는 방식(연출 중 종료 처리 애매), 볼 그림 파일 사용(에셋 규칙 — 공식 그림은 받지 않음).

## 내 결정 (바꿔도 됨)
- 볼 3개는 각각 독립으로 굴림 → 받는 확률은 그대로 70/25/5.
- 안 고른 볼의 포켓몬은 보여 주기만 (결정 등 보상 없음). 이미 있는 계열이어도 그냥 표시.
- 고른 볼은 단계마다 클릭으로 진행, 안 고른 볼은 자동으로 빠르게.
- 볼(몬스터·슈퍼·하이퍼)은 코드로 그린 도트, 번쩍임·반짝임은 pixelfx.

## 목표 · 범위 밖 · 안티 목표
- 목표: 고르기 → 단계 변화 → 옆 볼 공개까지 한 번에 자연스럽게, 입력 연타로 멈추거나 두 번 결제되지 않음.
- 범위 밖: 천장(보장), 확률 변경, 박스 화면.
- 안티 목표: 고르기 전 결과가 새어 보이면 실패. 연출 중 종료로 코인만 잃으면 실패.

## 테스트 (계획에서 구체화)
- `rollBalls` 결정적(rng 주입)·코인 불변, `claimBall` 코인 100 차감·고른 결과만 적용·부족하면 거절.
- 장면: 고르기 → 열기 → 옆 볼 공개 → 메뉴, 연타해도 결제 한 번.

## 빌더 재량
볼 도트 디자인, 흔들림·번쩍임 타이밍, 옆 볼 공개 배치, pixelfx 이펙트 선택.
