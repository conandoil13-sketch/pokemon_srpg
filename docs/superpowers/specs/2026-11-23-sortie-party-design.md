# 마을 출격 게시판 · 편성소 업그레이드 — 짧은 설계

- 작성일: 2026-11-23 · 상태: 승인
- 바탕: `codex-reviews/2026-11-22-town-sortie-board.md`, `codex-reviews/2026-11-22-town-move-relearning.md`

## 목적
매 판 거치는 두 화면을 손본다. 출격 전에 **어디에 누구로 가는지** 한눈에 확인하고, 편성소에서 **잊은 기술을 되찾고**, 메타몽 캡슐은 **써 보기 전에 무엇인지** 알 수 있게.

## 접근
- **A. 기존 화면에 단계 추가 (선택)**: `dungeonSelect` 에 출전 확인 단계, `box` 메뉴에 "기술 떠올리기"(새 화면 `relearn.js`, 규칙 `core/relearn.js`), `dittoBuild` 에 설명 단계. 기술 설명 그리기는 `summary.js` 의 기술 줄을 공용 함수로 빼서 셋이 같이 씀.
- B. 출격 전용 새 화면: 지금 목록·정보창을 그대로 두면 충분해서 버림.

## 설계 *(내 결정 표시)*

### 출격 게시판
- 정보창에 **주 타입 최대 2개** 배지: 던전 `types` 중 `minorTypes` 가 아닌 앞의 두 개. 사막은 `shownTypes: ['ground']` 로 땅 하나 (데이터에 덮어쓰기 칸). 잠긴 던전은 안 보임. 보조 타입·지형·힌트는 공개 안 함.
- 해금된 던전을 고르면 **출전 확인창**(항상): 출전 멤버를 편성 순서대로 — 초상화·이름·Lv·현재 타입 배지·현재 특성 (메타몽은 빌드의 타입·특성). 문구 "이 멤버로 {던전}에 출전할까?", 선택지 **출전한다 / 돌아간다**. 진행 중 탐험이 있으면 "새로 출전하면 진행 중인 탐험에서 모은 보물을 잃는다." 를 함께 (기존 따로 묻던 확인창은 이걸로 합침).
- 돌아간다·취소 → 방금 고른 던전에 커서 그대로. 이어하기는 지금처럼 바로.
- 멤버가 4마리 넘으면 *(내 결정)* 2열로 줄여 보여 줌 (출전 최대 수 안에서 모두 보임).

### 기술 다시 떠올리기 (편성소)
- 일반 동료 메뉴에 **기술 떠올리기** (메타몽 제외). 무료·무제한, 출전·대기 모두.
- 후보 = (현재 모습 습득표에서 지금 레벨 이하) ∪ (그 개체가 실제로 익혔던 기술 `member.learned`) − 지금 기술. 습득표 순서 → 이력 순.
- 개체 이력 `learned`: 처음 받은 기술·레벨업으로 배운 기술·진화 때 배운 기술·떠올린 기술을 모두 기록, 교체·진화해도 유지. **기존 저장**: 없으면 지금 기술로 채움 (습득표 쪽은 후보에 늘 들어가므로 따로 안 넣음).
- 흐름: 후보 목록 → 고르면 **설명** (타입·분류·위력·명중·사거리·범위 모양·부가효과 태그·설명문) → 빈 칸이 있으면 "배울까?" 확인 → 칸에 넣음. 네 칸이 차 있으면 **잊을 기술 고르기**(고르는 동안 옛 기술과 새 기술을 나란히 비교) → 확인 → 교체. 언제든 취소 = 그대로.
- 후보가 없으면 "떠올릴 기술이 없다."

### 메타몽 빌드 미리보기
- 캡슐을 고르면 먼저 **설명**: 기술 = 위와 같은 기술 설명, 특성 = 설명문 + 지금 특성 설명 나란히, 타입 = 타입 배지와 지금 타입. 확인하면 지금처럼 칸 고르기(기술은 바꿀 기술과 비교) → 최종 확인 → **확정할 때만 캡슐 1개 소모**. 취소하면 빌드·캡슐 그대로 (지금과 같음).
- 위쪽 빌드 영역의 **지금 기술·특성도 골라서 설명을 열람** 가능 (캡슐 없어도).

## 비목표
출격 게시판에서 편성 바꾸기, 기술 떠올리기 비용, 다른 진화 갈래 습득표, 알기술·기술머신, 메타몽 기술 떠올리기.

## 확인
- 테스트: 주 타입 2개·사막 1개·잠김 숨김 / 확인창 멤버·타입·특성(메타몽 빌드) / 진행 중 탐험 문구, 출전 확정 때만 포기, 돌아가기 커서 유지 / 후보 = 습득표(레벨 이하)+이력−지금, 건너뛴 기술·진화 전 기술 포함, 다른 갈래 제외 / 빈 칸 추가·교체·취소 / 이력 기록(레벨업·진화·떠올리기)·저장 이전 / 캡슐: 설명 단계에서 취소하면 소모 없음, 확정 때만 1개.
- 브라우저: 마을 → 게시판 확인창, 편성소 떠올리기, 메타몽 캡슐 설명 (2~3회).
