# 숨겨진 특성 (1~5세대) — 짧은 설계

- 작성일: 2026-11-24 · 상태: 승인 (2026-11-24)
- 바탕: `docs/design/generation-migration.md` (숨겨진 특성 — 결정 4개, 세대 묶음마다), `docs/design/extra-abilities.md` (1칸 = 원래 특성, 숨겨진 4결정), 코덱스 `codex-reviews/2026-11-20-gen5-moves-abilities.md`

## 왜
5세대 추가의 남은 몫. 아끼는 포켓몬을 결정으로 한 단계 더 키우는 성장 — 숨겨진 특성은 보통 일반 특성보다 세다(재생력·가속·우격다짐…).

## 지금 상태 (조사)
- 1~649 중 578종에 숨겨진 특성(9세대 기준), 서로 다른 특성 123개. 71종(대부분 전설)은 없음.
- 이미 효과가 있는 특성 100개 → 데이터만 연결.
- 게임에 없는 5세대 특성 15개, 효과 없음 표시된 특성 6개.
- 6세대 이후 숨겨진 특성(승기·변환자재)이 9세대 데이터에 섞여 있음.
- 동료 저장: `abilitySlot`(0/1) + `abilityUnlocked`. 저장 v10.

## 결정 (사용자)
- **비용: 계열 결정 4개**, 일반 특성 해금(3개)과 **따로** — 일반 해금 없이도 열 수 있음 (2026-11-24).
- **효과를 낼 수 없는 숨겨진 특성은 해금을 잠가 "준비 중"** 으로 표시 — 결정을 쓰고 효과가 없는 일은 없게. 도구·나무열매 작업 때 푼다.
- **새 5세대 특성 11개는 이번에 다 구현.**

## 설계
### 데이터
- `fetch-pokeapi.js`: 종마다 `hidden: abilityId | null` 추가. 일반 슬롯과 같은 규칙 — 숨겨진 특성이 5세대 이후 것이면 `past_abilities` 의 숨겨진 슬롯 중 5세대까지 것으로, 없으면 `null`. 일반 특성과 같은 특성이면 `null`.
- 특성 표(`ABILITIES`)에 새 특성이 들어옴 (이름·설명은 PokeAPI 한국어, SRPG 해석은 `SRPG_ABILITY_TEXT`).

### 동료·저장
- 동료에 `hiddenUnlocked: boolean`, `abilitySlot` 에 숨겨진 칸 값 `'hidden'` 추가. 저장 v11 (옛 저장은 `hiddenUnlocked: false`).
- `abilityOf(m)`: `'hidden'` 이면 `SPECIES[m.species].hidden` (진화형에 없으면 첫 일반 특성).
- `unlockHidden(game, key)` (`progress.js`): 결정 4개, 이유 `none`(숨겨진 특성 없음) · `pending`(준비 중) · `already` · `shards`. 해금하면 바로 숨겨진 특성으로 바뀜. 그 뒤 세 칸 사이 전환은 공짜 (일반 칸 둘 사이 전환은 지금처럼 일반 해금이 있어야).
- 진화: 진화형의 숨겨진 특성으로 따라감. 메타몽은 대상 아님. 적은 이번에 숨겨진 특성을 쓰지 않음 *(내 결정 — 보스 부여는 밸런스 작업 때)*.

### 요약 화면 특성 탭
- 지금 "특성 / 다른 특성" 두 줄 → **최대 세 줄 목록**(일반 1 · 일반 2 · 숨겨진, 숨겨진 줄엔 "숨겨진" 표시). 위아래로 고르고 확인 = 해금 또는 바꾸기.
- 숨겨진 줄 상태: 잠김(`해금 결정 n/4`) · 준비 중(회색, "아직 이 게임에서 효과가 없어 해금할 수 없다") · 열림.

### "준비 중" 특성 (해금 잠금)
긴장감 · 먹보 · 통찰 · 곡예 · 서투름 · 나쁜손버릇 · 수확 · 짓궂은마음 · 달마모드 · 괴짜 — 목록은 `NO_EFFECT` 와 하나로 관리 (효과가 생기면 목록에서 빼면 자동으로 풀림).

### 새 5세대 특성 11개 (코덱스 규칙, 없는 건 본가 그대로)
| 특성 | SRPG 효과 |
|---|---|
| 애널라이즈 | 공격 직전, 살아 있는 모든 포켓몬 중 보유자 스피드가 가장 느리면(공동 최저 포함) 위력 1.3배 *(본가 값; 코덱스 1.5배는 과하다고 보고 본가로 — 사용자 확인)* |
| 심술꾸러기 | 모든 랭크 변화를 반대로 (맵 요소 포함: 전기 거미줄 스피드 −1 → +1) |
| 열폭주 | 화상일 때 특수 공격 위력 1.5배 (화상 데미지는 그대로) |
| 독폭주 | 독·맹독일 때 물리 공격 위력 1.5배 |
| 프렌드가드 | 상하좌우로 붙은 다른 아군이 받는 공격 피해 감소 — 보유자 1마리 30%, 한 마리 더마다 +6%p |
| 헤비메탈 · 라이트메탈 | 몸무게 2배 · 절반 (안다리걸기·풀묶기·헤비봄버·히트스탬프에 반영) |
| 멀티스케일 | HP 가득일 때 받는 피해 절반 |
| 주눅 | 벌레·고스트·악 공격에 맞으면 스피드 +1 |
| 변덕쟁이 | 자기 페이즈 끝마다 (전투 안 해도) 명중·회피 뺀 무작위 능력 하나 +2, 다른 능력 하나 −1 |
| 매직미러 | 보유자 칸과 상하좌우 4칸을 노린 상대 변화기를 시전자에게 되돌림 (한 번만, 되돌린 기술은 다시 안 튐). 보호 범위에 깔리는 압정은 시전자 주변으로 |

## 비목표
적·보스의 숨겨진 특성, 6세대 이후 숨겨진 특성, 특성 2·3칸(`extra-abilities.md`), 짓궂은마음·나무열매·도구 특성의 효과, 특성 등급표 갱신(2칸 작업 때).

## 확인
- 테스트: 데이터(578종 근처에 `hidden`, 6세대 특성이 없음, 일반과 겹치면 null), 해금(비용 4·이유들·일반 해금 없이 가능·준비 중 거절), 진화 따라감, 저장 v10→v11 마이그레이션, 새 특성 11개 각각.
- 브라우저: 요약 화면에서 해금·전환, 실제 전투에서 매직미러 반사와 변덕쟁이 한 번씩.
