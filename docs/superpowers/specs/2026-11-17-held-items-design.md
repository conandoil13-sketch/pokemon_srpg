# 지니는 도구 1차 (바탕 + 그대로 옮기는 도구) — 설계

- 작성일: 2026-11-17 · 상태: 사용자 승인 대기

## 목적
포켓몬에게 도구를 하나씩 지니게 해서 파티 구성에 고민거리를 더한다. 미뤄 둔 도구 관련 기술·특성과 상점의 바탕이 된다.

## 사용자 결정
- 바탕(도구 칸·지니기 화면·얻는 경로) + 지금 전투 규칙에 **그대로 옮길 수 있는 도구 전부**.
- 한 번 쓰는 도구(기합의띠·하얀허브·멘탈허브)는 **층마다 돌아온다**.
- **나무열매는 이번에 넣지 않는다** (나중에 따로 커스텀).

## 접근
- **A. 도구 표 + 기존 계산 자리에 훅 (선택):** `src/data/heldItems.js` 에 도구별 효과 값을 두고, 데미지·급소·명중·차례 끝·장판/날씨 턴·속박 턴 계산이 `heldItem(u)` 를 읽는다. 특성과 같은 자리지만 따로 쌓여서 특성과 함께 적용된다.
- B. 도구를 "두 번째 특성"으로 취급: 특성 훅을 재활용할 수 있지만, 특성 끄기(위액·틀깨기)에 도구까지 꺼지는 등 규칙이 섞여서 고르지 않았다.

## 설계

### 바탕 *(내 결정)*
- 동료마다 `held: 도구 id | null`. 가방 `game.items.held: { [id]: 개수 }` (지닌 것은 가방에서 빠짐). 저장·불러오기에 포함, 모르는 id 는 버림.
- **얻기:** 보물상자 굴림에 도구를 추가 (상자의 20%, 일반 도구 위주 · 생명의구슬·구애 계열·기합의띠는 드물게). 낙엽더미 상자도 같은 표. 다른 보물처럼 층 돌파 때 가방으로, 전멸·포기면 잃음.
- **지니기:** 박스의 포켓몬 메뉴에 "도구" 항목 → 가방 도구 목록(이름 + 한 줄 설명) → 지니기 / 지닌 것 빼기 / 바꾸기. 요약 화면과 전투 정보 창에 지닌 도구 이름.
- **발동 알림:** 특성 알림과 같은 방식으로 "○○의 먹다남은음식!" 같은 짧은 표시.
- 적은 도구를 지니지 않는다 (나중에 보스용으로).

### 도구 (약 45종)
- **타입 강화 1.2배 (17):** 목탄·신비의물방울·기적의씨·자석·녹지않는얼음·검은띠·독바늘·부드러운모래·예리한부리·휘어진스푼·은빛가루·딱딱한돌·저주의부적·용의이빨·검은안경·금속코트·실크스카프.
- **공격:** 힘의머리띠(물리 1.1) · 박식안경(특수 1.1) · 달인의띠(효과 굉장 1.2) · 생명의구슬(1.3, 공격기를 맞히면 최대 HP 1/10 잃음) · 구애머리띠(물리 1.5) · 구애안경(특수 1.5). 구애: 그 층에서 처음 쓴 기술만 쓸 수 있음 *(내 결정 — 층이 바뀌면 풀림)*.
- **회복·버티기:** 먹다남은음식(자기 차례 끝 1/16) · 검은진흙(독 타입 1/16 회복, 아니면 1/8 피해) · 조개껍질방울(준 피해 1/8 회복) · 기합의띠(HP 가득일 때 기절할 피해를 HP 1로, 층마다 1번) · 기합의머리띠(10% 확률로 HP 1로 버팀).
- **급소·명중:** 초점렌즈·예리한손톱(급소 +1) · 광각렌즈(명중 ×1.1) · 빛의가루·느긋한향로(상대 명중 ×0.9).
- **상태·랭크:** 화염구슬·독독구슬(자기 차례 끝에 화상·맹독, 이미 상태이상이면 없음) · 하얀허브(떨어진 랭크를 바로 되돌림, 층마다 1번) · 멘탈허브(헤롱헤롱을 바로 풂, 층마다 1번) · 붉은실(헤롱헤롱에 걸리면 건 쪽도 헤롱헤롱) · 끈적끈적바늘(자기 차례 끝 1/8 피해).
- **지속 턴:** 빛의점토(리플렉터·빛의장막 +3턴) · 축축한바위·뜨거운바위·보송보송바위·차가운바위(해당 날씨 부르기 +3턴) · 끈기갈고리(속박 +2턴) *(턴 수는 내 결정)*.
- **전용:** 전기구슬(피카츄 공격·특공 2배) · 굵은뼈(탕구리·텅구리 공격 2배) · 심해의이빨(진주몽 특공 2배) · 심해의비늘(진주몽 특방 2배) · 메탈파우더(변신 안 한 메타몽 방어 2배) · 럭키펀치(럭키 급소 +2) · 대파(파오리 급소 +2).

## 비목표
나무열매, SRPG식으로 바꿔야 하는 도구(구애스카프·선제공격손톱·검은철구·연기구슬 등), 도구 관련 기술 6개·특성, 상점, 적의 도구, 진화용·플레이트·향로 중복분.

## 확인
- 테스트: 도구별 배수·발동 조건 (대표 하나씩 + 전용 도구), 층마다 돌아오는 1회 도구, 구애 고정과 층 바뀌면 풀림, 상자 굴림에 도구가 나오고 시드가 같으면 같음 (신오 상자 결과는 그대로 — 별도 난수), 저장 왕복·모르는 id 버림, 지니기/빼기가 가방 개수를 맞게 바꿈.
- 브라우저: 저장 백업 → 가방에 도구 몇 개 → 지니기 → 던전에서 먹다남은음식·기합의띠 발동 알림 확인 → 저장 복원.
