# 임시 스테이지 8개 (난이도 곡선만) — 짧은 설계

- 작성일: 2026-11-17 · 상태: 사용자 승인 대기

## 목적
새 맵·기믹을 만들기 전에도 레벨링을 더 할 수 있게, 기믹 없는 임시 스테이지 8개를 신오 동굴 뒤에 이어 붙인다. 나중에 진짜 새 맵을 하나 만들 때마다 그 순서의 임시 스테이지 자리를 대체한다.

## 사용자 결정
- 8개 추가 (총 10단계), 들판·동굴 번갈아, 난이도 곡선만.
- **방법 B:** 곡선 규칙 하나가 "n번째 임시 단계"의 숫자를 계산한다. 진짜 맵은 그 자리에 끼워 넣는다.

## 설계
- `src/data/fillerStages.js`: `fillerStage(n)` (n = 1..8) → 던전 표 한 줄과 같은 모양 `{ id: 'trial-<n>', name, floors, unlock, theme, baseLevel[], budget[], levelCap, early, types, bstCap, stageCap, fallback, boss, clusters, weather }`.
  - 테마: n 홀수 들판(`field`), 짝수 동굴(`cave`). 타입·early·fallback·clusters·weather 는 같은 테마의 신오 던전 값을 쓴다.
  - 층: n 1~2 → 7, 3~5 → 8, 6~8 → 9.
  - 기준 레벨: 시작 = 23 + 7(n−1), 마지막 층 = 시작 + 5 (사이는 고르게). 보스 = 마지막 + 3 = `levelCap`. (표: 23~28/31, 30~35/38 … 72~77/80)
  - 위협도 예산: 층 레벨에 비례 (`budget = round(level × 9)` *(내 결정 — 신오 동굴 마지막 층 19→200 의 비율과 비슷하게)*).
  - 종족값 상한: 470 + 25n (최대 670) *(내 결정)*. 진화 단계 상한: 앞 1/3 층 0, 중간 1, 끝 2; n ≥ 5 부터는 마지막 2층이 2 *(내 결정)*.
  - 이름: "시련의 들판 Ⅰ"·"시련의 동굴 Ⅰ" … (테마별 로마 숫자).
  - 해금 사슬: 1번은 `sinnoh-cave` 돌파 뒤, 그다음은 앞 단계 돌파 뒤.
- `DUNGEONS` = 신오 2개 + `fillerStage(1..8)`. 진짜 맵을 만들면 `REPLACED = { <n>: 진짜 던전 }` 로 그 자리를 바꾸고 해금 사슬은 순서대로 다시 이어진다.
- 레벨 상한 규칙(`levelCapFor`)·적 굴림·보스·보물 등은 그대로 데이터만 따른다.
- 던전 선택 화면: 목록이 화면을 넘으면 커서를 따라 스크롤 (위·아래 화살표 표시) *(내 결정)*.

## 비목표
새 지형·기믹·맵 디자인, 임시 단계 전용 보상·대사, 밸런스 미세 조정(곡선 숫자로 나중에).

## 확인
- 테스트: 8개가 생기고 해금 사슬이 이어짐 / 레벨·상한 곡선 값 / 테마 번갈아 / 대체 슬롯이 사슬을 유지 / 선택 화면에서 10개를 스크롤해 고를 수 있음 / 각 임시 단계 층 생성이 막히지 않음(적·지형 생성 스모크).
- 브라우저에서 선택 화면 스크롤과 임시 1단계 입장 한 번 (저장 백업·복원).
