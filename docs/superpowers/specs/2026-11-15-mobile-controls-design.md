# 모바일 조작 (세로 휴대용 게임기) — 짧은 설계

- 작성일: 2026-11-15 · 상태: 사용자 승인 대기

## 목적
휴대폰에서도 친구들이 배포 페이지로 바로 할 수 있게. 지금은 화면이 최소 2배(512px)로 고정돼 세로 폰에서 잘리고, 취소·턴 종료·정렬은 키보드로만 돼서 폰에서는 못 한다. 에뮬레이터 감성의 게임기 버튼으로 해결한다.

## 사용자 결정
- **세로 휴대용 게임기 모양:** 위에 화면, 아래에 십자키 + A·B + START·SELECT.
- **터치 기기에서만 버튼 표시.** PC 는 지금 그대로(버튼 없음, 화면만 크게).
- **화면 터치 조작도 된다:** 칸·메뉴를 손가락으로 톡 쳐서 고르는 것(지금 마우스 클릭과 같음).

## 설계
- 버튼 대응: 십자키 = 방향키, A = 확인(Z), B = 취소(X), START = 턴 종료(E), SELECT = 박스 정렬(S). 키보드와 **같은 게임 이벤트**를 보낸다(게임 쪽 코드는 거의 그대로).
- 십자키를 누르고 있으면 키보드처럼 반복(`repeat`)되고, 떼면 `release` (마을 계속 걷기).
- 화면 터치: 손가락이 닿으면 그 칸으로 커서 + 클릭(지금 `mousedown` 과 같음), 누른 채 끌면 커서만 따라감. 터치를 따로 받아 늦게 반응하거나 두 번 눌리는 일(브라우저가 터치를 마우스로 바꿔 주는 것)을 막는다. PC 마우스는 지금 그대로.
- 화면 크기: 정수 배율(2배·3배…)이 들어가면 정수, 폰처럼 좁으면 폭(또는 높이)에 맞춘 비정수 배율. 버튼이 보이면 버튼 자리를 뺀 공간에 맞춘다.
- 가로로 돌리면: 화면 가운데, 십자키 왼쪽, A·B 오른쪽, START·SELECT 아래.
- 폰 기본 동작 막기: 두 번 톡 확대·끌어서 스크롤·길게 눌러 메뉴 막기, 아이폰 홈 바 자리(safe area) 비우기.
- 진동: 지원하는 폰에서 버튼 누를 때 짧게(내 결정).
- 버튼은 HTML/CSS 로 그린다(누르기 쉬운 크기, 또렷한 글씨). 어두운 게임기 몸체에 A 빨강·B 파랑 같은 일반적인 색(특정 게임기 디자인을 따라 하지 않음).
- 터치 기기 판정: `(pointer: coarse)` 또는 터치 지원.

## 비목표
버튼 위치·크기 설정, 두 화면 접이식, PC 에서 버튼 보이기.

## 빌더에게 맡기는 것
버튼 크기·간격·색, 반복 간격(키보드 반복과 비슷하게), 파일 배치.

## 확인
- 테스트: 버튼 → 이벤트 대응, 누르고 있기 반복·떼기, 화면 터치 좌표 → 칸, 배율 계산(정수/비정수, 세로/가로).
- 브라우저 패널을 휴대폰 크기·터치로 바꿔 세로·가로 배치와 조작 확인. 실제 폰은 배포 뒤 사용자 확인.
