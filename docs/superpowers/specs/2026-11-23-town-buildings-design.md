# 마을 건물 — 짧은 설계

- 작성일: 2026-11-23 · 상태: 승인 대기
- 바탕: ROADMAP 백로그 "마을 실제 건물 타일" · 코덱스 마을 기획(업적 게시판·의뢰·도전의 문)

## 목적
마을(`src/data/town.js`)의 건물 자리는 지금 바위 덩어리(`^`) 더미다. 이걸 **포켓몬들이 꾸려 사는 마을** 느낌의 진짜 건물 겉모습으로 바꾼다. 사람 집이 아니라 흙·나무·돌·나뭇잎으로 지은 둥근 집과 포켓몬 모양 장식 (탐험대 시리즈의 분위기만 참고, 특정 건물을 옮기지 않음 — 사용자 결정).

## 접근
- **A. 코드로 그린 도트 (선택)**: 던전들처럼 `src/render/townTiles.js` 에 굽기(bake) + 매 프레임 소품. 화풍·색이 기존 도트와 맞고 크기·문 위치를 자유롭게.
- B. 이미지 생성(PixelLab): 화풍이 어긋나기 쉽고 고칠 때마다 크레딧. 버림.
- 실내(들어가는 건물)는 비목표 — 겉모습만 (사용자 결정).

## 설계
- 마을 크기·이동 규칙·상호작용은 그대로 (28×14, 건물 칸은 못 지나감, 표지판·문 앞에서 말 걸기 → 지금 화면). 저장·마을 대사 그대로.
- 건물 *(구상은 사용자 승인, 세부 모양은 내 결정)*:
  - **편성소**: 파낸 큰 나무 그루터기 집 — 둥근 나무문, 이끼·새싹 지붕, 옆 장작더미.
  - **모집소**: 몬스터볼 무늬 둥근 천막 — 꼭대기 깃발 줄, 입구 알 바구니.
  - **상점**: 나뭇잎 줄무늬 차양 노점 — 열매 상자·진열대, 켈리몬은 지금처럼 옆에.
  - **출격 게시판**: 작은 지붕 달린 나무 게시판에 종이 몇 장.
- **미래 시설 빈터** *(사용자 승인)*: 업적 게시판·의뢰소·도전의 문 자리를 지금 잡아 둔다. 말뚝·밧줄로 두른 공사터(지나갈 수 없음) + 표지판 "공사 중이다." *(내 결정)*. 자리: 업적 게시판 = 왼쪽 아래 지금의 2×2 바위 자리, 의뢰소 = 출격 게시판 오른쪽 아래, 도전의 문 = 마을 오른쪽 아래 끝 (구체 칸은 플랜에서).
- 흙길로 건물 문·게시판·출발 자리를 잇고, 꽃·울타리·우편함 소품 *(내 결정)*.
- 타일: 건물 발판은 새 글자로 표시해 `town.js` 걷기 판정에 넣는다 (기존 `^` 더미 대체). 지붕은 발판보다 위로 튀어나오게 그려 입체감.

## 비목표
실내 맵, 새 시설의 기능(업적·의뢰·도전의 문 자체), 낮밤·계절, 마을 확장.
