# 뽑기 동료 해금 + 출전 편성 — 설계 스펙 (B)

- 작성일: 2026-11-13
- 상태: 사용자 리뷰 대기
- 선행: 1~4세대 확장 + 메타몽 주인공 (스펙 A, main `68e5938`), 마을 NPC = 파티 동료(미커밋 변경 포함)

## 1. 목표

던전에서 모은 **코인**으로 **뽑기**를 돌려 1단계 포켓몬을 동료로 해금하고, 편성소에서 메타몽과 함께 출전할 **4마리를 고른다**.

### 성공 기준
1. 적 격파·층 돌파·보물상자로 코인을 얻는다. 전멸하면 이번 탐험 코인을 잃는다(보물 규칙과 동일).
2. 마을 **모집소**에서 코인 100개로 1회 뽑기. 결과는 1단계 포켓몬, 희귀도 3단계(평범·희귀·매우 희귀).
3. 새 포켓몬은 동료 목록에 추가된다. 이미 같은 계열이 있으면 **결정**(중복 기록) +1 — 나중의 알기술·특성 해금용.
4. 편성소에서 출전 4자리를 고른다 (메타몽은 항상 출전, 5번째 칸 고정). 출전하지 않은 동료는 경험치를 받지 않는다.
5. 저장·불러오기(코인, 동료 목록, 출전 멤버, 결정).
6. `npm test` 통과, 브라우저에서 코인 획득 → 뽑기 → 편성 → 새 동료 출전 흐름 동작.

### 범위 밖
알기술·특성 해금(결정 사용처), 10연차, 천장(보장), 동료 방출, 이로치, 뽑기 확률 변경 이벤트.

## 2. 코인

| 획득 | 양 |
|---|---|
| 적 1마리 격파 | `3 + floor(적 레벨 / 3)` |
| 층 돌파 (계단 도착·적 전멸·보스 격파) | `10 × 층` |
| 보물상자 | 진화의돌 15% · 경험 사탕 55% · **코인 주머니 30%** (`20 × 층`) |

- 모두 탐험 보상(`run.loot.coins`)으로 쌓이고, 돌파·귀환 시 `game.coins` 로 지급, 전멸·포기 시 잃는다.
- 층 결산 화면에 "코인 +N" 표시, 층 사이 메뉴에 이번 탐험 누적 코인 표시.

## 3. 뽑기

`src/core/gacha.js` (순수, rng 주입)

- **뽑기 대상**: `stage === 0` ∧ `!legendary` ∧ ≠ 메타몽 (아기 포켓몬 포함).
- **희귀도**: 계열의 **최종 진화형 종족값 합**(갈래가 여럿이면 가장 높은 것) 기준
  - 평범 `< 450` — 70%
  - 희귀 `450 ~ 534` — 25%
  - 매우 희귀 `≥ 535` — 5% (예: 미뇽·딥상어동·애버라스·메탕·애기토스)
- 희귀도를 먼저 뽑고, 그 등급 안에서 균등하게 한 종족.
- **중복 판정**: 같은 계열(1단계 종족 기준)이 이미 동료면 중복 → `game.shards[1단계 종족] += 1`, 메시지 "이미 ○○ 계열이 있다! ○○의 결정을 얻었다."
- **합류 레벨**: 출전 동료 평균 레벨 − 2 (최소 5). 기술은 그 레벨의 시작 기술.
- 비용 100코인. 코인이 부족하면 안내 대사.

### 3.1 모집소 장면 (`src/game/gacha.js`)
- 마을의 "도감 연구소(준비 중)" 표지판 자리를 **모집소**로 바꾼다.
- 화면: 보유 코인, [뽑기 (100코인) / 돌아가기]. 뽑으면 연출(몬스터볼이 흔들림 1.2초 → 희귀도 색 번쩍임 → 포켓몬 등장 + 이름·희귀도) → 다시 메뉴.
- 희귀도 색: 평범 흰색, 희귀 파랑, 매우 희귀 금색.

## 4. 동료 · 출전 편성

- `game.party` = 전체 동료 목록 (메타몽 맨 앞 유지). `game.sortie` = 출전할 동료 종족 4개 (메타몽 제외, 파티 순서와 별개).
- 전투 출전 = `[메타몽, ...sortie]` (5칸). sortie 가 4개보다 적으면 있는 만큼.
- 경험치: 출전한 유닛만 (기존 전투 규칙 그대로 — 맵에 없으면 못 받음). 사탕 경험치도 **출전 멤버에게만**.
- 편성소 화면 확장 (`src/game/party.js`):
  - 메뉴 [출전 멤버 바꾸기, 진화의돌 사용, 돌아가기]
  - 출전 멤버 바꾸기: 동료 목록(메타몽 제외)을 페이지 단위로 보여 주고, 각 항목에 출전 표시. 선택하면 출전 ↔ 대기 전환. 출전이 4마리면 다른 동료를 넣기 전에 한 마리를 빼야 한다 ("출전 자리가 꽉 찼다").
  - 출전 0마리로 확정 불가 ("최소 1마리는 출전해야 한다").
- 마을 NPC: 출전 멤버 우선, 남는 자리(최대 6)에 대기 동료.
- 진화·결정·레벨은 동료별로 유지 (종족으로 식별 — 같은 계열 중복이 없으므로 안전).
