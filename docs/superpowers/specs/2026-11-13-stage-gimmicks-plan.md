# 스테이지 기믹 기획 (날씨 · 지형) — 기획 메모

- 작성일: 2026-11-13 · 상태: 기획 (구현 전, 단계마다 따로 설계 → 계획 → 구현)
- 목적: 층(스테이지)의 조건이 전투 판단을 직접 바꾸게 한다. 던전 종류마다 다른 손맛.

## 사용자 결정
- **날씨는 층 전체 고정** (층에 들어갈 때 정해짐, 배너에 표시).
- **안개 = 명중 하락 + 먼 시야 제한(가벼운 수준)**. 본격적인 시야 제한(전장의 안개)은 **어두운 동굴** 기믹으로 따로.
- **순서: 날씨 먼저** → 지형 기믹을 던전 하나씩.

## 1단계: 날씨 (모든 던전 공통)

| 날씨 | 효과 (본가 4세대) | SRPG 추가 (제안) |
|---|---|---|
| 쾌청 | 불꽃 ×1.5, 물 ×0.5, 얼음 상태 안 걸림 | 얕은 물 일부가 마름(지나갈 수 있음) — 선택 |
| 비 | 물 ×1.5, 불꽃 ×0.5, 번개 명중 100% | 불붙은 칸 즉시 꺼짐, (지형 단계 뒤) 늪 확장 |
| 모래바람 | 바위·땅·강철 외 페이즈 끝 최대 HP 1/16, 바위 특방 ×1.5 | 원거리(사거리 2 이상) 사거리 −1 — 선택 |
| 싸라기눈 | 얼음 외 페이즈 끝 1/16, 눈보라 명중 100% | (지형 단계 뒤) 눈길 확장 |
| 안개 | 명중 −10%p | **먼 시야 제한**: 아군 누구에게서든 4칸 넘게 떨어진 적은 정보창·예상 창에 정체가 "???" 로, 맵에는 흐린 그림자로만 (위치는 보임). 적 AI 도 같은 거리 밖 아군은 노리지 않음 |

- 정해지는 법: 던전마다 날씨 확률표 (예: 들판 맑음 60 · 비 20 · 쾌청 15 · 안개 5). 보스 층은 고정 날씨 가능.
- 화면: 층 시작 배너에 날씨 이름, 맵 위에 pixelfx 날씨 연출(비·눈·모래·안개, `weather` 카테고리), 정보창 구석에 날씨 아이콘.
- 상태이상·랭크·범위 모양과 같은 방식(순수 규칙 모듈 + 데미지 배율 + 페이즈 끝 처리)으로 붙인다.
- 나중 확장: 비바라기·쾌청 같은 날씨 기술(5턴) — 이번 범위 밖.

## 2단계 이후: 지형 기믹 (던전 하나씩)

| 기믹 | 규칙 (제안) | 어울리는 던전 · 날씨 |
|---|---|---|
| 빙판 | 들어가면 그 방향으로 벽·유닛에 막힐 때까지 미끄러짐, 얼음 타입은 안 미끄러짐 | 얼음 동굴 |
| 눈길 | 이동 비용 2 (얼음 타입 1), 싸라기눈이면 늘어남 | 눈 덮인 산길 · 싸라기눈 |
| 늪 | 이동 비용 2, 들어가면 스피드 −1 랭크(3턴), 독·물 타입 영향 없음, 비 오면 늘어남 | 안개 늪 · 안개/비 |
| 낙엽 더미 | 숨기 좋은 칸(회피 +), 불꽃 기술에 맞으면 1~2턴 불타는 칸(지나가면 화상 확률) | 가을 숲 |
| 숨은 포켓몬 | 풀숲·낙엽 속 보이지 않는 적/아이템, 인접하면 튀어나옴(적이면 기습 선공) | 가을 숲, 기존 들판 풀숲에도 소량 |
| 어두운 동굴 | 본격 시야 제한: 아군 주변 n칸만 보임, 빛 기술(플래시 등)로 넓힘 | 어두운 동굴 |

- 지형 그림은 이번에 만든 타일 방식(코드로 그림, 솟는 스프라이트·오토타일)으로 추가.
- 던전 해금 순서(안): 들판 → 동굴 → 가을 숲 → 눈 덮인 산길 → 얼음 동굴 → 안개 늪 → 어두운 동굴.

## 추가 기믹 (사용자 아이디어)

### 괴력 바위
- 맵에 놓인 **밀 수 있는 바위**(지금의 `^` 돌무더기와 다른 새 오브젝트, 지나갈 수 없음).
- **공격기로 바위를 때리면** 때린 방향 반대쪽으로 밀린다. **위력에 따라 밀리는 거리**: 약(≤50) 1칸 · 중(51~89) 2칸 · 강(≥90) 3칸 (이펙트 위력 단계와 같은 구간 — 제안).
- **미는 경로에 있는 모든 캐릭터(적·아군 모두)는 피해를 입고 경로 옆 인접 칸으로 밀려난다.**
- 바위는 벽·물·다른 바위·맵 끝에서 멈춘다.
- 정할 것: 어떤 기술이 밀 수 있나(물리만? 단일 기술만? 범위기도?), 경로 피해량(바위 위력 고정 / 때린 기술 위력 비례 / 최대 HP %), 밀려나는 쪽(왼쪽·오른쪽 중 빈 칸, 둘 다 막히면?), 물에 빠진 바위가 징검다리가 되는지, 적 AI 도 바위를 미는지.

### 텔레포트 판
- **서로 연결된 텔레포트 판들**(같은 색끼리 연결). 이동을 판 위에서 끝내면 연결된 판으로 순간이동.
- **자연 맵에는 안 나오고 도시적인 맵에서만** — 주로 **악당 보스에게 가는 길**(아지트·빌딩형 던전)에 자주 등장.
- 그래서 **도시/아지트 테마**(바닥 타일·벽·장식)와 그 던전이 함께 필요하다.
- 정할 것: 연결 방식(두 개씩 짝 / 여러 개가 순환 / 한쪽 방향), 순간이동 뒤 행동 가능 여부, 도착 판에 누가 서 있으면?, 적도 쓰는지, 연결 표시(색·번호).

### 강풍
- 층에 **바람 방향**이 정해져 있고, **차례(페이즈)가 끝날 때마다 모든 아군·적이 그 방향으로 한 칸씩 밀린다.**
- 벽·물·다른 유닛에 막히면 그 자리. 바람 방향은 맵에 화살표·흐르는 바람 연출(pixelfx)로 표시.
- 정할 것: 매 페이즈 끝마다 양쪽 모두인지(아군 차례 끝에도 적까지 밀리는지) 아니면 끝난 쪽만인지, 비행 타입·무거운 포켓몬 예외, 밀려서 물·용암 같은 위험 칸에 들어가면?, 바람 방향이 층 도중에 바뀌는지, 날씨(1단계)와 함께 걸릴 수 있는지.

### 전설 포켓몬 전용 특수 날씨 (진짜 나중)
- 그란돈 / 가이오가 / 레쿠쟈 / 토네로스 / 볼트로스 / 러브로스 / 랜드로스가 나오는 층(보스전)에는 **각자에 맞는 특수 날씨 기믹**.
- 아이디어 메모 (확정 아님):
  - 그란돈: 끝없는 가뭄 — 물 기술 실패, 물 칸이 마름, 불꽃 강화
  - 가이오가: 큰 비 — 불꽃 기술 실패, 물 칸이 넓어짐
  - 레쿠쟈: 난기류 — 비행 타입 약점 사라짐, 강풍 기믹과 결합
  - 토네로스: 폭풍 — 강풍 기믹 강화판(밀리는 칸 증가·방향 변화)
  - 볼트로스: 뇌우 — 매 페이즈 무작위 칸에 벼락(예고 표시 뒤 떨어짐)
  - 랜드로스: 대지의 힘 — 주기적 지진(땅 위 유닛 피해, 비행 제외) 또는 땅 솟음
  - 러브로스: 봄바람 — 아군·적 무작위 매혹/회복 같은 계절 기믹
- **주의**: 지금 게임 데이터는 1~4세대(493종)라 토네로스·볼트로스·랜드로스(5세대), 러브로스(8세대 레전드 아르세우스)는 **도감·스프라이트 확장이 먼저** 필요하다. 그란돈·가이오가·레쿠쟈는 지금 데이터에 있다.
