# 5세대 포켓몬 추가 (세대 추가 2단계) — 짧은 설계

- 작성일: 2026-11-24 · 상태: 승인 (한 브랜치 · 스프라이트 다운로드, 2026-11-24)
- 바탕: `docs/design/generation-migration.md`, 1단계 `2026-11-24-gen9-baseline-design.md`, 코덱스 `codex-reviews/2026-11-20-gen5-moves-abilities.md` · `2026-11-22-gen5-9-*`

## 목적
494~649번(156종)을 9세대 기준 데이터로 넣는다. 적 풀·뽑기·동료에 자연스럽게 섞여 나오게.

## 지금 상태 (조사)
- 데이터: `tools/fetch-pokeapi.js` 의 `MAX_DEX` 493 · `GEN_LIMIT` 4 를 649 · 5 로 올리면 종·5세대 기술·특성이 함께 들어온다. 5세대 종은 일반 특성이 5세대 특성뿐인 경우가 많아 `GEN_LIMIT` 5 가 꼭 필요.
- 적 풀은 타입으로, 뽑기는 "1단계·비전설·메타몽 아님"으로 고름 → 따로 손대지 않아도 5세대가 섞인다.
- 진화: 칼라마네로식 특수 조건은 6세대 이후 것. 5세대 통신 교환 진화(쪼마리·딱정곤)는 지금 규칙(교환 = 레벨)으로 자동.
- 스프라이트: `assets/sprites/pmd/` 에 1~493만 동봉(141MB). 5세대 것은 없음 → 지금은 임시 도트로 나옴.

## 설계
- `MAX_DEX` 649, `GEN_LIMIT` 5, 재생성. 전설·환상(비크티니·레시라무·제크로무·큐레무·케르디오·메로엣타·게노세크트 …)은 지금처럼 적 풀·뽑기 제외.
- 폼: PokeAPI 기본 폼만 (불비달마 달마모드·메로엣타 스텝폼·큐레무 합체·토네로스 영물폼은 비목표 — 기술·특성 단계에서 필요하면).
- **브랜치 전략** *(사용자 승인)*: 2·3·4단계를 **한 브랜치(`feat/gen5`)에서 이어서** 하고, 코덱스 특수 기술 ~16개·특수 특성 ~20개까지 구현한 뒤 main 에 머지. 그 전엔 특수 기술이 효과 없이 공격기로, 특수 특성은 효과 없이 붙어 있어 main 에 올리면 거짓 설명이 보인다.
- **스프라이트**: PMD SpriteCollab(GitHub `PMDCollab/SpriteCollab`)에서 494~649 의 `sprite/NNNN/`·`portrait/NNNN/` 를 지금과 같은 구성으로 받아 동봉 *(사용자 승인, 약 45MB 예상)*. 없는 번호는 지금처럼 임시 도트, 목록을 보고.
- 저장: 버전 그대로 (새 종만 추가, 기존 데이터 불변).

## 결정 필요
1. 브랜치 전략: 2~4단계를 한 브랜치에서 끝내고 머지 *(추천)* vs 2단계만 먼저 머지(특수 기술·특성은 한동안 효과 없음).
2. 스프라이트 다운로드: SpriteCollab 에서 494~649 받기 (약 45MB, 저장소 크기 ~186MB 로).

## 비목표
특수 기술·특성 효과(3·4단계), 숨겨진 특성, 5세대 도구, 특수 폼, 새 던전.

## 확인
- 테스트: 649종·`validateData`, 5세대 샘플(주리비얀 타입·종족값·진화 레벨), 쪼마리→슈바르고 레벨 진화, 전설 제외, 기존 1~493 데이터 그대로(1단계 골든 값 유지).
- 브라우저: 5세대 적이 나오는 던전 한 판, 뽑기 한 번, 스프라이트 표시.
