# X 메뉴 + 가방 화면 — 짧은 설계

- 작성일: 2026-11-17 · 상태: 사용자 승인 대기

## 목적
모바일에서 박스를 거치지 않고 가방을 열어, 가진 것을 종류별로 보고 지니는 도구를 출전 포켓몬에게 바로 지니게 한다.

## 사용자 결정
- 새 **X 버튼**으로 메뉴를 열고, 메뉴에서 가방으로 간다.
- 가방: **종류별로 나눠 보기**, **도구를 출전 포켓몬에게 바로 지니게 하기**.
- X 메뉴는 **마을에서만** 열린다.

## 접근
- **A. 새 게임 이벤트 `menu` + 가방 장면 (선택):** 키보드·터치에 `{ type: 'menu' }` 를 더하고, 마을 장면이 받으면 작은 메뉴(가방 · 닫기)를 띄운다. 가방은 박스·요약처럼 독립 장면(`src/game/bag.js`)으로 만들어 마을 위에 연다.
- B. 박스 화면에 가방 탭 추가: 박스를 거치지 않는다는 요구와 맞지 않아 고르지 않았다.

## 설계 *(내 결정 표시)*
- **입력:** 터치 패드 A·B 옆에 **X** 버튼(`data-k="x"`), 키보드는 **C** (X 는 이미 취소) *(내 결정)*. 마을 밖에서는 `menu` 이벤트를 무시.
- **X 메뉴:** "가방" · "닫기" 두 줄 (나중에 항목을 늘릴 자리) *(내 결정)*. 취소로 닫힘.
- **가방 화면:** 위에 탭 3개 — **도구** / **진화·뽑기** (진화의돌, 10연속 뽑기 바우처) / **메타몽** (파우더 6종, 캡슐). 좌우로 탭, 위아래로 항목. 항목: 이름 · 개수, 아래에 고른 항목 한 줄 설명. 비면 "아무것도 없다".
- **지니게 하기 (도구 탭):** 도구에서 확인 → 출전 포켓몬 목록(이름 · 지금 지닌 도구) → 고르면 지니게 함 (지닌 게 있으면 바꾸고 원래 것은 가방으로, 기존 `equip`). 목록 맨 위에 출전 포켓몬이 지닌 도구도 "지닌 도구" 줄로 보여 주고, 고르면 빼기(`unequip`) *(내 결정)*. 바뀐 뒤 저장.
- 진화·뽑기·메타몽 탭은 보기만 (쓰는 곳은 지금처럼 박스·뽑기·메타몽 빌드).

## 비목표
마을 밖(던전·층 사이)에서 열기, 버리기, 정렬, 다른 메뉴 항목.

## 확인
- 테스트: 키 C·패드 X → `menu` 이벤트 / 마을에서 menu → X 메뉴, 다른 장면은 무시 / 가방 탭 전환과 항목 개수 / 도구 → 출전 포켓몬 → 지니기·바꾸기·빼기가 가방 개수를 맞게 바꾸고 저장 호출.
- 브라우저: 모바일 크기에서 X 버튼 보임 → 메뉴 → 가방 → 도구 지니기 (저장 백업·복원).
