# 분기 단계 구조 — 짧은 설계

- 작성일: 2026-11-22 · 상태: 승인 (해금 규칙 사용자 수정 2번 반영)
- 바탕: `codex-reviews/2026-11-20-stage-progression.md` (6단계부터 한 단계에 맵 2~3개, 분기는 한 단계로 셈)

## 목적
코덱스 단계표대로 6단계부터 **한 단계에 맵 여러 개(분기)**를 둔다. 분기를 다 해 보려면 앞 단계 분기도 다 깨야 하게 — **하나 깨면 하나가 열린다** *(사용자 결정)*. 이번에는 구조만 — 실제 분기 맵(하수도 등)은 다음 작업.

## 지금
`DUNGEONS` = 신오 2개 + 시련 자리 8칸(`stageSlots`) 한 줄. 각 던전은 `unlock: '앞 던전 id'` 하나.

## 접근
- **A. 자리 하나에 맵 배열 (선택)**: `stageSlots({ 1: 단풍 숲, …, 4: [하수도, 깊은 동굴] })`. 같은 자리 맵은 그 자리 곡선(층·레벨·상한)을 함께 쓰고, `unlock` 은 **앞 단계 맵 id 배열**(그중 하나라도 돌파하면 열림 — 짝 규칙은 배열을 어떻게 채우냐로 표현). 지금 코드의 `unlock` 검사 세 곳을 `unlockedBy(d, cleared)` 하나로 모음.
- B. 단계 객체(`STAGES = [{ n, maps }]`)를 새로 두고 던전 목록을 거기서 펼치기: 깔끔하지만 던전 id 로 찾는 코드가 많아 바꿀 곳이 큼. 버림.

## 설계 *(내 결정 표시)*
- **단계 번호**: 던전마다 `stage` (들판 1 · 동굴 2 · 단풍 숲 3 · 해변 4 · 시티 5 · 시련 자리 4~8 → 6~10단계).
- **해금** *(사용자 결정)* — 앞 단계 분기 수 → 이번 단계 분기 수에 따라:
  - **1 → 여러 개** (시티 → 6단계): 앞 맵 하나뿐이라 돌파하면 다 열림.
  - **같은 수** (2 → 2, 3 → 3): **짝끼리** — 6-1 돌파 → 7-1, 6-2 돌파 → 7-2 *(내 결정: 순서대로 짝)*. 두 맵을 다 하려면 앞 단계 둘 다 깨야 함.
  - **2 → 3** (10 → 11단계): **공통 맵 하나**는 앞 분기 중 아무거나 깨면 열리고, **나머지 둘**은 앞 분기와 하나씩 짝 — 10-1 돌파 → 공통 + 11-2, 10-2 돌파 → 공통 + 11-3 *(사용자 결정)*. 공통 맵은 그 단계 첫 맵 (데이터 순서로 정함).
  - 그 밖(3 → 2 등): 순서대로 짝, 남는 앞 분기는 마지막 맵에 붙음.
  - 여러 개 → 1 (12 → 13 유적): 하나라도 (이번 범위 밖, 규칙만).
  - 예전 저장도 `unlockFromCleared` 로 자동.
- **레벨 상한**(`levelCapFor`): "아직 하나도 못 깬 첫 단계"의 상한. 분기 중 하나만 깨도 그 단계는 깬 셈 (진행은 한 줄기로 충분).
- **임시 스테이지와 분기** *(내 결정)*: 그 자리에 진짜 맵이 하나라도 생기면 임시 스테이지(시련의 ○○)는 **빠진다**. 진짜 맵이 없는 자리는 지금처럼 임시 스테이지 하나.
- **저장 이전** *(내 결정)*: 임시 자리가 분기 맵들로 바뀌면 예전 `trial-n` 기록(해금·돌파·최고 층·진행 중 탐험)은 그 자리 **첫 분기 맵**으로 옮김 (지금 `RENAMED` 규칙 그대로).
- **던전 선택 화면** *(내 결정)*:
  - 목록에 단계 머리 없이 맵 이름 앞에 단계 표시: `6-1 하수도`, `6-2 깊은 동굴` (분기 없는 단계는 이름만).
  - 잠긴 맵 설명: `any` 면 "하수도 또는 깊은 동굴 돌파 시 해금", 하나면 "하수도 돌파 시 해금", 
  - 같은 단계 분기 중 하나를 깨면 나머지 분기에도 ★ 대신 작은 "단계 돌파" 표시는 **안 함** — 맵마다 자기 ★ 만.
- 이번에는 **분기가 실제로 있는 단계가 없음** (하수도가 생길 때 처음 쓰임). 테스트는 가짜 분기 맵으로.

## 비목표
11~13단계 추가(최종장 유적), 분기 선택이 최종 보스에 영향 주기(유적 기획), 단계마다 다른 보상.

## 확인
- 테스트(가짜 분기): 1→2 둘 다 열림, 2→2 짝끼리만 열림, 2→3 하나 깨면 공통 + 짝 2개·둘 깨면 3개 (탐험 결산 경로 + `unlockFromCleared`); 같은 자리 맵은 같은 단계·같은 곡선; `levelCapFor` 가 분기 하나 돌파 뒤 다음 단계로 넘어감; 임시 스테이지가 빠짐; `trial-n` 저장 이전; 지금 던전 목록·골든 해시 그대로.
- 브라우저: 던전 선택 화면 (가짜 분기로 잠깐 띄워 보기, 소리 끄기 + 저장 백업·복원).
