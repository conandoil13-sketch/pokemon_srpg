# 2칸 특성 뽑기 — 설계

- 작성: 2026-11-24 · 기반 기획: `docs/design/extra-abilities.md` (확정)
- 범위: **2칸(무작위 특성)만, 내 포켓몬만.** 3칸(SRPG 전용 특성·상점), 적의 2칸 특성, 각성의 구슬은 이번에 하지 않는다.

## 왜
후반으로 갈수록 "내 포켓몬을 내 방식으로" 키우는 성장. 원래 특성(1칸)에 무작위 특성 하나를 더 얹어, 같은 종이라도 개체마다 다른 맛을 낸다. 결정(계열 재료)의 새 사용처이기도 하다.

## 목표 / 비목표 / 실패 조건
- 목표: 편성소에서 결정 2개로 2칸 특성을 굴리고, 그 특성이 전투에서 1칸과 똑같이 작동한다.
- 비목표: 3칸, 적 2칸, 각성의 구슬(얻을 곳이 아직 없음 — 보스 레이드 때 함께), 2칸 특성 고르기(무조건 무작위).
- 실패 조건: 2칸 특성이 일부 상황에서만 작동하거나(특성 검사를 한 곳이라도 놓침), 1칸 특성 동작이 바뀜, 기존 저장이 깨짐.

## 접근
| 방식 | 장단점 | 결정 |
|---|---|---|
| 유닛에 `ability2` 를 두고, 특성 검사를 전부 "두 칸 중 하나라도"로 (`has()`·`abilitiesOf()`) | 검사 약 70곳 수정. 대신 2칸이 1칸과 완전히 같은 대접 | **채택** *(내 결정)* |
| 2칸은 별도 훅(공격 배율·차례 끝 등) 몇 곳만 | 수정은 적지만 특성마다 작동 여부가 갈림 → 실패 조건에 걸림 | 버림 |
| 굴리는 곳: 자세히 보기 특성 페이지 / **편성소** / 둘 다 | | **편성소** (사용자 결정) |

## 규칙
**굴리기** *(기획서 그대로)*
- 비용: 그 동료 계열 결정 2개 (`game.shards[계열 첫 종]`). 메타몽은 메타몽 결정.
- 등급 확률: C 50% · B 30% · A 15% · S 5%. 등급 안에서는 고르게.
- 후보: 등급표에 있는 특성 중 **SS 제외 · 효과 없는 특성(`inactive`) 제외 · 지금 1칸 특성 제외**. 뽑힌 등급에 후보가 없으면 그 아래 등급, 그래도 없으면 위 등급 *(내 결정)*.
- 다시 굴리면 이전 2칸 특성은 사라진다(되돌리기 없음). 같은 특성이 다시 나올 수 있다 *(내 결정 — 단순함)*.
- 난수: 순수 함수, 시드 = 저장 카운터 `game.extraSeq` (상점 `seedOf` 와 같은 방식, 다른 소금값). 굴릴 때마다 +1.

**유지** *(내 결정)*
- 2칸은 동료에 붙는다: 진화·폼 변경·1칸 해금/전환에도 그대로. "한 마리 더"로 데려온 개체는 2칸 없이 시작.
- 이미 가진 2칸 특성이 나중에 등급표에서 SS 가 되어도 그대로 둔다 (다시 굴릴 때만 후보에서 빠짐).
- 1칸이 나중에 2칸과 같아지면(진화·전환으로) 그대로 두되 화면에 "1칸과 같음"으로 흐리게. 효과는 한 번만.

**전투** *(내 결정, 기획서 메모 따름)*
- 전투 유닛: `ability`(1칸) + `ability2`(2칸, 없으면 null). 적은 늘 null.
- `has(u, id)` 와 새 `abilitiesOf(u)`(켜진 특성 목록) 가 두 칸을 다 본다. 특성 표 조회(`PINCH[…]`, `WEATHER_SETTER[…]`, `CONTACT_AILMENT[…]`, `STATUS_IMMUNE[…]`, `REDIRECT[…]` 등)는 두 칸을 모두 돌며, 둘 다 해당하면 둘 다 적용(배율은 곱).
- 위액(특성 끄기): 두 칸 다 꺼짐. 지금 `abilityOff` 를 거치지 않고 `.ability` 를 직접 읽는 곳(해감액·천진·헤비/라이트메탈·발광 등)도 이번에 `has`/`abilitiesOf` 로 바꿔 위액이 두 칸 다 끄게 한다.
- 서로 다른 날씨 특성 두 개: **1칸 날씨만 발동** (2칸 날씨 특성은 날씨를 부르지 않음, 그 밖의 효과는 없음) *(사용자 결정)*.
- 트레이스: 트레이스가 있는 칸이 상대 1칸 특성으로 바뀐다.
- 미라(접촉)·고민씨: **1칸만** 미라/불면으로 바뀌고 **2칸은 남는다** (2칸은 무작위로 얹은 덤이라서) *(사용자 결정)*. 쓰러진 기록에는 원래 1칸을 남김(지금처럼).
- 특성 발동 대사·이펙트는 특성 id 기준이라 어느 칸이든 같다.
- AI 의 특성 검사도 두 칸을 본다(같은 `has`).

## 화면
**편성소 동료 메뉴**에 `특성 각성` 항목 (기술 떠올리기 옆, 메타몽은 메타몽 빌드 옆 *(내 결정)*).
- 결정이 모자라면 회색, 누르면 이유: `○○ 계열 결정이 모자라다 (1/2)`.
- 열면 한 화면:
  ```
  특성 각성                       ○○ 계열 결정 5개
  1칸  맹화
  2칸  테크니션 [S]   위력 60 이하 기술의 위력이 1.5배
  ─────────────
  확인: 결정 2개로 굴리기 · 취소: 닫기
  확률  S 5% · A 15% · B 30% · C 50%
  ```
- 확인 → 2칸이 있으면 `지금 2칸 테크니션은 사라진다. 굴릴까?` / 없으면 `결정 2개로 굴릴까?` (예/아니오).
- **굴림 연출 — 등급 룰렛** *(사용자 결정)*
  1. 결과(등급·특성)는 **굴리기 전에 먼저 정해 둔다.** 연출은 그 결과를 보여 줄 뿐이다.
  2. **기본 룰렛**: C·B·A 세 색 칸이 도는 룰렛.
  3. 결과가 S면 도는 중간에 **업그레이드 연출**(번쩍임·흔들림 + `고급 룰렛!` 글자)이 뜨고 룰렛에 S 칸이 더해진 **고급 룰렛**으로 바뀐 뒤 S에 멈춘다. S가 아니면 대개 업그레이드 없이 기본 룰렛에서 그 등급에 멈추지만, **가끔 낚시**: 결과가 A면 30%, B면 10% 확률로 업그레이드 연출까지 나온 뒤 고급 룰렛이 그 등급에 멈춘다 (S를 아슬아슬하게 비껴가는 느낌) *(낚시는 사용자 결정, 확률은 내 결정)*. 낚시 여부도 굴릴 때 결과와 함께 미리 정한다.
  4. 칸이 멈추면 등급 색이 확정되고, 그 **등급 색이 걷히면서** 특성 이름과 설명이 딱 나타난다.
  5. 전체 약 2~3초(S는 조금 더), 확인으로 건너뛰면 바로 결과.
  - 등급 색: S 금 · A 빨강 · B 파랑 · C 회색 *(내 결정)*.
- 같은 화면에서 바로 다시 굴릴 수 있다.

**자세히 보기 특성 페이지**: 행 아래 `2칸` 줄에 지금 2칸 특성·등급(없으면 `없음 · 편성소 특성 각성에서`). 여기선 보기만 한다.
**전투 정보창**: 특성 줄에 2칸이 있으면 `특성 맹화 · 테크니션`.

## 데이터
- 동료: `extraAbility: id | null` (등급은 표에서 찾음 — 저장하지 않음).
- 저장 v11 → **v12**: 없으면 null, `game.extraSeq` 없으면 0. 정리할 때 `ABILITIES` 에 없는 id 는 null.
- 등급표 `src/data/abilityTiers.js`: `{ id: 'SS'|'S'|'A'|'B'|'C' }`. 기획서 표 + 아래 34개.

### 새로 매긴 등급 (34개, 이 게임의 SRPG 효과 기준) *(내 제안)*
- **S**: 멀티스케일 · 우격다짐 · 재생력
- **A**: 매직미러 · 자기과신 · 승리의별 · 프렌드가드 · 테라볼티지 · 터보블레이즈 · 모래헤치기 · 변덕쟁이
- **B**: 애널라이즈 · 심술꾸러기(랭크업 기술이 손해가 될 수 있음) · 저주받은바디 · 오기 · 열폭주 · 독폭주 · 치유의마음 · 틈새포착 · 철가시 · 정의의마음 · 미라 · 방진 · 독수 · 모래의힘 · 초식 · 텔레파시 · 깨어진갑옷 · 미라클스킨
- **C**: 부풀린가슴 · 헤비메탈 · 라이트메탈 · 주눅
- **SS(후보 제외)**: 무기력 (손해만 봄)

효과 없는 14개(통찰·먹보·수확·일루전·괴짜·서투름·멀티타입·나쁜손버릇·짓궂은마음·시간벌기·점착·곡예·긴장감·달마모드)는 등급과 관계없이 후보에서 빠지고, 효과가 생기면 자동으로 들어온다(등급이 있을 때).

## 테스트 (구현자가 확인할 것)
- 굴림: 시드 고정 결과, 등급 분포(많이 굴려 대략 50/30/15/5), SS·inactive·1칸 제외, 결정 2개 차감·모자라면 거절, 다시 굴리면 교체, 카운터 증가.
- 연출: 결과가 연출 전에 정해짐(연출 단계는 결과를 바꾸지 않음), S면 늘 업그레이드, A·B는 미리 정한 낚시일 때만 업그레이드, C는 업그레이드 없음, 멈추는 칸 = 결과 등급.
- 전투: 2칸 특성이 1칸처럼 작동 — 대표로 배율형(테크니션), 표 조회형(맹화·날씨·접촉 상태이상·면역·피뢰침), 차례 끝형(재생력·탈피), 상대가 보는 형(위협·틀깨기·해감액). 위액이 두 칸을 끔. 날씨 두 개면 1칸 날씨, 미라·고민씨 뒤에도 2칸 유지, 트레이스 규칙.
- 1칸만 있는 기존 동작 회귀 없음(전체 테스트 통과).
- 저장: v11 → v12 이전, 잘못된 id 정리.

## 구현자 재량
- 특성 검사 리팩터링 방식(직접 비교 → `has`, 표 조회 → `abilitiesOf` 순회)의 세부, 함수 이름.
- 굴림 화면 배치·연출 세부(위 스케치 범위 안에서).
