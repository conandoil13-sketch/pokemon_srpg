# 8세대 도입 기획 · 특성

## 멸망의바디

**보스는 멸망의바디를 보유할 수 없다.** 보스의 모든 특성 슬롯에 적용한다. 보스가 접촉 공격으로 다른 포켓몬의 멸망의바디를 발동시킬 수는 있다.

접촉 공격을 받으면 특성 보유자와 접촉자에게 3턴 카운트를 표시한다. 둘 사이의 거리가 충분히 벌어지면 카운트를 해제한다. 해제에 필요한 정확한 거리는 미정이다.

| 카운트가 끝났을 때 | 특성 보유자 | 접촉 공격을 한 포켓몬 |
|---|---|---|
| 일반 포켓몬이 접촉 | 기절 | 기절 |
| 보스가 접촉 | 기절 | **특성 보유자의 최대 HP**만큼 HP 감소 |

## 행동과 특성 슬롯

| 특성 | 적용할 규칙 |
|---|---|
| 퀵드로 | 자기 페이즈 시작에 30% 확률로 공격기 전용 보너스 행동을 얻는다. [페이즈별 보너스 행동](./2026-11-20-phase-bonus-actions.md) |
| 화학변화가스 | 보유자 주변 2칸에서 피아 공통으로 다른 포켓몬의 메인 특성만 억제한다. 부유가 꺼지면 현재 칸에 머물 수 있는지 확인하고 필요하면 착지 판정을 한다. |
| 떠도는영혼 | 메인 슬롯에만 붙는다. 접촉 공격을 받으면 보유자와 공격자의 메인 특성을 교환하고 해당 층 동안 유지한다. |
| 무아지경 | 물리기 위력을 1.5배로 높이고 처음 선택한 기술에 고정한다. 비전투 판정을 충족하면 기술 고정을 해제한다. 변화기를 사용한 턴도 비전투로 세지 않는다. |
| 보이지않는주먹 | 접촉기는 방어와 고대의팔찌의 자동 방어를 관통한다. 접촉 범위기는 와이드가드도 관통한다. |

## 지형과 범위

| 특성 | 적용할 규칙 |
|---|---|
| 미러아머 | 기술·특성에 의한 랭크 하락은 시전자에게 반사한다. 버섯 포자 등 반사할 상대가 없는 지형 효과는 랭크 하락만 무효화한다. |
| 솜털 | 피격 때마다 보유자 중심 3×3에서 자신을 제외한 피아 모두의 스피드를 1랭크 낮춘다. 연속기는 실제 피격 횟수만큼 발동한다. |
| 파워스폿 | 상하좌우 직선 1~2칸의 아군이 쓰는 기술의 위력을 1.3배로 높인다. 여러 보유자가 지원하면 배율이 중첩된다. |
| 강철정신 | 보유자 자신과 상하좌우 직선 1~2칸의 아군이 쓰는 강철 기술의 위력을 1.5배로 높인다. 여러 보유자가 지원하면 배율이 중첩된다. |
| 파스텔베일 | 자신과 반경 2칸 아군의 독을 예방하고 이미 걸린 독을 치료한다. 하수도 독 웅덩이의 지형 피해는 그대로 적용한다. |
| 배리어프리 | 보유자가 첫 기술을 쓸 때 반경 2칸 안의 양측 대상에게 적용된 리플렉터·빛의장막·오로라베일을 제거한다. |
| 기묘한약 | 보유자가 첫 기술을 쓸 때 반경 2칸 안의 동료에게 쌓인 상승·하락 랭크를 초기화한다. |
| 의태 | 필드 생성·교체·해제로 타입이 바뀔 때 지형 통과와 면역을 함께 갱신한다. 현재 칸에 머물 수 없게 되면 즉시 착지를 판정한다. |

## 먹이와 연출

| 특성 | 적용할 규칙 |
|---|---|
| 숙성 | 보유자가 한 층에서 처음 먹는 나무열매 한 개의 효과를 2배로 적용한다. 두 번째부터는 원래 효과를 적용한다. 볼가득넣기의 섭취 기록에는 첫 열매도 한 개로 센다. |
| 그대로꿀꺽미사일 | 윽우지가 파도타기나 다이빙으로 먹이를 물어오면 그 순간 “윽우지가 찌로꼬치를 물어 왔다!” 또는 “윽우지가 피카츄를 물어 왔다!”를 표시한다. 같은 스프라이트를 사용해도 먹이 종류를 구분할 수 있게 한다. |

## 기존 판정 연결

리베로는 변환자재의 타입 변경 규칙을, 백의울음·흑의울음은 자기과신의 처치 수 판정을 재사용한다. 스크루지느러미·굳건한신념은 날따름·스포트라이트 등의 표적 유도를 무시한다. 벽과 엄폐는 해당 기술의 사거리·조준 규칙을 따른다.
