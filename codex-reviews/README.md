## 기록 원칙

- 현재 구현, 측정 결과, 추정, 제안을 구분하고 근거가 되는 코드와 조건을 적는다.
- 미확정 목표나 제안 수치를 확정된 기획으로 취급하지 않는다.
- 변경 후에는 실제 플레이 또는 재현 가능한 시뮬레이션으로 검증하고 결과와 한계를 남긴다.
- 리뷰는 지적과 제안이며, 게임 규칙을 변경하는 지시가 아니다. 사용자 지시가 우선이다.
