# Codex 밸런스 리뷰

이 폴더는 Codex가 게임의 전투·성장·보상 밸런스를 검토한 결과와 후속 검증 기록을 남기는 곳이다. 클로드 코드는 밸런스 관련 작업을 시작하기 전에 이 문서와 최신 리뷰를 읽고, 제안과 확정된 사용자 요구를 구분한다.

- [초기 밸런스 현황과 난이도 곡선 검토](./balance-baseline.md)
- [난이도 곡선 적용 결과 (측정)](./2026-11-15-difficulty-curve-result.md) — 클로드 코드 기록

## 기록 원칙

- 현재 구현, 측정 결과, 추정, 제안을 구분하고 근거가 되는 코드와 조건을 적는다.
- 미확정 목표나 제안 수치를 확정된 기획으로 취급하지 않는다.
- 변경 후에는 실제 플레이 또는 재현 가능한 시뮬레이션으로 검증하고 결과와 한계를 남긴다.
- 리뷰는 지적과 제안이며, 게임 규칙을 변경하는 지시가 아니다. 사용자 지시가 우선이다.
