# 긴급패치 목록

## 압정뿌리기 · 한 이동에서 시전자당 피해 1회

**상태** · 구현 완료 (2026-11-22, 클로드 코드 · tests/field.test.js `hotfix:` 테스트 5개)

한 포켓몬이 한 번의 이동으로 같은 시전자가 깐 압정 여러 칸을 통과하면 칸마다 피해를 받는 현상이 보고됐다. 첫 번째로 피해를 받은 칸에서만 해당 시전자의 압정 피해를 적용한다. 같은 시전자가 서로 다른 차례에 설치한 압정도 한 이동에서는 합쳐서 1회로 센다.

| 이동 경로 | 기대 결과 |
|---|---|
| A가 한 번에 설치한 압정 세 칸을 연속 통과 | 첫 칸에서만 피해 1회 |
| A의 압정 → B의 압정 → A가 나중에 설치한 압정 | A와 B에게 각각 1회, 총 2회 |
| 같은 포켓몬이 다음 이동에서 A의 압정을 다시 밟음 | 새 이동이므로 A에게 다시 1회 |
| 다른 포켓몬이 같은 경로로 이동 | 각 포켓몬의 이동별로 독립 판정 |

**구현 확인점** · 현재 압정 칸에는 설치한 진영만 기록된다. 설치 시 시전자 개체 ID를 남기고, 이동 경로마다 이미 피해를 준 시전자를 기록한다. 걷기와 강제 이동 모두 경로 하나를 한 이동으로 처리한다. 사망 예상 칸을 계산하는 경로 미리보기도 같은 제한을 적용해야 실제로 살아남는 칸에서 이동이 잘리지 않는다. [압정 설치·피해·경로 예측](../src/core/field.js) · [이동 처리](../src/core/battle.js)
