# 6세대 도입 기획 · 특성

질풍날개와 선제공격손톱은 매 자기 진영 페이즈 시작에 독립적으로 발동한다. 질풍날개는 시작 시 HP가 가득 차면 비행 기술 전용 행동 1회를 얻는다. 전체 순서는 [선공 도구·특성과 스피드 보너스 행동](./2026-11-20-phase-bonus-actions.md)을 따른다.

| 특성 | 기획 규칙 |
|---|---|
| 변환자재 | 층당 처음으로 타입이 실제 변경될 때 1회 발동한다. 사용한 기술의 단일 타입이 되며 그 타입의 특수 능력, 지형 통과 및 면역을 얻는다. 먼저 적용된 핼러윈·숲의저주의 추가 타입도 교체한다. 기술을 전혀 쓰지 않고 기술 피해도 받지 않은 차례를 보내면 원래 타입으로 돌아간다. 사용 횟수는 다음 층에서 갱신한다. |
| 배틀스위치 | 킬가르도 전용. 공격기 사용 직전에 블레이드폼, 킹실드 사용 직전에 실드폼이 된다. |
| 공생 | 6세대 도입 대상에서 제외한다. 플라베베·플라엣테·플라제스는 일반 특성 플라워베일을 사용할 수 있다. |
| 매지션 | 빈손인 보유자가 공격으로 맞힌 상대의 도구 하나를 훔친다. 도구 소유권은 [나쁜손버릇 규칙](./2026-11-20-gen5-moves-abilities.md)을 따른다. 후보가 1개면 획득하고 2개면 하나를 선택한다. 3개 이상이면 무작위로 2개를 남긴 뒤 하나를 선택한다. 선택한 도구만 이전하는 것으로 해석했다. |
| 아로마베일 | 자신과 주변 2칸 아군을 도발·앙코르·사슬묶기·트집·회복봉인·헤롱헤롱에서 보호한다. |
| 플라워베일 | 주변 3칸의 같은 편 풀 타입을 주요 상태이상과 외부 요인에 의한 랭크 하락에서 보호한다. 맵 요소가 일으키는 랭크 하락에도 적용한다. |
| 스위트베일 | 자신과 주변 2칸 아군의 수면 발생을 막는다. |
| 다크오라 · 페어리오라 | 해당 타입 기술의 위력을 약 1.33배로 높인다. 보스가 보유하면 전장 전체, 플레이어가 사용하면 보유자 주변 3칸에 적용한다. 범위 안에서는 양 진영이 영향을 받는다. |
| 오라브레이크 | 보스는 전장 전체, 플레이어는 주변 3칸에 적용한다. 오라와 오라브레이크가 함께 적용되는 곳에서는 해당 타입의 기술 위력이 0.75배가 된다. |

## 전용 폼 도입 시 적용

- **부자유친**은 대상 공격기의 두 번째 타격을 첫 타격 위력의 25%로 처리한다. 두 번째 타격도 프레셔의 방어 횟수를 소모하고 접촉기라면 울퉁불퉁멧·철가시를 다시 발동시킨다.
- **시작의바다·끝의대지**는 각각 원시가이오가의 강한 비로 불꽃 공격기를, 원시그란돈의 강한 햇살로 물 공격기를 무효화한다. **델타스트림**은 메가레쿠쟈의 난기류로 비행 타입에서 비롯된 약점을 상쇄한다. 이 날씨들은 일반 날씨보다 우선하며, 유지하는 보유자가 전장을 떠나면 종료된다. [전장 필드](./2026-11-20-gen6-moves.md)와 공존한다.
