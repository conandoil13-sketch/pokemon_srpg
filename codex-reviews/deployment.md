# GitHub 및 테스트 배포

- GitHub 저장소: https://github.com/conandoil13-sketch/pokemon_srpg
- Git 원격 주소: https://github.com/conandoil13-sketch/pokemon_srpg.git
- Pages 예상 주소: https://conandoil13-sketch.github.io/pokemon_srpg/
- 배포 용도: 브라우저 테스트. Pages 설정 및 실제 배포 상태는 GitHub에서 확인할 것.
- 정적 웹 게임이며 저장 데이터는 브라우저별 localStorage에 보관된다.
- `assets/sprites/pmd/`의 로컬 스프라이트 팩과 `SpriteCollab-master/`는 `.gitignore`에 따라 배포되지 않는다. 없는 스프라이트는 게임의 대체 도트가 표시된다.
- 변경을 배포하기 전 Git 원격과 브랜치, Pages 설정 및 배포 결과를 확인한다.
