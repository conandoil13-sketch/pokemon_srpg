# 9세대 도입 기획 · 본편과 DLC 특성

## 첫 기술과 비전투 판정

| 특성 | 적용할 규칙 |
|---|---|
| 협연 | 층에서 첫 기술 사용을 확정하면 기술 효과가 나가기 전에 반경 2칸의 다른 아군 한 마리를 무작위로 고른다. 상승 랭크가 많이 쌓인 아군의 선택 확률을 조금 높인다. 선택한 아군의 상승·하락 랭크를 함께 복사하며, 복사본은 원본의 남은 시간과 관계없이 **3턴간 유지**된다. 추첨 가중치의 정확한 수치는 미정이다. |
| 대접 | 첫 기술 사용 직전에 상하좌우 인접 아군 중 한 마리를 직접 선택해 대상 최대 HP의 ¼을 회복한다. 변화기도 쓰지 않는 비전투 조건을 충족하면 재발동 기회를 얻고 다시 대상을 고른다. |
| 감미로운꿀 | 층 첫 기술 사용 직전에 반경 2칸 안의 적 회피율을 1랭크 낮춘다. 첫 기술부터 낮아진 회피율을 적용한다. |
| 마이티체인지 | 돌핀맨이 퀵턴으로 출발 칸에 복귀하면 마이티폼이 된다. 해당 층에서 한 번 이상 교전한 뒤 변화기도 쓰지 않는 비전투 조건을 충족해도 변신한다. 변신은 해당 층 동안 유지한다. |

## 전투 위치·강제 이동·설치물

| 특성 | 적용할 규칙 |
|---|---|
| 사령탑 | 싸리용이 아군 어써러셔와 상하좌우로 인접하면 합류해 한 칸을 점유한다. 어써러셔의 공격·방어·특공·특방·스피드가 각각 2랭크 오른다. 합체 중에는 어써러셔만 행동하고 싸리용은 독립 피격 대상에서 빠진다. 어써러셔가 기절하면 싸리용이 그 칸에 나온다. [한판내기](./2026-11-22-gen9-moves.md) |
| 파수견 | 위협을 받으면 공격이 1랭크 오른다. 상대가 일으킨 밀치기·끌어당기기를 막는다. 해류와 분출구 등 맵의 강제 이동은 적용한다. |
| 독치장 | 물리 공격으로 피해를 받으면 **공격자** 인접 8칸 중 무작위로 서로 다른 4칸에 독압정을 설치한다. 설치 가능한 칸이 부족하면 가능한 만큼만 설치한다. 연속 타격은 공격 기술 한 번당 설치 1회로 센다. |
| 편승 | 반경 3칸의 적이 얻은 랭크 상승을 같은 양만큼 복사한다. 편승으로 복사한 상승은 다시 편승을 유발하지 않는다. |
| 총대장 | 이번 층에서 현재 기절한 출전 동료 한 마리당 공격 위력 +10%, 최대 +50%. 동료가 부활하면 보정도 즉시 줄어든다. |
| 되새김질 | 보유자가 마지막으로 먹은 열매의 효과를 다음 자기 턴 끝에 한 번 더 받는다. 이때도 열매 섭취로 처리해 다른 열매 연동 특성과 볼가득넣기의 섭취 수에 반영한다. 되새김질 자체를 다시 예약하지 않는다. |
| 재앙의그릇·재앙의검·재앙의목간·재앙의구슬 | 각각 특공·방어·공격·특방에 ×0.75 보정을 건다. 보스는 전장 전체, 아군 보유자는 반경 3칸에서 자신을 제외한 피아에게 적용한다. 여러 보유자의 효과가 겹치면 각 배율을 중첩한다. 랭크 하락으로 처리하지 않아 탈출팩·분풀이를 유발하지 않는다. |

## 날씨·필드·지형

| 특성 | 적용할 규칙 |
|---|---|
| 고대활성·쿼크차지 | 각각 햇살·일렉트릭필드 또는 부스트에너지로 발동한다. 발동 시점의 최고 능력을 1.3배로 강화하며 스피드면 1.5배다. 날씨·필드로 얻은 효과는 해당 조건이 끝나면 풀린다. 부스트에너지로 얻은 효과는 보유자가 전장에서 이탈할 때까지 유지된다. |
| 열교환 | 화상에 면역이며 불꽃 기술에 맞으면 공격 +1. 현무암 등 불꽃 지형 피해에는 피해 면역만 적용한다. |
| 바람타기·풍력발전 | 바람타기는 바람 기술을 무효화하고 공격 +1, 풍력발전은 바람 기술에 맞으면 다음 전기 기술을 강화하는 충전을 얻는다. 아군 순풍 시작에도 각각 발동한다. 두 특성은 추후 정리할 전체 바람 기술 분류를 공유한다. |
| 심안 | 노말·격투 기술로 고스트를 타격하고, 상대의 회피 랭크 상승을 무시하며 자신의 명중 랭크 하락을 막는다. 지형 회피 보너스는 최대 10%p만 상쇄한다. 예를 들어 +20%p 수풀에서는 +10%p가 남는다. |

## 기존 규칙과 연결할 특성

| 특성 | 적용 기준 |
|---|---|
| 가시지않는향기 | 미라와 같이 접촉한 공격자의 메인 특성 슬롯을 교체한다. |
| 넘치는씨 | 공격에 맞으면 기존 필드를 그래스필드로 덮어쓴다. |
| 분노의껍질 | 공격 피해로 HP가 절반 초과에서 절반 이하가 되면 공격·특공·스피드 +1, 방어·특방 −1. |
| 정화의소금·노릇노릇바디 | 정화의소금은 주요 상태이상 면역과 고스트 기술 피해 반감. 노릇노릇바디는 불꽃 기술 무효와 방어 +2. |
| 바위나르기·예리함 | 각각 바위 기술·베기 기술 위력 1.5배. |
| 전기로바꾸기 | 공격으로 피해를 받으면 다음 전기 기술을 강화하는 충전을 얻는다. |
| 황금몸 | 다른 포켓몬이 보유자에게 쓰는 변화기를 막는다. 아군 지원기도 포함한다. 고대의왕관과 같은 판정을 사용한다. |
| 진홍빛고동·하드론엔진 | 등장 시 각각 햇살·일렉트릭필드를 만들고 해당 조건에서 자신의 공격·특공을 각각 약 1.33배로 높인다. 날씨와 필드는 공존한다. |
| 테일아머 | 여왕의위엄·비비드바디와 같은 판정으로 자신과 상하좌우 인접 아군을 보호한다. |
| 흙먹기 | 땅 기술을 무효화하고 최대 HP의 ¼을 회복한다. |
| 독사슬·독조종 | 독사슬은 공격으로 피해를 줄 때 30% 확률로 맹독을 건다. 독조종은 복숭악동이 자신의 기술로 독·맹독을 걸었을 때 혼란을 추가한다. |

## 후속 기획

- **균사의힘**은 보류한다. 변화기를 늦게 쓰는 대가와 대상 특성 무시를 SRPG 페이즈에 적용하는 방식은 추후 결정한다.
- **초상투영·테라체인지·테라셸·제로포밍**은 오거폰·테라파고스의 폼과 함께 테라스탈 기획에서 다룬다.
