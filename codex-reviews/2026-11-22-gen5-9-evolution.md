# 5~9세대 도입 기획 · 특수 진화 조건

아래 조건은 각 개체에 적용하는 확정 기획이다. 기본 진화와 분기 선택은 [세대 추가 규칙](../docs/design/generation-migration.md)과 [분기 진화 기획](./2026-11-21-regional-forms.md)을 따른다.

## 레벨 진화

아래 다섯 진화는 표의 레벨 도달만으로 조건을 충족한다. 신비록과 저승갓숭은 현재 배운 기술과 기술 사용 횟수를 검사하지 않는다.

| 진화 | 레벨 | 대체하는 조건 |
|---|---:|---|
| 오케이징 → 칼라마네로 | 30 | 기기 뒤집기 |
| 노라키 → 신비록 | 32 | 속공 배리어러시 20회 |
| 맨돌핀 → 돌핀맨 | 38 | 멀티플레이 연결 |
| 성원숭 → 저승갓숭 | 40 | 분노의주먹 20회 |
| 멜탄 → 멜메탈 | 40 | 멜탄의 사탕 400개 |

## 층·전투 조건

| 진화 | 판정 조건 |
|---|---|
| 가라르 데스마스 → 데스판 | 고스트가 메인 타입인 맵에서 **층을 클리어하는 순간** 데스마스가 살아 있고, 최대 HP에서 현재 HP를 뺀 값이 49 이상이어야 한다. 출구 직전에 회복하면 회복 후 HP로 판정한다. |
| 가라르 파오리 → 창파나이트 | 한 층에서 자신의 공격 기술로 급소를 3회 기록한다. 한 번의 기술 사용으로 여러 타격이나 여러 대상에 급소가 발생해도 1회로 센다. |
| 흰줄 배쓰나이 → 대쓰여너 | 한 층에서 기절하지 않고, 웨이브태클·돌진 등 자신이 쓴 공격 기술의 반동으로 실제 잃은 HP가 누적 294 이상이면 진화한다. 중간에 회복해도 누적값은 유지한다. 적의 공격, 독, 지형 피해는 집계에서 제외한다. |
| 절각참 → 대도각참 | 절각참 자신의 공격으로 보스에게 마지막 일격을 가하면 진화한다. 다른 아군이 마무리한 전투의 처치 관여는 집계에서 제외한다. |

## 맵 돌파와 상점

- **빠모트 → 빠르모트, 그푸리 → 공푸리, 구르데 → 베라카스**는 해당 개체를 출전시켜 **서로 다른 맵 3곳 이상을 함께 돌파**하면 진화한다. 같은 맵을 반복 돌파하면 한 곳으로 세고, 한 맵 안의 층 통과는 맵 돌파 횟수에 더하지 않는다.
- **모으령 → 타부자고**의 진화 재료인 **모으령의코인 999개**는 상점에 가끔 한 묶음으로 등장한다. 묶음 하나의 가격은 **구매용 코인 999개**다.
