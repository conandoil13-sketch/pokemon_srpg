# 다이맥스·거다이맥스 전투 규칙

다른 기믹과 함께 사용할 때는 [같은 층에서의 전투 기믹 병용 규칙](./2026-11-22-terastallization.md#같은-층에서의-전투-기믹-병용)을 따른다.

## 변신과 행동

- 두 형태 모두 전투판에서 1칸을 점유한다. 도트 크기를 키우되 지형 통과와 충돌 판정은 기존 점유 칸을 기준으로 한다.
- 거다이맥스는 전용 스프라이트가 있으면 사용하고, 없으면 기존 도트를 확대한다. 어느 쪽이든 머리 위에 **화려한 붉은 소용돌이 구름**을 변신 내내 표시한다. 이동·공격 중에도 따라가며 변신 해제 시 사라진다.
- 지속 시간은 **자기 정규 차례 3번**이다. 보너스 행동은 지속 횟수를 소모하지 않는다. 자기 진영 페이즈당 다이기술 사용권은 1회이며 다이월도 포함한다. 사용권을 쓴 뒤 남은 보너스 행동에서는 해당 행동의 조건에 맞는 원래 기술을 사용한다.

## 공격 범위와 위력

상하좌우 한 방향을 선택한다. 공격 범위는 시전자 바로 앞줄부터 **폭 3칸 × 깊이 3칸**이다. 아래는 위쪽을 선택한 예다.

```text
■ ■ ■
■ ■ ■
■ ■ ■
· ▲ ·
```

범위 안의 적이 직접 피해를 받는다. 적 한 마리를 맞히면 위력 100%, 둘 이상을 맞히면 각각 75%를 적용한다. 앞줄과 뒷줄의 배율은 같다. 와이드가드는 실제 피격 수에 관계없이 범위기를 막는다. 거다이일격·거다이연격의 방어 관통은 전용 효과를 따른다.

## 공용 다이기술

| 종류 | 기술과 효과 | 적용 대상 |
|---|---|---|
| 날씨 | 다이번은 햇살, 다이스트림은 비, 다이록은 모래바람, 다이아이스는 싸라기눈 | 명중 후 전장 날씨를 한 번 변경한다. 다이아이스는 추후 싸라기눈·설경 통합 규칙을 따른다. |
| 필드 | 다이썬더는 일렉트릭, 다이그래스는 그래스, 다이사이코는 사이코, 다이페어리는 미스트필드 | 명중 후 전장 필드를 한 번 변경한다. 기존 필드를 덮어쓰며 날씨와 공존한다. |
| 아군 강화 | 다이너클은 공격, 다이스틸은 방어, 다이애시드는 특공, 다이어스는 특방, 다이제트는 스피드 +1 | 시전자와 상하좌우 인접 아군에게 기술당 한 번 적용한다. 다이제트로 오른 스피드는 그 페이즈 종료 시 보너스 행동 판정에 반영한다. |
| 적 약화 | 다이드라군은 공격, 다이할로우는 방어, 다이웜은 특공, 다이아크는 특방, 다이어택은 스피드 −1 | 전방 3×3에서 실제로 맞은 적에게 각각 적용한다. |
| 다이월 | 변화기를 다이월로 사용할 수 있다. | 시전자 자신을 다음 상대 페이즈 종료까지 보호한다. 일반 방어로 다이 공격을 받으면 피해의 ¼을 받고, 다이월은 방어 관통 예외를 제외하고 완전히 막는다. |

## 거다이맥스 전용기

전용기에 대응하는 타입의 공격만 거다이기술로 바뀐다. 해당 타입의 공용 다이기술 부가효과는 전용 효과로 교체한다. 예를 들어 리자몽의 불꽃 공격은 거다이옥염, 비행 공격은 다이제트가 된다.

| 사용자 | 전용 효과 |
|---|---|
| 리자몽·이상해꽃·거북왕·석탄산 | 피격 지점 중심 3×3에 4턴간 지속 피해 장판을 둔다. 자기 진영 페이즈를 장판 위에서 마치면 한 번 피해를 받으며 기술과 같은 타입은 면역이다. 여러 적을 맞혔을 때의 장판 배치 기준은 추후 정한다. |
| 갈가부기·대왕끼리동 | 피격 지점 주변에 각각 바위·강철 설치물을 둔다. 한 이동에서 같은 시전자의 설치물 피해는 1회다. |
| 팬텀·다태우지네·사다이사 | 팬텀은 대상의 이동을 봉인한다. 다태우지네와 사다이사는 속박 지속 피해를 준다. |
| 라프라스·마휘핑·괴력몬 | 시전자와 주변 2칸 아군에게 각각 오로라베일, HP 회복, 급소율 상승을 적용한다. |
| 피카츄·버터플·스트린더·브리무음·더스트나·이브이·나옹 | 전방 3×3에서 맞은 적마다 독립적으로 해당 기술의 상태이상·혼란·헤롱헤롱을 판정한다. 확률은 본가보다 낮춘다. **첫 테스트값은 대상당 30%**다. 상태 후보가 여러 개면 대상마다 발동을 한 번 굴린 뒤 하나를 정하고 기존 면역을 적용한다. 나옹의 코인 효과는 구매용 코인 규칙을 따른다. |
| 두랄루돈 · 거다이감쇠 | [섬뜩한주문](./2026-11-21-gen8-moves.md) 판정을 재사용한다. 맞은 적마다 그 포켓몬이 마지막으로 쓴 기술을 1턴간 봉인한다. |
| 이올브·아머까오 | 이올브는 기존 중력과 착지 규칙, 아머까오는 기존 안개제거의 제거 대상 목록을 따른다. |
| 우라오스 두 태세 | 거다이일격·거다이연격은 다이월까지 관통한다. |
| 킹크랩·애프룡·단지래플·오롱털·멜메탈 | 각각 스피드 2랭크 하락, 회피율 하락, 아군 상태이상 회복, 하품, 같은 기술 연속 사용 제한 효과를 사용한다. |
| 고릴타·에이스번·인텔리레온 | 본가 전용기의 고위력과 대상 특성 무시를 적용한다. |

### 잠만보 · 거다이재생

거다이재생이 적 한 마리 이상에게 명중하면 **잠만보 상하좌우 빈칸에 회복 열매를 최대 2개** 놓는다. 피격 수에 따라 열매가 늘어나지 않는다.

- 아군과 적 모두 밟을 수 있다. 밟은 포켓몬은 자기 최대 HP의 **⅛**을 회복하고 먹은 열매는 사라진다. 가방에 들어가지 않는 층 전용 설치물이다.
- [압정의 이동 판정](./hotfixes.md)처럼 **한 번의 이동에서 같은 잠만보가 놓은 열매는 1개만** 발동한다. 한 경로에서 두 번째 열매를 지나면 그 열매는 바닥에 남아 다른 포켓몬이 먹을 수 있다.
- 같은 잠만보가 다시 명중시키면 남아 있던 자기 열매를 거두고 새로 배치한다.
