# 5세대 도입 기획 · 기술과 특성

5세대 신규 기술 92개와 특성 41개를 검토하면서 별도 판정이 필요했던 항목의 기획 기록이다. 기본 데이터는 [세대 추가 규칙](../docs/design/generation-migration.md)을 따른다. 아래 수치는 기획값이며, 추가 논의가 필요한 부분은 마지막 절에 남긴다.

## 기술

| 기술 | 위력 | 적용할 규칙 |
|---|---:|---|
| 당신먼저 · 순서미루기 | — | 도입 대상에서 제외한다. |
| 돌림노래 | 60 | 본가 연계 효과를 적용한다. 같은 턴에 뒤이어 돌림노래를 선택한 아군은 바로 이어서 행동하며 후속 돌림노래의 위력은 120이다. |
| 에코보이스 | 40~200 | 양 진영이 연속 사용 기록을 공유한다. 연속된 턴마다 40씩 올리고, 한 턴에 여러 번 써도 한 번만 올린다. 한 턴 동안 아무도 쓰지 않으면 40으로 돌아간다. |
| 원수갚기 | 70 | 아군을 기절시킨 상대를 대상으로 처음 쓰는 원수갚기는 위력 140이다. 이후 그 대상에게는 기본 위력을 적용한다. |
| 크로스플레임 · 크로스썬더 | 각 100 | 서로 다른 두 기술이 어느 순서로든 연달아 적중하면 뒤 기술의 위력은 200이다. |
| 불꽃의맹세 · 물의맹세 · 풀의맹세 | 각 80 | 불꽃+풀은 지속 피해 장판, 물+풀은 스피드 감소 장판, 불꽃+물은 기술의 부가효과 확률을 높이는 장판을 만든다. |
| 프리폴 | 60 | 설계안은 첫 턴에 시전자와 대상이 함께 공중날기 상태가 되고 대상의 행동이 묶이는 방식이다. 다음 턴에 낙하 공격을 한다. 중도 해제 시 양쪽의 공중 상태와 대상의 행동 제한을 함께 풀도록 검토한다. |
| 볼트체인지 | 70 | 유턴과 같이 2칸 대시한 뒤 공격하고 출발 칸으로 복귀한다. 비접촉 전기 특수기이므로 대시한 지점에서의 공격 사거리를 유턴보다 1칸 길게 둔다. |
| 와이드가드 | — | 범위 공격기로 분류된 기술을 막는다. 실제로 한 마리만 범위에 있어도 방어한다. |
| 패스트가드 | — | 한 턴 동안 시전자 상하좌우의 인접 4칸에 선 적은 우선기를 사용할 수 없다. 적이 기술을 쓰는 칸을 기준으로 판정한다. |
| 가드셰어 · 파워셰어 | — | 본가처럼 사용자와 대상의 해당 능력치를 항목별로 평균 내어 양쪽에 적용한다. 가드셰어는 방어·특방, 파워셰어는 공격·특공을 다루며 능력 랭크는 별도로 유지한다. |
| 원더룸 · 매직룸 | — | 시전자 칸을 중심으로 7×7 영역을 만든다. 원더룸 안에서는 방어·특방을 바꿔 계산하고, 매직룸 안에서는 지닌 도구의 효과를 정지한다. |
| 불태우기 | 60 | 공격 후 바닥에 일자형 불 장판을 남긴다. |
| 테크노버스터 · 옛노래 | 120 · 75 | 게노세크트와 메로엣타의 데이터 도입 시 각각 본가 효과를 적용한다. 테크노버스터는 카세트에 따라 타입이 바뀌고, 옛노래는 수면 부가효과와 명중 시 메로엣타의 폼 전환을 갖는다. |
| 기프트패스 | — | 보류. 도구를 대상에게 건네는 효과의 SRPG 규칙은 추후 결정한다. |

## 특성

| 특성 | 적용할 규칙 |
|---|---|
| 짓궂은마음 | 매 자기 진영 페이즈 시작에 보유자마다 변화기 전용 보너스 행동을 1회 얻는다. 이 행동으로 상대 악 타입도 지정할 수 있으며, 해당 대상에게는 “효과가 없다…”를 표시한다. [선제공격손톱·질풍날개와의 처리 순서](./2026-11-20-phase-bonus-actions.md) |
| 애널라이즈 | 전장의 모든 포켓몬 중 보유자의 스피드가 가장 느릴 때 공격 위력을 1.5배로 올린다. |
| 재생력 | 자연회복과 같은 비전투 조건을 쓴다. 직전 상대 차례부터 공격하지도 공격받지도 않았다면 자기 차례 끝에 최대 HP의 ¼을 회복한다. |
| 우격다짐 | 선공기는 예외로 두고, 적용 대상 공격기의 모든 부가효과를 제거하며 위력을 1.3배로 올린다. |
| 매직미러 | 보유자 칸과 상하좌우 인접 4칸까지 반사 대상으로 보호한다. 압정이 보호 범위에 깔리면 시전자 주변으로 압정 배치를 반사한다. |
| 틈새포착 | 관통할 수 있는 보호 효과를 기술별로 지정한다. 같은 장판 모양이어도 각 기술의 지정값을 따른다. |
| 일루전 | 모습·이름·정보창·상성·예상 피해·AI 판단에서 정체를 숨긴다. 실제 첫 타격은 본래 타입으로 계산하고 피해를 받은 직후 정체가 드러난다. [고산의 조로아 기획](./2026-11-20-high-mountain-stage.md) |
| 괴짜 | 출현·획득 후보에서 제외한다. |
| 미라 | 접촉한 공격자의 메인 특성 슬롯만 미라로 바꾼다. [특성 슬롯 기획](../docs/design/extra-abilities.md) |
| 달마모드 | 불비달마 전용이다. 다른 종의 무작위 특성 후보에서도 제외한다. |
| 프렌드가드 | 상하좌우로 인접한 다른 아군이 받는 공격 피해를 줄인다. 피해를 받는 포켓몬을 기준으로 인접 보유자를 센다. 1마리는 30%, 이후 한 마리마다 **+6%p**로 2마리는 36%, 3마리는 42%, 4마리는 48%다. 보유자 둘이 서로 인접하면 상대방 덕분에 각각 30% 보호받는다. |
| 승리의별 | 자신과 주변 2칸의 아군에게 명중률 1.1배를 적용한다. 다른 명중 보정을 계산한 뒤 마지막에 곱한다. |
| 변덕쟁이 | 비전투 턴에도 발동한다. 명중·회피를 제외한 무작위 능력 하나를 2랭크 올리고 다른 능력을 1랭크 내린다. 각 변화는 기존 단일 대상 랭크 변화와 같은 주기로 만료된다. |
| 자기과신 | 직접 쓰러뜨린 적 한 마리마다 공격이 1랭크 오른다. 범위기 한 번으로 셋을 쓰러뜨리면 +3이다. |
| 심술꾸러기 | 맵 요소로 생기는 랭크 변화도 반전한다. 전기 거미줄의 스피드 −1은 +1이 된다. |
| 방진 | 날씨 피해와 가루·포자 기술 면역에 요정의 숲 버섯 포자 면역을 포함한다. |
| 저주받은바디 | 공격 한 번으로 맞힌 서로 다른 보유자 수를 세어 해당 기술의 사슬묶기 확률을 한 번 계산한다. 1마리 30%, 2마리 40%, 3마리 50%로 추가 보유자당 +10%p다. |
| 나쁜손버릇 | 적에게도 지닌 도구가 도입되면 양측 모두 접촉 시 탈취할 수 있다. 일반 장비는 해당 층에서만 임시 이전한다. 아군이 야생 포켓몬에게서 훔친 1회성 소모품(나무열매·주얼)은 아군 소유가 된다. |
| 긴장감 | 나무열매 도입 시 보유자 주변 2칸 안의 상대는 나무열매를 사용할 수 없다. |
| 수확 | 전투 종료 시 확률 판정으로 나무열매 하나를 발견한다. 강한 햇살에서도 발견 확률은 약 50%로 둔다. |

## 후속 결정 사항

- 맹세·불태우기 장판의 크기와 지속 턴, 룸의 중심이 시전 칸에 고정되는지 또는 시전자를 따라가는지는 미정이다.
- 짓궂은마음의 보너스 행동은 현재 칸에서 이동 없이 사용하고, 범위 변화기는 상대 악 타입에게만 면역을 적용하는 안이 제안됐다.
- 애널라이즈는 공격 직전 양측 생존자의 현재 스피드를 비교하고 공동 최저속도 인정하는 안이 제안됐다.
- 우격다짐의 선공기 예외는 선공기 전체를 적용 대상에서 제외하는 해석이다. 매직미러의 연쇄 반사는 1회로 제한하는 안이 제안됐다.
- 수확의 평상시 발견 확률은 미정이다. 평상시 25%는 밸런스 제안값이다.
