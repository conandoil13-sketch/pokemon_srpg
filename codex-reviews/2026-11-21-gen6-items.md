# 6세대 도입 기획 · 전투 도구

약점보험·빛이끼·눈덩이는 [구근·충전지](./2026-11-20-gen5-items.md)처럼 착용자마다 층당 1회 발동한다. 세 도구 모두 랭크 상승이 기본 지속 시간보다 1턴 더 유지된다.

| 도구 | 발동 조건과 효과 |
|---|---|
| 약점보험 | 효과가 굉장한 공격으로 피해를 받으면 착용자의 공격과 특공이 각각 2랭크 오른다. 아군의 범위 공격으로도 발동할지는 미정이다. |
| 돌격조끼 | 착용자의 특방이 1.5배가 되고 변화기 선택을 막는다. 짓궂은마음의 변화기 전용 보너스 행동은 자동으로 건너뛴다. 질풍날개의 보너스 행동에서는 비행 공격기를 사용할 수 있다. [페이즈별 보너스 행동](./2026-11-20-phase-bonus-actions.md) |
| 방진고글 | 방진 특성과 같은 면역을 적용한다. 날씨 지속 피해, 분진을 포함한 가루·포자 기술, 요정의 숲 버섯 포자를 막는다. |
| 빛이끼 | 물 타입 공격으로 피해를 받으면 착용자의 특방이 1랭크 오른다. |
| 눈덩이 | 얼음 타입 공격으로 피해를 받으면 착용자의 공격이 1랭크 오른다. 얼음동굴의 고드름 바위 충돌도 얼음 타입 피해로 계산하며 눈덩이를 발동시킨다. |
| 정령플레이트 | 착용자가 사용하는 페어리 타입 공격기의 위력이 1.2배가 된다. 기존 타입 강화 장비의 판정을 사용한다. |

로셀열매·악키열매·타라프열매의 발동 조건은 [나무열매 기획](./2026-11-22-berries.md)을 따른다. 전투 밖 도구는 이번 업데이트 범위에서 제외한다.
