# 기술 밸런스 조정 메모

2026-11-20 사용자 결정. ‘원작’의 기준은 4세대다. 아래는 기획 단계에서 합의한 동작이다.

## 발동 시점과 사용 조건

| 기술 | 결정한 동작 |
|---|---|
| 미래예지 · 파멸의소원 | 포켓몬 하나를 지정한다. 사용한 지 두 턴 뒤, 대상이 이동했더라도 지정한 포켓몬에게 피해가 들어간다. |
| 구멍파기 · 다이빙 · 섀도다이브 · 공중날기 · 뛰어오르기 | 본가의 순서를 따른다. 첫 턴에 숨거나 떠오르고, 다음 턴에 나타나 공격한다. |
| 충전 | 특방 1랭크 상승에 본가의 전기 기술 강화 효과를 더한다. 바로 다음 턴에 전기 공격기를 쓰면 그 기술의 위력이 2배가 된다. |
| 힘껏펀치 | 한 턴 동안 집중한 뒤 공격한다. 집중을 시작한 뒤 공격을 내기 전에 상대의 공격에 맞으면 실패한다. |
| 코골기 | 사용자가 잠들었을 때 사용할 수 있다. 깨어 있는 상태에서 쓰면 실패한다. |

## 조건부 위력과 상태이상

| 기술 | 결정한 동작 |
|---|---|
| 소금물 | 대상의 남은 HP가 최대 HP의 절반 이하이면 위력 2배. |
| 객기 | 사용자가 독·맹독·마비·화상 상태이면 위력 2배. |
| 분화 · 해수스파우팅 | 공격 시점의 사용자 HP 비율에 따라 위력이 정해진다. 150 × 현재 HP ÷ 최대 HP의 소수점을 버리고 최소 위력은 1로 한다. HP가 가득 차면 150, 절반이면 75다. |
| 웨더볼 | 기본은 노말 타입, 위력 50. 비에는 물, 쾌청에는 불꽃, 모래바람에는 바위, 싸라기눈에는 얼음 타입이 되며 이 네 날씨에서는 위력 100. |
| 잠깨움뺨치기 | 잠든 대상에게 위력 2배로 피해를 준 뒤 잠을 깨운다. |
| 정신차리기 | 마비된 대상에게 위력 2배로 피해를 준 뒤 마비를 해제한다. |
| 승부굳히기 | 대상이 같은 턴에 이미 피해를 받았다면 위력 **1.5배**. |
| 리벤지 · 눈사태 | 사용자가 직전에 맞은 공격을 가한 상대에게 쓰면 위력 **1.5배**. 턴이 바뀌어도 직전 공격자가 그 상대라면 적용한다. |
| 혼내기 | 대상의 양수 능력치 랭크를 합산한다. 기본 위력 60에 합계 1랭크당 20을 더하며 최대 위력은 200. |
| 솔라빔 | 비·모래바람·싸라기눈에서는 위력이 절반이 된다. |

## 연속 사용과 지속 효과

| 기술 | 결정한 동작 |
|---|---|
| 연속자르기 | 4세대 본가처럼 연속 명중할 때마다 위력이 커진다. 빗나가거나 다른 기술을 쓰면 누적이 끊긴다. |
| 구르기 · 아이스볼 | 이번 조정은 연속자르기처럼 연속 명중할수록 위력이 커지는 효과까지 적용한다. 이후 동작은 추후 조정 대상으로 남긴다. |
| 역린 · 꽃잎댄스 계열 | 처음 지정한 적을 **2~3턴 동안 자동으로 따라가며 공격**한다. 연속 공격이 끝나면 사용자가 혼란에 빠진다. 앞서 같은 계열로 검토한 기술에는 난동부리기도 있다. |
| 소란피기 | 시전자 주변에 여러 턴 지속되는 영역을 표시한다. 영역 안에서는 잠들 수 없고, 지속 중 시전자는 다른 기술을 사용할 수 없다. |
| 트리플킥 | 본가처럼 최대 세 번 차며 각 타격의 위력은 차례로 10·20·30이다. 타격마다 명중을 판정하며 빗나가면 거기서 끝난다. |
| 분노 | 본가처럼 분노가 이어지는 동안 상대의 공격에 맞으면 사용자의 공격 랭크가 1 오른다. |

|---|---|

## 대시와 이동에 반응하는 기술

칸 수는 기술을 사용할 때의 대시 거리다.

| 기술 | 결정한 동작 |
|---|---|
| 돌진 · 플레어드라이브 · 스파크 · 브레이브버드 | 1칸 대시해 공격한다. |
| 이판사판태클 · 화염바퀴 · 양날박치기 | 2칸 대시해 공격한다. |
| 신속 | 기존 공격 후 이동 효과에 공격 전 2칸 대시를 추가한다. |
| 전광석화 · 아쿠아제트 | 공격 전 1칸 대시를 추가한다. 공격 후에는 남은 이동력으로 다시 이동할 수 있다. |
| 폭포오르기 | 기본 대시 거리는 1칸이다. 경로의 물 타일은 0칸으로 계산하므로 물을 따라 더 멀리 대시할 수 있다. |
| 점프킥 | 중간의 한 칸을 뛰어넘어 착지한 뒤 공격할 수 있다. 예를 들어 물 한 칸을 건너거나 바위 한 칸을 넘는다. |
| 회전부리 | 1칸 대시해 공격한 뒤 기술을 쓰기 시작한 칸으로 돌아온다. |
| 유턴 | 2칸 대시해 공격한 뒤 기술을 쓰기 시작한 칸으로 돌아온다. |
| 따라가때리기 | 공격 턴에 이 기술로 때린 대상이 사용자에게서 멀어지려 하면, 이동하기 직전에 같은 위력으로 한 번 더 공격한다. 이후 대상은 이동을 계속한다. |
| 구르기 · 아이스볼 | 대시 추가 예정. 거리와 세부 동작은 추후 조정한다. |
