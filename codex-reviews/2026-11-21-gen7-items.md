# 7세대 도입 기획 · 전투 도구

| 도구 | 발동 조건과 효과 |
|---|---|
| 그라운드코트 | 착용자가 기술 또는 메이커 특성으로 만든 필드가 5턴에서 8턴으로 연장된다. 메이커가 동시에 발동하면 마지막 필드를 만든 포켓몬의 착용 여부로 지속시간을 정한다. |
| 방호패드 | 착용자가 접촉 공격을 할 때 울퉁불퉁멧 피해, 미라의 특성 교체, 준비 중인 부리캐논의 화상 등 상대와의 접촉으로 생기는 효과를 막는다. 기술의 원래 접촉 분류와 사거리는 유지한다. [원격 판정](./2026-11-21-gen7-abilities.md) |
| 주눅구슬 | 상대의 위협을 받으면 스피드가 1랭크 오른다. 상승한 스피드는 발동 후 돌아오는 스피드 보너스 행동 판정부터 적용한다. |
| 일렉트릭시드·그래스시드 | 각각 일렉트릭필드·그래스필드에서 착용자의 방어가 1랭크 오른다. |
| 미스트시드·사이코시드 | 각각 미스트필드·사이코필드에서 착용자의 특방이 1랭크 오른다. |

주눅구슬과 필드시드 4종은 착용자마다 층당 1회 발동하며, 상승한 랭크는 기본 지속시간보다 1턴 더 유지된다. 시드는 공중에 있는 착용자에게도 발동한다.

여러 메이커가 동시에 등장하면 빠른 순서부터 필드를 모두 펼친 뒤, 최종 필드를 기준으로 시드를 판정한다. 예를 들어 일렉트릭필드 위에 느린 포켓몬이 사이코필드를 펼치면 사이코시드만 발동하고 일렉트릭시드의 사용 기회는 남는다.

실버디의 메모리는 [실버디·아르세우스 공동 기획](./2026-11-21-silvally-arceus.md)에서 다룬다. Z크리스탈은 Z기술 기획 때 논의한다.
